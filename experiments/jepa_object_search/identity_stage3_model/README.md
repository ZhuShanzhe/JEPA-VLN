# 位姿条件 JEPA 跨视角实例核验

多实例寻物需要记住“我看到过的是哪一件”。这一模块在 MOST-Nav 已经登记物体、机器人又看到同类候选时，比较旧参考和当前各候选，输出同一实例、不同实例或证据不足。高层决策、路线、检测器、报告距离与动作回执仍走原有接口。

## 学习方法

冻结 DINOv2 ViT-B/14，分别编码物体裁块和周围背景。参考相机位置、当前相机相对旋转和平移，以及参考框的深度支持点，供预测器估计换视角后应当得到的局部特征。将预测与实际观察逐个匹配，并用同类不同实例的监督标签抑制串号。与它配对的直接监督头有相同的输入、网络容量和更新步数。唯一训练目标差异是 JEPA 额外学习匹配同物体另一视角的冻结编码。在 28 栋 HSSD 房屋训练，6 栋单独校准，包含自然观察和人为构造的同款干扰。三个固定种子的全部结果均保留。[训练与接口](train/README.md)

## 独立房屋结果

新选 12 栋与前期身份研究分房不重叠的 HSSD 官方验证房屋，以 92 次同物复看、94 次原物缺席的自然查询评估。另外从其中 7 栋构建 73 组同款邻居移除探针。下表中三个数字依次对应相同的三个种子；旧外观规则和位置规则无训练随机性。

| 测试 | 旧外观规则 | 仅用位置 | 等输入直接监督 | JEPA |
|---|---:|---:|---:|---:|
| 正确认回同物，分母 92 | 4 | **73** | 65 / 56 / 47 | 68 / 70 / 69 |
| 人为增加位姿误差后正确认回，分母 92 | 4 | 45 | 57 / 49 / 44 | **63 / 68 / 67** |
| 正确认回 A 且未把 A 当成已移走的同款 B，分母 73 | 25 | **58** | 36 / 44 / 44 | 54 / 55 / 57 |
| 把 A 错认成已移走的 B，分母 73，越低越好 | 10 | **0** | 17 / 9 / 7 | **1 / 0 / 0** |

旧外观规则使用 RGB 与候选框。两个学习头及位置规则还使用深度、相机内参和位姿。独立房屋上，把预测目标加入相同网络后，三个种子都认回了更多物体，也减少了邻居错认。理想位姿下简单的位置规则更强；人为加入每个机位水平 15 厘米和偏航 5° 的误差后，其正确认回数从 73 降到 45。此项敏感性测试不能代表所有真实建图误差。[独立房屋的选样、统计与复现](new_houses/README.md)

## 复看与写回

在原开发面板上，三个种子在 89 次可见复看中的 JEPA 正确数为 62 / 60 / 63，直接监督为 60 / 52 / 56。82 组同款成对测试中，误认已移走的邻居分别为 2 / 2 / 2 和 11 / 4 / 4。首种子按时间顺序增加一张系统自行确认的参考图后，JEPA 从 62 次正确变为 64 次，直接监督从 60 变为 62。自动补存仍会接受身份难以核实的检测框。[原开发面板与多种子对照](eval/README.md)

在 HM3D 既有失败回合的实际复看图上，原外观规则未认回时钟。使用三幅真实存档 RGB 重建同一坐标系的几何，再送入已接入报告核验环节的两个学习头，两者均命中经核验的钟面。若只使用当时系统已留存的数据，抵达时属于非关键帧，缺同步几何，两者都会暂缓。13 项受控接口与报告写回检查通过。尚需新的闭环导航回合检验实际的不同实例上报数、重复报告和任务完成率。[真实回放与集成验收](integration/README.md)
