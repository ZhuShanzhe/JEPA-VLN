# 独立房屋多视角实例核验

从 HSSD 官方验证划分中，排除前期身份实验训练、校准和诊断用过的 50 个房屋族。按固定散列选房，优先覆盖有时钟的房屋，再补足 12 栋。每屋每类最多选 3 个物理实例，每物体最多取 3 个视角。采集只检查可行走机位和实例像素可见性。保留图像、深度、真实相机参量和实例像素标签，模型运行时只使用指定的 RGB、候选框、深度及相机参量。此处的“独立”指本项目的实例模块训练与方法选择。HSSD 场景及其资产仍来自同一数据来源。

12 栋房屋共得到 49 个实例、141 张图（39 张时钟、102 张画作）。取每个物体的第一张图登记，其余合格视角形成 92 次同物查询。另有 94 次异物查询，要求登记物体在查询图中的像素数为零，并有其他同类实例达到可见标准。每个实例最多取两次这样的查询。自然样本中的负例可以离得较远，另设紧邻同款物体对照。

## 换机位认回同一实例

| 方法 | 标定位姿下认回 / 92 | 加入位姿误差后认回 / 92 |
|---|---:|---:|
| 原项目现场外观规则（RGB） | 4 | 4 |
| 仅按最近 3D 表面点匹配 | 73 | 45 |
| 等输入直接监督，三个种子 | 65、56、47 | 57、49、44 |
| 位姿条件 JEPA，三个种子 | 68、70、69 | 63、68、67 |

所有方法使用同一份冻结 Grounding DINO 候选和同一登记机会。真实检测源框只有与指定实例唯一对应（IoU ≥ 0.5）时才用作参考。92 个正例有 5 个缺可用源框，均保留在分母。查询时提供当前整组检测框，模型不知道哪个是正确实例。三个学习种子共用选样、类别、预算、冻结编码器和校准规则。

精确位姿下，JEPA 首种子为 68 次正确、1 次认作其他实例、4 次判不同、14 次暂缓、5 次源框缺失。在两端都具备正确框的 77 次中，JEPA 认对 68，其余 9 次暂缓。94 个原物完全不在场的查询，三个 JEPA 种子均有 80 次明确判不同、6 次暂缓、8 次源框缺失，未把其他实例接受为旧实例。未认出旧物与明确识别为不同均可避免错误接受，两者分别计数。

位姿压力测试对每张图单独施加固定的水平 15 厘米偏移和正或负 5° 偏航，像素、局部深度、候选和模型保持一致。它测量对一种误差的敏感性，实际 SLAM 的噪声可能在相邻机位相关，且地图尺度也可能不准。按每个输入先平均三个种子、再按房屋等权配对重采样，在标定位姿下 JEPA 相对直接监督的认回率差为 +13.6 个百分点（95% 区间 +7.8 至 +19.4）；在该压力条件下相对直接监督为 +17.5（+8.6 至 +26.9），相对仅靠位置为 +26.3（+14.4 至 +38.8）。这些区间针对本次 12 栋房屋。

## 把同款邻居移走

在上述独立房屋内，沿用既有受控布局协议，在同一面墙并排放置原件 A 和同资产的 B。登记图里二者同时可见；在相同的三个预设机位再录一组只有 A 的图。按物理可见性筛选后，共有 7 栋房屋、9 个布局、54 张图、73 组成对判断。其中 48 组变换了机位。每组用 A、B 两张参考分别查询**同一张**当前图。联合正确要求认回 A，且用 B 作参考时不接受任何当前框。后者可明确判不同或暂缓。

| 方法 | 联合正确 / 73 | 用 B 的参考错认 A / 73 |
|---|---:|---:|
| 原外观规则 | 25 | 10 |
| 仅用位置，标定位姿 | 58 | 0 |
| 等输入直接监督，三个种子 | 36、44、44 | 17、9、7 |
| JEPA，三个种子 | 54、55、57 | 1、0、0 |

要求在认回 A 的同时**明确**判 B 不同，三个 JEPA 种子分别为 12、18、18 组；直接监督为 9、11、2 组。联合成功仍有相当部分依赖暂缓。按三个种子平均后，以七栋房屋为单位成对重采样，JEPA 相对直接监督的联合正确率差为 +18.8 个百分点（95% 区间 +4.8 至 +36.2），将现场 A 错归给 B 的比例差为 −13.0 个百分点（−31.0 至 −0.3）。房屋样本很小，受控移除试验不能代表自然房屋中的误认频率。理想位姿下的位置对照在本组最强。

## 记忆更新回放

复用先前 13 栋房屋、36 份登记的定向复看序列。先处理过渡观察，仅当模型接受某候选为同一实例时才把它存为附加参考，再独立处理随后各复看图。两份参考若指向两个不同候选则暂缓。首种子 JEPA 在 89 次目标可见复看上从 62 次正确升至 64 次，直接监督从 60 升至 62。JEPA 接受了 29 次过渡图写入，其中 28 次可核实为本实例，1 次检测框未达到可核验条件；后者的物理身份仍未知。此项是对已知序列的离线重放。

## 运行与记录

在独立输出目录 `OUT` 的 `private` 下保存原始材料。顺序为：

1. 在 Habitat 环境运行 `collect_panel.py PROJECT HSSD_ASSETS OUT/private`。使用 `benchmark.py PROJECT OUT detect` 生成冻结检测框。
2. 依次以 `legacy`、`learned`、`summary` 运行同一评分入口。额外种子对 `learned` 和 `summary` 使用各自的 `--checkpoint-dir`，再运行 `seed_summary.py OUT`。
3. 对同款干扰物运行 `independent_twins.py PROJECT OUT collect HSSD_ASSETS`，再运行 `detect`、`score`。该入口重用历史受控布局生成器及固定视角配对评分。
4. 对上一轮的连续观察运行 `bridge_replay.py PROJECT OUT/bridge.json`。
