# 时钟复看与记忆写回

在现有报告前核验环节，将“登记参考图与现场候选是否为同一实例”的局部判定切换为冻结的直接监督或 JEPA 头。原动作、近距离约束、同一区域的多实例竞争检查、已报告去重和下一步执行回执沿用现有适配器。初始模式为 `original`，学习版分别为 `NAV_STAGE3_IDENTITY=direct`、`jepa`。学习模型通过独立本地进程运行，候选匹配不能自行登记或合并实体。

| 判定 | 行为 |
|---|---|
| 同一实例 | 将唯一匹配的现场候选交给原距离与邻居竞争检查；只有真实报告动作回执才能写入已报告状态 |
| 不同实例 | 保留已有实例和当前候选，当前候选由既有新实例审核链处理 |
| 证据不足、缺少对应机位的几何 | 保留待查；每次获新的现场画面后重算 |

当前图是已登记关键帧时，接口可用现有映射点云估计该帧深度、相机内参和公制位姿；保留稀疏深度，未观测像素不插值作为独立证据。非关键帧也可以显式传入参考和当前图像各自的同步深度、内参、同一坐标系下的相机位姿。接口校验两张 RGB 的内容指纹以及当前步号。原服务器日志没有对每个非关键帧提供这些输入，接入线上还需与前端的实时几何生成对接。

## 首个时钟复看

复用此前已独立核验的 HM3D 时钟回合，取首次登记、复看移动前和抵达时的三张图。固定登记框、当前全部合格 Grounding DINO 候选和 RGB，最终判定用独立人工核实的钟面框评分。定位命中门槛为 IoU ≥ 0.50。三种方法共享图片和候选，两个学习头共享几何。全程没有新增导航动作或付费推理。

| 现场确认结果 | 原模板与局部特征 | 直接监督头 | JEPA 头 |
|---|---|---|---|
| 只提供归档时原可取的输入 | 暂缓 | 该步没有同步点云，暂缓 | 该步没有同步点云，暂缓 |
| 在相同的原始三个机位上，从 RGB 重新估计几何 | 暂缓 | 接受，命中核验钟面 | 接受，命中核验钟面 |

归档保留了精简的关键帧位置轨迹，未保留该复看步的原始密集点云。重建组使用本地 VGGT 从三张 RGB 共同估计深度、相机内外参，再由接近阶段实际执行且未记录运动失败的动作估算公制尺度。两个学习头都通过了该配对，尚无两者在这一例上的优劣证据。该结果衡量抵达后的身份核验，抵达前选路与在线 SLAM 的几何质量还需另外评价。

## 验收与运行

预输入测试覆盖正确识别后暂存报告、错误回执可重试、重复回执只认一次、同类邻居仍待查、两个参考竞争同一区域时暂缓、缺少几何或图像指纹不符时暂缓，以及稀疏深度和相机内参的映射。受控回执用于验证状态转换，不能折算成新导航回合成功率。

在项目数据盘，历史回合提取、三帧几何估计和冻结评分工具与该实验一起保存。在评测环境加载既有适配器后，用 `python check_chain.py contract_results.json` 重跑独立的上报与记忆状态验收。
