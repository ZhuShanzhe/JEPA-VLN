# 位姿条件局部特征与实例身份核验

输入为参考图与当前候选框的 RGB、对应深度、相机内参以及同一米制度量坐标系下的 OpenCV 相机位姿。冻结 DINOv2 ViT-B/14 对每个候选提取目标裁块 CLS、区域 patch 均值和遮去目标的邻域特征。参考框内深度给出估计的表面支撑点。模型输入不含仿真实例编号或真实物体中心。当前开发集的位姿和深度来自模拟器，在真实系统的估计地图下需单独评估。

**训练对照。** 两种方法各有 611,041 个可训练参数。给定一个观察的编码、相对旋转和平移以及参考物体相对于相机的位置，残差预测器输出另一个观察方向上的期望区域特征。现场判断综合预测与实际编码的一致性、两端实测的外观与几何信息。正向和反向各计算一次。直接监督对照使用相同输入和网络，以两端是否属于同一实例的二元损失训练。JEPA 另对正例加入权重为 3 的余弦预测损失，目标取自冻结的另一视角区域编码。两套模型均不含生成或重建像素的目标。预测对象为物体局部裁块的池化表征，每次现场查询均需提供候选框。

**数据。** 沿用 HSSD 项目划分，训练房屋 28 栋、校准房屋 6 栋。既有绕物观察、自然的近邻检测框提供大转角同物、同类异物和同帧竞争。新增受控布局在训练房屋与校准房屋内分别生成同款时钟和画作，在同一机位保存有邻居和移走邻居后的画面。共 8 个训练布局、48 张全图，9 个校准布局、54 张全图。真实检测器出框，经一对一 IoU ≥ 0.5 归属标注后才进入身份训练，未匹配候选不以负例加入。既有绕物源使用渲染时的标注裁块。仿真实例编号用于构造匹配标签，未用于预测。收集时需有满足布局及可见性约束的位置，场景数不反映自然分布。

| 配对来源 | 训练正 / 负 | 校准正 / 负 |
|---|---:|---:|
| 绕物观察 | 27,604 / 27,604 | 5,750 / 5,750 |
| 自然房间候选 | 238 / 1,213 | 160 / 540 |
| 受控同款候选 | 92 / 94 | 124 / 106 |

每批每个来源的正负样本各取 32 对，批量 192。每轮 48 步，共训练 12 轮。两个方法在每个随机种子中共享初始化、采样顺序、随机位姿扰动和训练预算。按三个校准来源等权的低误接收区部分 AUC 选择轮次。高阈值使各来源的校准异物误接受率均不超过 5%，低阈值另限制正例被强判为异物的比例。阈值使用合格配对，面对未匹配检测框或场景变化的误接受率需要用相应评测检验。

**现场输出。** 每个参考单独对应整组同类别候选。最高分达到高阈值，并领先第二名至少 0.05 时输出同一实例及对应索引；所有有效分数均低于或等于低阈值时输出不同实例；其他情况暂缓。空候选、缺失几何、两张参考竞争同一候选均暂缓。此处“不同实例”只说明未与给定参考建立同一性。上游另行核查类别、当前实例是否已登记以及上报条件。

**复现。** 使用项目现有的 V20 编码器、V21 真实候选与位姿缓存及兼容的 HSSD 仿真资产。在新的输出目录中执行以下步骤：

1. `bash prepare.sh PROJECT HSSD_ASSETS HABITAT_PYTHON MODEL_PYTHON` 生成隔离的训练和校准同款数据；脚本支持在已有阶段完成后继续。
2. `MODEL_PYTHON fit_identity.py PROJECT` 训练首轮成对方法。其他种子可用 `--seed 126112 --output-dir DIR` 或 `--seed 126113 --output-dir DIR`；已有权重受到覆盖保护。
3. `IdentityVerifier(project, mode="jepa", device="cuda", checkpoint_dir=None)` 加载对应头。先用 `encode(rgb, boxes, depth, K, c2w)` 编码每一帧，再使用 `score(left, right)` 和 `decide(scores)`。直接监督的模式名为 `direct`。两个模型共享同一冻结编码。
4. `MODEL_PYTHON check_interface.py PROJECT interface_results.json` 将实际校准图重新编码，与训练缓存比较并验证缺失观测、冲突和拒判路径。

三个预定随机种子的低误接受区间校准 pAUC（直接监督 / JEPA）分别为 0.866 / 0.898、0.841 / 0.879、0.809 / 0.890。校准样本用于选轮次和阈值，效果比较需另看冻结后的留出集。检查点指纹逐种子保存；额外种子使用独立目录及可选加载目录，首轮权重保持原指纹。
