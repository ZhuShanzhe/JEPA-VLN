# 仿真场景

[场景程序](tools/README.md) 生成 Blender 资产与两条实际路线，并验证原版多实例报告评分。模型观测和离线裁判结果分开保存。

## HM3D v0.2 与 MOST-Bench

验证集包含 100 个带导航网格的场景，其中 36 个带实例语义标注。MOST-Bench 的 36 栋任务房屋全部覆盖。750 个公开起点均落在原始导航网格上，5,251 次目标实例引用全部匹配。冻结的 ManyON 子集包含 150 个类别回合与 150 个属性回合。

Habitat-Sim 在每栋任务房屋的原始起点读取了 RGB、深度与实例语义。原版 MOST-Bench 评测入口使用一个真实回合，以 1280×1280 RGB-D 观测验证转向与结束动作。上述数字描述数据覆盖和接口验收，策略性能由后续闭环评测给出。
