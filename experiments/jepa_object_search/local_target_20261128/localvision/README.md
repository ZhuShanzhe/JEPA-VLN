# 局部观察位的视觉评分

局部模块接收当前右、中、左三帧 RGB、目标类别和候选动作序列。中心图分成九个有重叠的区域，每个区域保留中心点、边界框和图块编号。区域先验沿用原有模型。深度、位姿、地图投影、可达性和目标坚持由调用方处理。

- `LocalViewPredictor(model, placement).patches(views, target)` 返回中心图的九个图块。坐标以左上角为原点，横纵坐标分别除以图像宽高。`background_mass` 是地面及其他背景的合计权重，`support` 是当前图块对给定目标的相对支持分。
- `score(views, target, plans)` 接受一至二十四步的实际 Habitat 动作序列（1 前进、2 左转、3 右转）。`route_patch_scores[i][j]` 是第 i 条路线对编号 j 图块的评分。两次调用共享当前扫描的缓存。
- 冻结的 JEPA 根据三视角图像与候选动作预测终点画面的视觉特征，再将该特征和每个当前图块匹配。图块的目标摆放支持分来自 HSSD 训练房屋。分数用于候选排序，可用性由导航闭环实验判定。
- `collect_surfaces.py` 仅在 HSSD 指定训练房屋采集 RGB 及支持面标签。家具使用已知模型语义，结构墙和地面使用建筑几何及深度平面法向。混合标签中心低于 60% 共识的图块不进入训练。家具采样和随机位置采样同时进行。
- `fit_surfaces.py` 在预先排序的前八栋训练房屋训练 RGB 图块读出，在后四栋独立训练房屋比较其与冻结文本提示的总体准确率和类别平均召回率。两项指标均提高才选用训练后的读出。类别平均召回只纳入至少有十个验证图块的类别。导航策略推理只使用 RGB。
- `surface_validation.json` 记录训练/检查房屋、类别频次、混淆矩阵和权重哈希。`visual_contract_training_v2.json` 记录训练屋上的换路、换目标、计划排列和空白输入检查。`local_vision_v1.py` 保存文本提示版本。
