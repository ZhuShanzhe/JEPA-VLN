# 新建筑上的实例靠近评测

8 栋房屋、8 类目标，每种方法每栋执行 300 个动作。达到两实例要求的房屋数为上一版 **3/8**、局部观察位版 **1/8**。累计靠近的不同实例数分别为 **10 个、6 个**。

## 房屋与计分

使用 StopWatch 发布的 HSSD-OV 验证回合和实例观察机位。43 个验证场景中，排除本路线既有评测、训练、校准和采集记录后有 19 个场景编号。再按房屋编号第一个下划线前的部分归组，排除开发房屋的其他楼层或布局，以及已登记的训练/开发划分，剩余 16 个候选。依照预先固定的类别顺序与回合编号哈希选取 8 栋不同房屋，每屋至少有两个目标实例的官方机位从起点可达。策略得分不参与筛选。首轮按完整场景编号选的面板保存在服务器上，以下结果统一使用建筑分组后的面板。

8 栋房屋和局部观察位模型的训练、模型检查均按编号前段隔离。此前独立的 FGPrompt 图像地点基准曾评过 HSSD 的全部 43 个验证场景。本面板用于衡量本路线在开发时未用过的建筑上的表现。随 StopWatch 发布的 HSSD 实例评分机位仅覆盖验证划分。

两版使用相同的起点、朝向、种子、RGB-D、诊断位姿与动作预算。每抵达距某实例任一官方观察机位的可通行最短路距离严格小于 0.25 米的位置，该实例记一次。0.5 米和 1 米只用于分析靠近程度。上报正确率、实例重新识别、看清物体的朝向和完整 MOST-Nav 任务成功率均需另行测量。8 个起点在计分半径内的目标数均为零。

| 目标 | 上一版靠近数 | 局部观察位版靠近数 | 已知地图和真值机位时接近两个实例所用步数 |
|---|---:|---:|---:|
| 挂画 | 2 | 1 | 25 |
| 台灯 | 2 | 1 | 65 |
| 床 | 0 | 0 | 145 |
| 植物 | 0 | 1 | 100 |
| 架子 | 0 | 0 | 127 |
| 凳子 | 1 | 0 | 136 |
| 扶手椅 | 0 | 0 | 99 |
| 柜子 | 5 | 3 | 35 |

正对照使用完整可通行地图和目标实例机位，验证 8 栋房屋都存在 300 步内可执行的路线。两版策略在决策过程中只看到各自已经探索到的环境。

## 动作与观察位

上一版在 164 次决策中做了 160 次路线选择，另有 4 次没有可用候选。按冻结脚本每轮扫描固定花费 4 个转向动作，合计 656/2400 步。新版有 242 次决策，其中 22 次根据新位姿继续驶向原观察位，跳过重复扫描。其余扫描累计 880 步，区域移动 977 步，局部移动 534 步，空动作转向 1 步，回合末补齐 8 步。两版出现碰撞或前进不足的次数分别为 41 次、31 次。

新版实际选出 58 个局部机位，50 个持续了至少两次决策，51 个收到实地到位回执。局部阶段的 534 个动作包括 195 次前进和 339 次转向。与真实目标机位匹配后，局部候选覆盖 7 个实例，选中的机位覆盖 6 个，实际抵达的局部机位覆盖 4 个。各阶段按实例去重，同一实例可出现在多个阶段。

## 文件与核验

| 文件 | 内容 |
|---|---|
| [panel.json](panel.json) 和 [eligibility.json](eligibility.json) | 冻结场景、回合、类别、动作预算、源文件哈希及几何筛选记录 |
| [family_exposure.json](family_exposure.json) | 建筑编号排除清单、可选房屋及独立历史基准覆盖情况 |
| [panel_lock.json](panel_lock.json) 和 [local_lock.json](local_lock.json) | 上一版策略、局部策略、模型和评测依赖的内容哈希 |
| [paired_public.json](paired_public.json) | 两臂逐屋靠近数、首次到达步数、动作预算与局部决策漏斗 |
| [oracle_control.json](oracle_control.json) | 使用真实地图和目标机位的独立几何正对照、轨迹复算结果 |
| [paired_audit.py](paired_audit.py) | 核对冻结清单、步骤、计分、实际动作与目标保持记录 |

在此目录运行 `python paired_audit.py . --public-only` 可从公开的逐屋记录验算主表和动作数。完整审计使用服务器上的冻结模型、原始运行记录及逐决策日志，运行 `python paired_audit.py .` 会核对 16 个结果、4800 个动作，并重新生成 [paired_public.json](paired_public.json)。原始仿真需要相应场景资产与 Habitat 环境。完整审计会读私有日志，公开汇总只保留按房屋、类别和阶段统计的结果。
