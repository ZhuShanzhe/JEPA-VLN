# 多实例寻物中的局部观察位

在 8 栋按建筑排重的 HSSD 房屋中，每种方法各执行 300 步。上一版在 3 栋房屋靠近至少两个不同实例，新版在 1 栋做到。新版选定的 58 个观察位有 51 个实际抵达。执行能持续朝指定位置推进，选点对寻找第二个实例的收益仍然有限。[配对结果](eval_family/paired_public.json) · [分阶段诊断](eval_family/decision_summary.json)

## 从选区域到选观察位

1. 上一版的摆放先验、探索记忆和路线证据评分共同选择一个区域。机器人实际进入已选位置周围 1 米范围后，使用新拍的图像判断该区域内值得靠近的表面。
2. 冻结的视觉编码器读取相机图像。在中心图的九个重叠图块上，一个经过训练的分类头识别墙、桌、柜、床等表面。系统结合目标类别与表面摆放先验，在已观测地图上生成能走到、能看向该表面的观察位。冻结的 JEPA 根据候选动作预测终点视觉特征，用其与当前图块的相似度及目标支持分排序。[视觉模块及验证](localvision/README.md) · [可达机位生成](waypoints/observation_sites.py)
3. 被选中的观察位以地图坐标和朝向保存。每次最多执行四个动作，然后用实际位姿和新地图重新规划。新证据显著更强、视线丢失或路径受阻会触发改选。走到目标 0.18 米内、朝向误差不超过约 15 度且视线仍通，才记一次观察位抵达。[决策记忆](local_search.py) · [共同运行接口](local_runtime.py)

## 300 步配对结果

八个回合使用 StopWatch HSSD-OV 原始起点与实例观察机位。两版获得相同的 RGB、深度、当前位置和朝向，每次前进或转向都占一步。主要指标为沿真实轨迹进入某个实例任一合法观察机位的可导航距离 0.25 米内，每个实例每回合只计一次。起点已达实例数均为零。该测试评价物理靠近能力；检测、身份确认和主动上报另行评测。[清单与验收](eval_family/README.md)

## 日志给出的原因

- **位置能记住，也能走到。** 50/58 个观察位跨至少两次决策保持坐标和朝向，31 个跨至少三次。51 个实际抵达，3 个因更强的新证据改选，3 个因受阻或停滞释放，1 个在预算结束时仍未完成。抵达的观察位合计覆盖了 4 个真实实例的合法机位。
- **六个实例的首次靠近都发生在区域移动段。** 将实例首次命中的步号与执行日志逐步对齐，画作在第 128 步、台灯在第 110 步、植物在第 165 步，三个柜子分别在第 90、128、180 步首次进入门槛。局部移动随后也覆盖了其中五个。这描述本次实际走过的路线，局部决策可能影响之后的区域选择。
- **有些区域从一开始就缺少有效机会。** 床、架子和凳子三个回合，沿新版实际路线生成的局部观察位中，没有可评分候选进入任何目标合法机位的 3 米范围。扶手椅回合出现过一个能贴近实例的候选，排序后选中的位置错过了它。这里对候选使用在线平面坐标和当时楼层高度做事后几何核对，实际靠近成绩始终使用模拟器中的真实轨迹。
- **视觉模块偏向墙面，重复获取方向证据也有代价。** 58 次选点中有 39 次选择了被识别为墙的图块。训练域独立检查中，墙面召回率约 79%，桌子只识别对 1/27 个图块。局部执行的 534 步里有 339 步在转向。新版扫描比上一版多花 224 步。两项现象可能减少换房间和寻找第二实例的机会，各自的因果影响需要单独对照。
- **步数在物理上足够。** 独立的完整地图诊断使用真实目标机位，8 栋房屋都能在 25–145 步内靠近至少两个实例。对在线策略而言，仍需从有限观测推断应该搜索哪个区域。[几何正对照](eval_family/oracle_control.json)

当前证据支持把持久观察位保留为局部执行能力。默认的 300 步探索继续以上一版为对照。局部精查更适合已经看到与目标相关、且可能属于新实例的线索时启动；证据只支持“这里有墙”时，把动作留给下一个区域。

## 宿主接入

原版 MOST-Nav 的探索入口能调用相同的局部决策。使用真实 HM3D RGB、受控地图与估计位姿核验了连续选点、原生 FINISH 抢占和地图尺度变化后的记忆清空。该接口缺少对齐的米制深度，使用观测地图中的障碍方向近似定位线索。完整原版 MOST-Nav 的端到端成功率需单独测量。[宿主检查](host_validation_trained.json)
