# 走过门口后的房型转换修正

当一条计划经过门口或转角，预报需要兼顾“继续处在当前环境”和“进入新房间”。轻量网络从起点三视角特征、当前房型读取、原 JEPA 房型预报和计划动作计算变化概率及目的房型。训练时只读取 40 栋训练房共 9,332 个起始和未来均可确定房型的时刻，其中 4,943 个主视野房型确实改变。按房屋等权抽样，均衡四个预测时刻和各时刻变化、未变化样本，增加少数目的房型的抽样权重。使用三个随机种子，每次训练 400 步。

第一种修正将当前环境分布与预测的目的房型按变化概率混合。第二种保持原路线预测为基础，只对目的房型作有界对数分数修正。两者均训练变化事件与目的房型，运行时只用已观测 RGB 和名义动作。校准用另外 6 栋房的 1,500 个有效时刻，其中 847 个变化。修正取得部署资格需改善变化帧的 Brier 分数，并且全帧 Brier 回退不超过 0.002；随后按全帧与变化帧 Brier 等权选择检查点与融合比例。

| 六栋校准房，房屋等权 | 全帧 Brier | 变化帧 Brier | 未变化帧 Brier |
|---|---:|---:|---:|
| 原 JEPA 环境预测 | 0.5695 | **0.6159** | 0.5288 |
| 变化概率混合，250 步、融合 20% | 0.5635 | 0.6174 | 0.5141 |
| 有界目的房型修正，250 步、融合 20% | 0.5667 | 0.6174 | 0.5208 |

两种修正都能在部分配置下提高全帧平均表现，但没有候选同时满足变化帧和全帧的条件，两个校准结果均选择融合系数 0，部署使用冻结的原 JEPA 房型预报。没有将这两项修正产生的结果用于新房导航评分。优先补相同门口开口、转向之后通往不同房间的训练对，并增加能区分“正面看见家具”和“即将走进家具所在房间”的标签。
