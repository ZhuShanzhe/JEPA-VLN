# 兼顾后续探索的路线价值

短路线可能只是通道，走完下一段以后才会看到目标。长程部件给环境选路头的分数加上一项有界修正，估计这条路线能否为后续探索打开机会。当只剩一段可走时，修正严格为零。

训练取 12 栋 HSSD 训练屋的 48 个起点。每个起点实走 4 层三分支树，按原始隐蔽任务和整棵树的实例记录重标了 460 个查询，其中 172 个在至少一个可行分支中实际出现。每次分岔考虑所有仍有预算的 2 至 4 段探索，扣除已经沿当前路径看到的实例，按配额截断增量收益。每次往下一层回传时，80% 权重给三个后续方向的均匀期望，20% 给最优后续方向的收益。全零或三个方向收益完全一样的查询不提供排序梯度。最后得到每个种子 1,691 个有区别的“分岔、目标、剩余预算”条件。

两个训练臂都读取当前目标在各房型的布局频率、该臂自己预测的候选环境、当前和此前已访问分岔的 RGB 环境与目标线索、动作方向、距离及剩余预算。在每个分岔内部先作中心化，再用按房屋等权、带正则的拟合学习相对价值；模型全程只处理本回合已经取得的观测。早期进入新区域的后续价值由训练树提供监督，测试时不会查询未走分支。

| 校准开发指标，112 步 | 原环境头 | 加长程价值 |
|---|---:|---:|
| JEPA，达到的目标数占配额比例 | 7.15% | 13.00% |
| 同输入直接监督 | 7.35% | 13.54% |

表中仅含目标在房屋中存在的查询，按房屋等权；校准策略连续走四段，不加下游外部在线记忆。两臂都从含零的强度网格中选出 1.5。该用途是冻结强度，独立新屋的实际搜索成绩另列于项目总报告。[训练回执](training_receipt.json)
