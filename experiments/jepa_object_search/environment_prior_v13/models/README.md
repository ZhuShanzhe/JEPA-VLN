# 预测沿路环境并据此选路

模型把两件事分开学习。训练房屋里，每类房间实际出现指定物体的频率构成先验，例如卧室有床的平滑概率为 94%，客厅有沙发为 86%。探索时输入目标词、当前三个方向的 RGB 和候选动作，预测选每条路之后将看到哪些环境，再把环境分布和目标先验结合起来。方向由候选动作在当前朝向下定义。

| 部件 | 如何工作 |
|---|---|
| 已观察环境的读出 | 冻结 RN50，提取整幅及左右局部的 RGB 特征，在 40 栋训练房屋的 11,919 张有房型监督的图上训练小网络。输出 12 种房型的软概率供在线记忆使用。仿真语义和房屋清单仅在构建监督时使用。 |
| 路线环境预测 | 读取起点三个方向和前进、转向序列，分别预测路线 1/4、1/2、3/4 和终点的环境概率。在 HSSD 中对应第 6、12、18、24 个动作。老师给出朝向所能看到的各类房间比例；缺少视野证据时才使用相机所在的已知房型。 |
| JEPA | 小网络同时预测四个时刻的实际未来 RGB 潜特征。余弦相似度损失对齐实际未来，另一个损失要求同起点的候选路线在预测空间保留各自的视觉差异。未来的图像只参与训练。 |
| 目标选路 | 取预测房型分布与目标先验的点积，得到预期的房型适合程度。把它与文本匹配、路线外观和动作特征交给打分头，再加上可用的回合内记忆。先验表示训练房型内存在该类别的频率；房间内的可见位置、距离和遮挡仍由路线样本提供监督。 |
| 同预算比较 | 直接监督臂同样能学房型和目标发现，使用相同网络、相同标签、相同批次与种子，仅去掉未来视觉表征对齐。旧 V11 单列。另计仅采用预期房型适合度、不使用成功打分头的分数。 |

三种子各训练两个头，以 6 栋校准房选择更新次数和新旧头的融合权重。两臂均选择 180 次更新、100% 新头。此前未用的测试房屋与下游长程结果不参与选择。[冻结配置和权重摘要](selection.json)

| 仅用于开发的校准指标 | JEPA | 直接监督 | 参考 |
|---|---:|---:|---:|
| 选择一条 24 步路线获得目标观察机会 | 51.65% | 51.71% | V11 为 44.18% |
| 仅用“预测环境 × 先验”选路 | 49.38% | 49.08% | 三条路线从同一位置出发 |
| 预测整条路线主要看到的房型 | 33.40% | 34.01% | 复制起点相应朝向为 26.85% |

直接观察一张 RGB 后判读主要房型的校准准确率为 43.59%，仅猜训练中最常见房型为 14.21%，按房屋等权。远处房间和相邻开放空间的归属仍有歧义，实时接口保留软分布。以上数值衡量模型和选择流程在校准房的表现，系统测试结果另见项目总报告。[单房核对与环境预测统计](diagnostics.json)

[推理接口](env_routes.py) 的 `live(rgb,target,plans)` 返回各策略分数、三条路径的环境预测、目标先验和当前三视角目标线索。`observe_batch(rgb,target)` 只读取已经实际获得的画面，返回每帧的环境分布和目标线索，供下一次决策更新记忆。`cached` 接受原冻结编码器的观测特征。6 栋校准房均已检查实际 RGB 与缓存两种调用的分数一致。[训练程序](train_routes.py) · [复核程序](check_environment.py)
