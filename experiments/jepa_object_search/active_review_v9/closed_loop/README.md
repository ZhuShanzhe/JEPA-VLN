## 主动补看与正式报告

原导航器处于正在跟随探索路线的状态时，原生碰撞恢复、目标导航、扫描、上报和结束具有优先权。常规探索每隔至少三步检查一次，已经启动补看时允许在下一帧立即复核。用最近一次前进后真正看过的方向计算单帧或相邻两帧特征。当前相机与训练相机通过已知姿态和视场角校正。一个补看动作以 30° 转头获取下一帧，在同一处最多两步。没有复核时逐步恢复原朝向；若上层先改变决策，直接交还控制。两类开销均消耗 300 步中的动作。每回合额外补看动作最多 12 次、原 VLM 复核最多 6 次，同一轮补看之后的冷却为 12 步。复核阈值为 0.92。

共在 160 个决策时刻评分，独立回放发现其中 17 个时刻处于至少一个尚未报告的指定实例的合格视点范围。实际主动转头 22 步，恢复朝向 21 步。在补看时已具备未报实例的合格位置共 1 步，转向后最多目标像素数增加的有 0 步，从小于 103 个目标像素跨到至少 103 像素的有 0 步（320×320 语义图，仅用于回放）。辅助头请求额外复核 1 次，其中在未报目标合格位置 0 次。同一步新增记入 0 个实例；随后六步内出现相同实例的新增报告共 0 个复核窗口。上层返回情况为 GOTO_INSTANCE 1 次。

当前在线训练组件使用类别词。白门和风景画由门、壁饰这两类筛选补看机会，原 VLM 接收完整原始目标。该版本未向辅助头传入经过实例核对的历史裁剪图，既有实例报告及去重由官方组件管理。上述回合是已有困难案例的开发对照；跨回合命中差不能独立归因于一次补看动作。
