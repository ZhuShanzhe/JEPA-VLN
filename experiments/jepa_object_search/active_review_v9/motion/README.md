# 四步短程复核路线

从同一张当前 RGB 和同一目标出发，比较原地补看、斜向走两步再回正、直行两步再补看。L、R 分别为转向 30°，F 为前进 0.25 米。六条路线依次是 LLRR、RRLL、LFFR、RFFL、FFLR、FFRL。每条实际执行 4 个动作，碰撞消耗原动作预算。整项评测在 HSSD 进行，未增加付费 VLM 调用。

每栋从 V9 已冻结的实际起点按标识哈希次序取 10 个，训练 12 屋共 120 个起点、校准 4 屋 40 个、独立评测另 4 屋 40 个。每个起点每条路线的收益是四步途中首次进入合格报告范围、同时出现足够清晰目标像素的不同实例数。出发时已符合条件的实例排除。清晰门槛与 [V9 复核训练](../models/README.md) 一致。监督覆盖完整四步过程，得分模型只看出发时的单张 RGB、目标和名义动作序列。

评分头用带 L2 正则的线性回归，各自学习同一起点各候选相对平均路线的收益差。只读名义动作的几何头、当前可见证据头、动作条件 JEPA 预测头、联合头使用相同标签。当前证据来自已训练 V9 局部感知模块。JEPA 复用 V8 的冻结稀疏视角预测器，逐个动作前缀预测末端区域特征，与目标词对齐。包括 1 步、3 步在内的短前缀超出了旧路线评分协议常用的 4/12/24 步标定范围。正则强度分别从 0.03、0.3、3 三档在校准房屋选定。先封存独立集的所有评分，再匹配真实标签。最高分并列时各路线平分选择概率。

## 四栋留出房屋

| 选路方式 | 平均每次得到的新合格实例 |
|---|---:|
| 均匀随机路线 | 0.03641 |
| 训练房平均最优的同一条路线 RRLL | 0.03310 |
| 只用名义几何的训练头 | 0.03310 |
| 按名义终点位移选路 | 0.03951 |
| 当前观测辅助头 | 0.03842 |
| JEPA 预测头 | 0.03253 |
| 联合头 | 0.04036 |
| 联合头换错目标词 | 0.03443 |
| 联合头将未来替换为不随动作改变的已观测特征 | 0.04496 |
| 使用真实未来的最佳路线 | 0.09719 |

每个物理起点先平均该屋有可核查实例的查询，再平均起点和房屋。490 个起点与查询组合中，443 个在六条路线上全部为零，47 个存在路线差异，分布于 24 个起点。20 个组合中最好的带前进路线优于两条纯转路线，13 个组合则以纯转更好。相同起点上，几何路线不能确定最值得看的方向。联合头略高于仅观测头的均值，但移除预测变化后更高。现有数据未证实复用 JEPA 的短程预测带来额外收益。采样以目标附近为主，清晰标签是像素代理，各方法数值均为短程局部机会。本模块未接入五例闭环。

## 复用代码

[motion_features.py](motion_features.py) 按出发时可取得的特征生成六条候选的张量。[motion_fit.py](motion_fit.py) 训练、校准、封存独立预测并揭盲。[results.json](results.json) 含全部物品、官方六类及补充十类的逐屋结果。

提供包含 `words`、`anchors`、`states` 的已观察 CPU 张量缓存。每个状态仅含 `sid`、`split`、`crops`（1×3×1024）、`code`（1×49×64）、`sim`（1×49×16）。运行时指定 V8 核心评分代码路径、V9 代码路径及自有的冻结权重文件。教师目录须提供每分割的 `<split>.plan.json` 与 `<split>.json`，按 sid 关联 6×16 的每路线实例数和 16 维可核查类别标记。每项已有真实场景结果的权重与原始图像保存在授权服务器。

```sh
python motion_features.py --v8-code v8/models --v9-code ../models --v9 v9.pt --full full.pt --sparse sparse.pt --states observed.pt --output run
python motion_fit.py run teacher
```
