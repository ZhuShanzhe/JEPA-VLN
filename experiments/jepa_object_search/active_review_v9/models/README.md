# 主动补看与报告复核 V9

V9 读取当前 RGB、最近一次在同一位置相邻方向取得的 RGB，以及目标词。每次可继续原路线、原地左转 30°、右转 30°，或请求原 VLM 复核。一个补看片段最多花两个原仿真动作。原 VLM 负责最终上报。若宿主传入三张图，预测只用最近两张；若收到该目标的历史报告裁剪，取最近一张计算局部相似度。

## 教师与训练

1. 在 12 栋 HSSD 训练房的 592 个位置各按 30° 左转取得 12 张真实视图。校准另用 4 栋、179 个位置，评测另用 4 栋、191 个位置。该评测面板包含此前选路研究用过的房屋，本次新任务按房屋隔离。采样同时涵盖正式实例视点、其附近偏移位置，以及已有自然起点。主表从目标附近取样较多。
2. 教师核对同一实例的合法报告位置及其在当前画面中的像素。要求至少 192 个实例像素、中央五列格子内至少 32 像素、至少两格各有 12 个像素。监督的是可辨认证据的几何与像素代理，不包含人工属性、真实辨认正确性标签或 GPT 报告结果。
3. 冻结 OpenCLIP RN50，用其已有投影、语义原型和 7×7 个局部特征训练小型感知头，输出类别可见性和 2 米范围内证据。时序头从当前及上一视角的局部证据和方位差，分别预测当前、左转一步、右转一步后得到合格证据的概率。V8 的 JEPA 路线预测器留在探索模块，V9 新训练的是补看与复核模块。
4. 同一房屋中，用先前独立采样的另一位置实际看过的合法实例裁剪模拟历史报告。该实例归为已报告，其他同类实例继续作为正例。训练共有 6,285 个带模拟记忆的起点与目标组合，去掉 1,483 个已报告目标的正视角，保留 4,401 个其他目标的正视角。实际使用裁剪的前提是上层已经报告并能提供对应图像。
5. 种子 91。两个阶段各训练 10 轮，分别使用 AdamW，学习率 0.0015、0.001。校准阶段在 0.10–0.98 的步长 0.02 网格中选阈值，要求精确率至少 65%、至少 12 次触发且正确触发覆盖至少两栋房。在满足条件的阈值中优先保留较高召回率。采用的阈值为 0.92。未达到复核阈值时，若某方向的预测值至少为 0.15 且比当前高 0.03 以上，选择该方向补看。

## 冻结结果

| 四栋评测房 | 复核正确 | 复核错误 | 可达机会 | 机会召回率 | 实际转数 |
|---|---:|---:|---:|---:|---:|
| 主动补看 | 177 | 101 | 3,626 | 4.88% | 24,622 |
| 仅当前视角 | 97 | 66 | 3,626 | 2.68% | 0 |
| 固定方向、最多转两次 | 243 | 159 | 3,626 | 6.70% | 56,555 |

机会以“起点 × 初始朝向 × 目标类别”为单位，同一起点含多个有关联的条件。只统计该屋有可核查目标的类别。28,488 个条件中有 3,626 个在左右两次原地转动范围内存在合格画面；正确触发要求请求复核时图像确实含可报告的新目标。主动补看精确率由校准集 65.96% 降到 63.67%。自然起点子组有 230 个可达条件，正确提示 9 次、误提示 5 次。

| 实际转动预算与学习策略逐条件相同 | 新显露合格目标画面的条件数 |
|---|---:|
| 学习策略，含最近一个已观察方向 | 524 |
| 消去前一视角，使用当前图决定每次转向 | 497 |
| 在该屋可核查类别之间循环换错词 | 444 |
| 固定左转 / 固定右转 | 471 / 495 |
| 等概率选择左或右的期望值 | 483 |
| 可读取真实结果的方向上界 | 935 |

门控在首次获取新证据后正确触发 45 次。按目标分开，灯有 78 次正确、19 次误触发；门为 2 次正确、4 次误触发；钟和镜子均没有触发。画饰有 44 次正确、62 次误触发，模型只识别“画饰”类别，颜色和画作内容需由原 VLM 判断。模拟记忆把只有重复实例的 415 个视角中的误触发从 18 降到 5，同时把仍有新实例的 1,230 个视角中的正确触发从 70 降到 32。

## 运行接口

`v9_live.Assistant(model_dir).score(frames, query, headings, report_images=[])` 接受真实历史、相对于当前的朝向格与已报告裁剪。最后一帧对应 0，上一帧为相邻实际朝向时使用其 −1 或 +1 编码。输出含动作、校准阈值、当前和两个补看方向的分数。规范词未获支持时继续原路线。已训练检查点 SHA-256 见 [policy.json](policy.json)。

使用自有合法资产时，`encoder.json` 提供 `rn50` 及 `projection` 两个路径。后者是含 `words`、`center`、`basis` 与 `anchors` 的 PyTorch 文件，视觉中心和主方向来自原训练的 RN50 投影，文本向量与既有 16 类顺序一致。`v9.pt` 与 `policy.json` 和其同目录。首次重建时，在邻目录 `collection/` 准备按房屋划分的三个 `*.index.json` 及对应的仿真图像、实例像素网格、独立合法视点记录，再执行以下入口。

```sh
python encode_data.py
python fit.py fit
python fit.py blind
python diagnose.py
python route_controls.py
```
