# 分房屋的主动补看训练数据

从每栋房屋每个可核验类别选择至多两个实例。采集器在独立的合法报告视点和随机偏移后吸附到导航网格的位置取样，另加入既有导航任务的自然起点。合法性逐实例重新计算。目标附近的刻意采样提高了正例覆盖，也改变了目标出现率。

在每个位置，朝向从固定随机种子生成，机器人每步左转 30°，保存 12 个连续的 RGB 视图。模型在真实决策时只能使用截至该步已取得的画面。训练教师单独保存每个实例的 7×7 网格像素、2 米内的像素及该位置的报告资格。稳定实例标识由同屋刚体名称排序产生。

| 分区 | 房屋 | 不重复位置 | RGB 视图 |
|---|---:|---:|---:|
| 训练 | 12 | 592 | 7,104 |
| 校准 | 4 | 179 | 2,148 |
| 留出检验 | 4 | 191 | 2,292 |

`drive_views.py` 读取项目的 V8 分屋清单，逐屋运行 `collect_views.py`。需要取得许可的 HSSD、ObjectNav 视点、自建类别视点及自然起点清单。将 `V8_TEACHER_DIR`、`V8_RENDERER_DIR` 指向仓库中 V8 的 `data_tools`，将 `HSSD_SCENE_DATASET_CONFIG` 指向本地 HSSD 配置即可使用对应的场景加载器。索引把可用观察与教师标签分别指向不同文件。`audit_collection.py` 核查房屋互斥、位姿唯一、实例标识、角度序列、像素包含关系及容量。
