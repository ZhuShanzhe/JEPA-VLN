# HM3D 同图候选框比较

在 Habitat 中重新渲染此前固定的两个开发场景。RGB 原始分辨率为 1280×1280，三个候选来源均读取同一张双三次缩放的 518×518 无损 PNG。原生语义相机的分辨率为 320×320，仅用于事后核对。对每个指定实例保存紧贴可见像素的外接框，主评分要求可见面积至少 103 个语义像素。

| 图像来源 | 帧数 | 达到可见门槛的帧数 |
|---|---:|---:|
| 已运行时钟轨迹的登记帧、复看前、复看后 | 3 | 3 |
| 原画作轨迹按时间等间隔选择的四张关键帧 | 4 | 0 |
| 时钟每个指定实例的官方机位列表中等间隔选六处、相机朝向实例中心 | 18 | 7 |
| 画作以相同规则放置相机 | 18 | 10 |

官方机位组解决“已经到过合适位置，框能否覆盖目标”的局部问题。使用实例中心确定相机朝向的特权信息只参与环境摆位。目标出现的位置和语义标注不输入模型。两个场景合计 43 张图，原轨迹和目标导向机位分别报告。

统一比较以同一免费图文模型排列三个来源各自的候选框。在时钟专题中，另记录全体候选中能达到的最佳语义外接框重叠、固定第一名的重叠以及框内覆盖的语义像素比例。墙、门和其他物品也可进入原生 SAM 候选池。

**时钟语义标注存在跨物体的连通分量。** 对三个历史机位叠加 RGB 和对应原始语义 ID，发现同一数值既出现在挂钟表面，也出现在远离钟面的木质台面上。两个相机世界位置和朝向完全对齐，水平视场角均为 120°。终点的 17,968 个同 ID 像素中，前景台面单独占 17,063；钟处两个分量合计 905，Grounding DINO 的首选框覆盖其中 901 个。登记帧里，该框覆盖钟处全部 76 像素，其他 189 像素来自另一分量。此前“仅覆盖 5.01%”以全部同 ID 像素为分母，不能用于判定检测器只框到钟的一角。三个方法在此终点的首选框在 RGB 中都覆盖可见钟面；匹配/上报仍可能因为跨视角外观等原因无法通过。暂不据此推断其他时钟的标签情况。[相机与分量审计](alignment_audit.json)

采集输入、图像、逐帧候选和标注只保存在项目私有数据盘。两幅私有示例按规则固定选择时钟复看终点和官方机位序列中首个达到可见门槛的画作正例。同一帧上分别标出真值和三个方法的首选框，研究人员可在项目内检查。
