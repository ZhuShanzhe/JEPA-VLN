# 参考框会不会改变复看机位的选择

在 HSSD 的 16 栋留出房屋固定 288 张图，沿用已冻结的局部 JEPA 和直接监督机位评分头。每组三张同一场景、相邻机位的实拍仿真图，任选一张作为登记图，在另外两个机位中选一个。在同一实例上把登记图中的 Grounding DINO 框替换为标注框，同时固定像素、相机运动、候选机位、评分权重。以下结果只衡量选择哪个附近机位可以再次看到该实例。

**338 次可正确关联的源框。** 661 次标注目标出现中，按同类、一对一 IoU ≥ 0.50，检测框与参考实例能匹配的有 338 次。该部分比较向两个模型提供同一个已匹配框，相当于预先知道哪个框属于目标。终点评分分别用同实例的合格仿真标注以及本地检测器对该实例的匹配。

| 起始框 | 机位头 | 选择后标注仍可见 | 同一终点检测器重新找到 |
|---|---|---:|---:|
| DINO 框 | JEPA | 317/338 | 285/338 |
| DINO 框 | 直接监督 | 316/338 | 283/338 |
| 标注框 | JEPA | 316/338 | 281/338 |
| 标注框 | 直接监督 | 316/338 | 284/338 |

替换参考框使 JEPA 改选 22/338 次，直接监督改选 15/338 次。以仿真标注为判据，JEPA 的总体命中数少 1，直接监督持平。按房屋等权，JEPA 的可见率变化为 −0.45 个百分点，按房屋成对重采样所得 95% 区间为 −1.49 至 +0.42。338 次中只有 27 次的两个机位具有不同的标注可见性，在这些确实能区分机位好坏的样本里，JEPA 的命中随替换从 20/27 变为 19/27，直接监督两者均为 19/27。

终点使用检测器计分会漏掉一部分实际可见目标。DINO 参考框下，JEPA 选中的 317 个标注可见终点中有 32 个未被重新检测。若只用终点检测器计分，两种方法相差极小的排名随参考框选择从 JEPA 多 2 次，变为直接监督多 3 次。机位取得目标视野的能力宜用仿真可见性作主指标；检测器复检率另外反映“到位后能否把框交给后续模块”。

**另外 323 次初始漏检或框未达门槛。** 固定同样的替代机位，注入特权标注框后，JEPA 与直接监督各有 268/323 个所选终点有同一实例标注，但各自只有 38/323 个能被冻结检测器匹配。这批目标在源图就缺少正确关联的检测框，本组数字用于揭示样本选择和终点计分的影响。实际自主运行是否会登记这些实例仍取决于提框、送审和记忆。

项目中常规探索头和主动复看头有不同的输入。普通前沿排序读取多个方向的 RGB、目标类别、候选计划和历史，将报告回执用于更新记忆；本实验只替换主动复看头读取的源图区域。整回合中的提框错误可能经登记、复看和报告历史间接影响探索，单次机位对照无法估计整条路线的累计损失。HSSD 合格语义标注能衡量此处目标是否在画面中，不能证明实例可被识别、机器人已到官方合法距离或已完成报告。
