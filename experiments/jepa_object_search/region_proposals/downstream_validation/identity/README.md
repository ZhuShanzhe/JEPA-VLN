# 选框对跨视角实例确认的影响

从同一房屋的两张同类别 RGB 中，用第一张图登记某个物体，在第二张图确认是否仍能找到同一实例。保持 RGB、实例、外观参考编码和现场确认器固定。四组分别替换登记方框及当前图的同类候选框。标注框只作为离线输入干预，不进入导航系统。

HSSD 的 16 栋留出房屋包含 288 张图。按房屋、拍摄序列、机位排序，以顺序在前的图为登记图；只采两图类别相同、当前图有合格同类标注的组合。根据登记实例能否在当前图的合格标注中找到，分为同物可见和仅标注其他同类两组。在看匹配结果前，以固定散列在每屋每组最多取 12 对，得到 192 和 179 对。采集中的小面积或低可见度实例可能不构成合格标注，因此第二组不能代表所有现实负例。多个图对可来自同一物体和同一房屋。另复跑既有 32 对固定样例，得到相同选择哈希和相同基准计数。

真实登记条件要求 DINO 源框与唯一实例标注 IoU 达到 0.50，选择首个唯一对应所问实例的原检测框。没有对应框时按缺少可用登记参考计入暂缓。这个对照给予真实检测器理想的源框选择，未引入 VLM 本身选错候选的误差。标注登记条件使用该实例的可见外接框，标注当前条件提供当帧所有合格的同类别标注框，身份编号对确认器不可见。保留现有 `build_reference`、`match_reference`、`eligible_boxes` 和 `current_support` 的全部参数。确认后用 IoU ≥ 0.50 且能唯一对应标注的规则判断身份，其余支持框标作无法核实。

| 登记框 → 当前图候选 | 同物可见的 192 对：正确 / 错认 / 无法核实 / 暂缓 | 仅其他同类有标注的 179 对：错认 |
|---|---:|---:|
| DINO → DINO | 29 / 0 / 1 / 162 | 0 |
| 标注 → DINO | 35 / 1 / 3 / 153 | 0 |
| DINO → 标注 | 34 / 2 / 0 / 156 | 0 |
| 标注 → 标注 | 49 / 1 / 0 / 142 | 1 |

两端使用标注框，正确匹配率从 15.1% 升至 25.5%，提高 10.4 个百分点。以房屋为单位成对重采样，95% 区间为提高 5.2 至 16.1 个百分点。逐对结果中，原本暂缓的 22 对变正确，原本正确的 2 对变暂缓。192 对中有 73 对在登记图缺少可唯一对应的 DINO 框。即使给两端标注框，仍有 132 对返回没有当前实例外观匹配，另有 10 对因匹配不唯一或参考框横跨图像两侧而暂缓。标注框干预测量输入质量和框覆盖率怎样影响同一个识别器，外观匹配器看到不同裁块后会改变输出；因此它不构成每个样例的数学上限。

| 两图内是否均有与该目标唯一对应的 DINO 框 | 图对 | 真实框正确匹配 | 两端标注框正确匹配 |
|---|---:|---:|---:|
| 两端均有合格框 | 98 | 29 | 32 |
| 至少一端缺少合格框 | 94 | 0 | 17 |

20 个净增的正确匹配中，17 个来自至少一端缺少合格框的图对。两端都有合格框的子集中，按房屋等权的正确率差 95% 区间为 −1.7 至 +9.0 个百分点。该子集适合固定同一框后比较识别方法，但 29/98 的真实正确率表明仅靠合格框不能解决跨视角识别。合格框按研究标注核验，实际部署时无法用真值来筛选。

原有 32 对样例的 16 个同物正例均以已有可对应的检测框登记。真实框正确 5/16，两端标注框正确 4/16。实际部署时参考框也可能缺失，仅看这个小面板会掩盖框可得性的影响。固定实际或固定标注裁框可以比较两个下游算法；面向真实输入的身份确认效果需要同时保留漏框、误认与暂缓数。这里测量的是报告前的单次局部视觉判断，没有执行选路、几何距离审核或最终报告。
