# 已运行场景中的换框对照

时钟使用冻结的登记机位、靠近前和靠近后的 RGB。参照框取自先前独立查看可见钟面的单名 AI 视觉审阅，逐帧标注在查看候选前已固定，用于排除该场景语义标签同时覆盖木台面的干扰。对登记图分别使用真实历史框和可见钟面参照框，对新图分别使用 DINO 全候选和可见钟面参照框。四种组合均调用相同的现有实例外观确认器。

| 时钟图像对 | 四种框输入组合通过数 |
|---|---:|
| 登记原图对自身 | 4/4 |
| 登记图对靠近后新图 | 0/4 |
| 靠近前的图对自身（检测源框或参照源框） | 4/4 |
| 靠近前的图对靠近后新图 | 0/4 |

跨视角暂缓均返回 `no_current_instance_match`。这些是同一案例的干预条件，不是四个独立回合。参照框已足以包含该钟面，替换框仍不能恢复匹配。

画作从同一场景的 18 个固定、朝向目标的机位中，取所有能构成对照的有方向图像对。10 张图有达到 103 个语义像素的指定实例。配对按源帧所见指定实例逐一构造。正对要求同一身份在两张图均达可见门槛。负对要求新图只有其他指定实例达门槛，原实例一个语义像素也没有。VLM 自由选区未参与这项物理视角对照。

| 画作登记图 / 当前图 | 正确确认 / 32 个同物图像对 | 错误放行 / 58 个异物对照 |
|---|---:|---:|
| DINO 经固定排序的首框 / DINO 全候选 | 7 | 0 |
| 指定实例参照框 / DINO 全候选 | 7 | 0 |
| DINO 首框 / 场景参照候选 | 6 | 0 |
| 指定实例参照框 / 场景参照候选 | 8 | 0 |

当前图的场景参照候选包含该图达到门槛的全部任务实例，不传入身份。替换会同时修正漏框、背景假框和边界。固定首框与源帧实例参照的含义也不同。所有对照复用同一场景的机位，不能用 32 个图像对估算 32 个独立场景的效果，或将单图外观确认率当作任务完成率。
