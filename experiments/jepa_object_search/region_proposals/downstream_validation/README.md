# 选框对选路和实例确认的影响

**现有 Grounding DINO 可以作为固定的输入继续做模块比较。评估所有目标的发现率、跨视角确认率或很小的方法差异时，只用检测框会改变结论。** 同一批仿真 RGB 分别使用实际检测框和标注参照框，保持模型权重、两端观测和可选机位一致。所有运行均在本地模型上完成。

## 自动框能找回多少目标

HSSD 的 16 栋留出房屋有 288 张测试图，244 张包含达到标注门槛的查询类别目标，共 661 次实例出现。同一个物体出现在多帧时会分别计数，框与实例外接框的 IoU 至少为 0.50 算命中。

| 问题 | 实测结果 |
|---|---:|
| 每张有目标的图片送审最多三个框，至少有一个正确框的图有多少 | 210/244（86.1%） |
| 启用已训练的源图类别筛选后，实际输出的首框有多少正确 | 180/235（76.6%） |
| 用全部 DINO 候选，能覆盖多少个实例出现 | 338/661（51.1%） |
| 用全部候选，框占画面 ≤2% 的小目标能覆盖多少 | 67/303（22.1%） |
| 其他大小的目标能覆盖多少 | 271/358（75.7%） |
| 同一物体在两个视角均可见，两个视角均有匹配检测框的比例 | 273/576（47.4%） |

前三个框用同一个冻结 CLIP 排序，不使用正分门槛。可选的源图筛选使用项目中已有的定位质量门槛，每帧最多交一个框，二者分母不同。在 244 张正例图中，32 张即使看完原检测器的所有候选也没有正确框，另有 2 张正确框排在前三之外。类别框的命中不代表指定属性、颜色或实例身份已经核对。[分层、误推和送审结果](selection/README.md)

## 换框后，哪种结果会变

| 相同图像和模型上的对照 | 使用实际框 | 换入参照框 | 能支持的判断 |
|---|---:|---:|---|
| HSSD 复看机位。按场景标注统计所选终点能看到同一目标，JEPA / 直接监督 | 317/338、316/338 | 316/338、316/338 | 在起点已框准的样本上，源框边界对整体命中数影响小。两个备选终点仅有 27 组在真实可见性上不同。 |
| 同样的复看机位，改用检测器在终点能否再次检出计分，JEPA / 直接监督 | 285/338、283/338 | 281/338、284/338 | 更换源框，方法排序翻转。实际框下 JEPA 选出的终点有 32 次目标已可见但检测器未计中，不宜把检测输出当作唯一裁判。 |
| HSSD 现有确认器，192 对同一实例均有标注的图像 | 两端 DINO，正确确认 29/192 | 仅登记框换参照为 35/192，仅当前候选换参照为 34/192，两端都换为 49/192 | 两端换框提高 10.4 个百分点（按屋配对重采样，95% 区间 5.2 至 16.1）。框会影响确认率。换框后仍仅约四分之一正确，另有匹配问题。 |
| HM3D 时钟，已登记小图对靠近后的新图 | 暂缓 | 登记框、当前框分别换入可见钟面参照或两端都换，均暂缓 | 这一个已复核时钟的失败仍发生在跨视角确认。 |

HSSD 机位对照的 338 组均要求已用事后标注确认 DINO 源框匹配，另外 323 次目标出现未进入这个条件比较。身份确认的 192 对正样本从各屋固定抽取，保留缺框情况。两端原先都框对的 98 对，正确确认从 29 增至 32；至少一端缺可靠框的 94 对，从 0 增至 17。因此 20 次净增中，有 17 次来自后一组。另有 179 对仅标注到其他同类实例，DINO 两端条件全部暂缓，参照框两端条件误认 1 对。源端 DINO 采用事后可唯一关联的真实候选，当前端参照候选包括全部合格同类实例，目标身份不输入匹配器。该干预同时改变候选是否存在、边界和可混淆候选，不能单独用它测边界回归的贡献。[机位选择](route/README.md) · [身份确认](identity/README.md) · [时钟与画作现场对照](hm3d/README.md)

**自动画框和上层选掩码是两条不同入口。** 逐一核对时钟的 6 张归档候选图、帧号、掩码编号及选区回执。3 次上层选区请求中，有 4 个返回候选可追溯到当时明确点选的同帧菜单项。四张图都能看见主挂钟，但四个掩码都覆盖墙面，把钟面留在掩码外。另两个候选未能对应到同帧的显式菜单选择，其中一个确实框中挂钟并被登记，另一个指向右侧小物，任务身份无法核实。画作的 5 个候选则都来自没有指定画作的两张图。时钟的记录证实了实际选区错误，这两例不足以估计上层选区的一般准确率。[实际选区核对](selection/README.md) · [完整回合的候选交接](../../pose_instance_memory/active_confirmation/README.md)

## 后续模块的对照口径

- **未知区域的探索选路。** 缺线索时比较同一起点、记忆、候选路线与动作预算，事后用仿真标注判断新出现的目标。单次探索评分直接读取全景和动作；整回合中，框会经由登记、记忆和上报间接改变后续探索。
- **已见目标的主动复看。** 给 JEPA 和直接监督同一组实际起始框与候选机位，分别记录所选终点的标注可见性和实际再检出。另列起点没有可靠框的目标数，避免只在容易的目标上作结论。
- **跨视角身份确认或整机报告。** 保留真实框下含漏检的全样本成绩，再列两端框均正确的受控成绩及两端参照框干预，用来区分检测损失和匹配损失。正式导航仍按真实输入和原任务裁判计分，参照框只用于离线诊断。
