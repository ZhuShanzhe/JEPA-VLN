# 原版 MOST-Nav 候选区域

调用已获许可的 MOST-Nav 代码中实际部署的 `MappingServer._vggt_frame_grid` 和 `SAMRefiner.segment_all`。原版分割权重为 SAM ViT-H，输入 RGB，不读取目标类别、目标位置或另一视点的图像。关键帧按原建图服务的方式缩放至宽 518 像素。SAM 对整帧采样，保留面积占画面 0.2% 至 55% 的掩码，按面积递减最多提供 24 个。输出沿用同帧的原生区域编号、面积、质心和预测 IoU，并将候选框换算为原始 RGB 的半开区间像素坐标。SAM 的预测 IoU 表示掩码质量，不是它属于目标类别的概率。

在 HSSD 的 16 栋留出房屋，使用同一套仿真中实际拍摄的 288 张冻结图，和读取目标类别的 Grounding DINO 三视图配置比较。在 HM3D 上重新渲染了 43 张图，复用同一原版模块。两个数据域的单帧提案都不调用上层 VLM，只有在确认所有图像均完成推理后才计分。

| 文件 | 用途 |
|---|---|
| [原生候选接口](native_regions.py) | 恢复原版像素网格并调用官方权重，返回原始 RGB 坐标。 |
| [批量提取](extract.py) | 按冻结清单提取候选，保存私有校验缓存。 |
| [完整候选池评分](proposal_coverage.py) | 使用 IoU ≥ 0.50 的一对一匹配，计算所有候选中有没有能覆盖该实例的框。 |
| [固定小样过滤检查](cap_audit.py) | 每栋留出房屋按冻结帧编号取第一张，在指定小样内区分生成阶段、面积过滤和截断至 24 个候选的影响。 |

完整候选池评分的分母是图片中的实例出现次数，同一物体在不同图像中可以多次出现。SAM 与 Grounding DINO 给出的候选数量不同；相同送审名额、相同筛选器下的结果见上一级实验。

## 候选完整度

| HSSD 留出集，所有可用候选 | 原版 SAM | Grounding DINO |
|---|---:|---:|
| 生成的框数 | 6,499 | 557 |
| 框能匹配的实例出现次数 / 661 | 355 | 338 |
| 小目标匹配次数 / 303（标注框面积 ≤2% 图幅） | 73 | 67 |
| 画作匹配次数 / 136 | 107 | 102 |
| 时钟匹配次数 / 15 | 11 | 12 |

两边同时匹配到 262 次，仅 SAM 命中 93 次，仅 DINO 命中 76 次。按房屋等权，SAM 减 DINO 的候选覆盖率差为 +0.19 个百分点，按房屋重采样的 95% 区间为 −7.69 至 +8.64。DINO 用类别词集中检索；SAM 的更大候选池把目标筛选成本留给后续审核。[完整统计](coverage.json)

在每屋预先固定的第一张测试图中，官方生成器给出 910 个原始框，其中能对应 37 次目标出现中的 33 次。按原生面积规则过滤后仍保留这 33 次；再按面积降序截到 24 个掩码后只保留 27 次。16 帧中有 11 帧达到了候选数上限。这个小样说明一部分漏框发生在原版截断候选时，也说明加大候选池会把更多无关区域交给后续排序。[过滤检查](cap_audit.json)
