# 已检测候选的 RGB 边框精修

模型接收完整 RGB 和 Grounding DINO 的原图坐标框。对矩形的每条边，比较在法线方向内移或外移后，边界两侧的颜色差、沿边的一致性和邻近纹理变化。一个共享的线性模型对位置打分。分数最高的位置给出该边的修正量。原检测顺序、分数、类别和名额全部保留，输出同时提供原图像素的 `bbox` 和 `xyxy`。候选为空时输出空列表。

HSSD 训练、校准、留出分别为 10、6、16 栋不同房屋，含 180、108、288 张仿真图。在训练图中，从 381 个真实检测框里选取至少与某个实例有 0.20 IoU 的 285 个，另从训练房屋的真实框构造 445 个轻度偏移框和 445 个单侧截断框。学习目标是贴近可见实例的真实四边。校准只比较应用修正量的比例 0、25%、50%、75%、100%，以一对一命中数为首要指标，同分时取每个目标最佳 IoU 的均值。各强度均命中 159 项，原始框平均 IoU 最高。独立训练方案采用校准表现最好的非零强度 25%，将未经修改的检测器作为单列的对照。

| 16 栋留出房屋 | 原检测框 | 独立训练的边框精修 |
|---|---:|---:|
| IoU ≥ 0.50，一对一命中 / 661 个目标出现 | 338 | 338 |
| 精确率 / 召回率 | 60.68% / 51.13% | 60.68% / 51.13% |
| 目标小于等于画面 2%，命中 / 303 | 67 | 67 |
| 取检测分最高的一个框，正例帧命中 / 244 | 189 | 189 |
| 每个目标与所有候选中的最大 IoU，包含无框目标 | 0.4983 | 0.4973 |
| 时钟 / 墙面艺术品，一对一命中 | 12/15、102/136 | 12/15、102/136 |

精修只调整已有方框。60 个与最近目标的原始 IoU 在 0.05 至 0.50 之间的偏框中，1 个调整后达到了 0.50，但是同图其他候选已经匹配该目标，独立命中总数持平。原始检测器已经漏掉且没有相关候选的目标无法由位置校正找回。实验支持保留原始检测坐标。此结论限于当前精修模型、图像和标注。
