# 相同审核名额的比较

冻结 CLIP ViT-L/14 对候选框及其周围 12% 的上下文打分，比较目标类别与易混类别、背景描述的图文相似度。所有来源使用同一排序器和裁剪规则，模型只读 RGB 和类别。每图取第一个或前三个候选，由实例外接框事后核对；另按正分送审规则统计空图误推。

HSSD 的 244 张正例图中，前三框命中图数依次为 DINO 210、原生 SAM 159、训练精修 210。按房屋等权，SAM 比 DINO 低约 21 个百分点，按房屋成对重采样的 95% 区间为低 13 至 28 个百分点。在 44 张空图中，按同一正分门槛，三个来源分别有 3、16、3 张误推。除“全部候选”项外，这些成绩包含排序器的影响。

在 HM3D 两个场景的 43 张诊断图中，20 张达到仿真实例可见门槛。画作有 10 张达标，DINO 首框命中 9 张，前三框命中全部 10 张；原生 SAM 分别命中 8 张和 8 张。时钟的特定语义标签跨越钟面和台面，逐场景定位需结合 RGB 复核。该组机位是固定诊断样本，不能用来估计随机导航的成功率。

三个候选来源均评分完成后，在研究项目目录以 `python score_boxes.py PROJECT_DIR` 汇总。每图候选保存在研究数据盘。
