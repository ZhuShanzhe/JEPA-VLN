# 可辨认钟面的 RGB 外观检查

检查对象为 21 张冻结的 HM3D 时钟任务 RGB，统一为 518×518。将图片随机改名、移去场景和流程标识。单个 AI 视觉审阅者只看 RGB 和局部放大图，以可辨认的表盘、罗马数字和指针为依据，框出可见钟面的外边缘。先固定逐帧判断和坐标的 SHA-256，再读取三个方法在这些图上的候选。先前已知有时钟任务及语义标注质量问题；审阅时未见对应的检测框、实例掩码或裁判信息。此检查评价时钟外观定位，不用于判定官方目标的实例身份。

7 张图可辨认完整钟面，1 张只见被图像上缘截断的钟面但仍可辨认，11 张因床头小物或斜视外观不清而存疑，另有 2 张近墙或门，未见钟面。存疑图单列，不作为确定负例。8 张正图中的观察有重复场景和实例。

重渲染的登记、靠近前、靠近后三张图中，DINO 首框与可见钟面的 IoU 分别为 0.9450、0.9860、0.9758。用仿真任务实例语义像素作分母得到的低覆盖率，不能直接解释成检测框只含钟面一角。对被上缘截断的一帧，SAM 的候选池含有合适区域，统一排序器未将它放入前三；另外两种方法的候选池均缺失。更多独立场景和多审阅者一致性仍有待检验。
