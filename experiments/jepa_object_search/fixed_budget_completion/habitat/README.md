# HSSD 连续寻物的相同总预算对照

从 V13 已验收的 12 栋留出房屋中读取全部 171 个多实例查询。三个训练种子分别运行同一组查询，表格给出各自任务总数的均值。每个起点最多连续走过四个分岔。每个分岔使用四步转动观察和 24 步路线运动，延续上段终点。统计在实际观察帧里两米内至少占 32 像素的目标，每个查询按实例 ID 去重。

JEPA 和直接监督两列来自 V13 的长程头。V11 列来自同一任务中已有的目标选路方法。上述回合测量到达可观察位置，观测机会与原版 MOST-Nav 系统实际报告并通过判定的实例数须分别解释。V13 长程策略还对每栋房屋抽取的一个固定查询重复实走，1,344 个动作、336 张图像及其可见实例集通过核对。
