# V8 图像目标探索评分头

当宿主决定探索时，V8 对其已有路线和九种固定短动作在同一起点、同一动作预算下评分。预测量是一条路线带来新增可报告实例的机会。训练标签扣除出发时已经可报告的实例，保留看见过但尚未进入报告范围的实例。自然采集采用冷启动，历史报告为空。模块只选路，发现、报告和去重仍由宿主负责。

## 四个可拆分的模块

| 模块 | 实现及作用 |
|---|---|
| 真实观测 | `dense_clip.py` 从冻结 OpenCLIP RN50 的末层提取每张图 7×7 个区域，并复用其 value/output 投影。`LocalGrounder` 将区域特征、目标词和 16 个训练词向量变成可见、近距两种概率。在线只用 RGB。 |
| 动作条件 JEPA | `route_heads.py` 使用此前真实观测的三个裁剪特征，结合计划动作预测中途和末端的区域特征。`heading_coverage.py` 按真实航向覆盖选用 V5 或稀疏视图 V6，在覆盖不足时保留宿主路线。 |
| 候选评分 | `grounded_route.py` 按四个距离假设投影已见目标证据，结合 JEPA 预测、文本对齐和动作几何。仅几何、仅观测辅助、仅 JEPA、联合四个头容量相同、分别训练，均有动作几何。 |
| 接入 | `inference.score_plans` 接收真实观测特征、航向、目标文本和合法动作，输出四臂概率。`route_heads.choose_pair` 按同预算对比，以严格大于 0.01 的概率差决定是否改道。 |

## 训练与独立验证

12 栋 HSSD 训练房屋贡献 144 个原生前沿起点及其中 72 个固定动作起点。每个起点比较 4、12、24 步，形成 432 组前沿和 216 组固定动作。4 栋校准房选择第 12 轮，再用此前未参与选模的 4 栋房屋、16 个物理起点检验。新可报告数、实际接触、未来近距和语义像素仅作标签。原生路线按计划交给宿主跟随器执行，固定动作按指令逐步执行。

- 当前可见性使用每格目标像素数/40 截断到 [0,1] 作为软标签。条件近距使用其中有效深度不超过 2 米的像素比例。**评测 F1** 对可见与近距均以每格至少 20 个相应像素为真，概率至少 0.5 为阳性。**未来近距训练** 则以整帧至少 64 个近距目标像素为阳性。
- 路线损失含出现新可报告实例的加权二元交叉熵（0.4）、有收益差的候选排序（0.6）、近等几何候选排序（0.6）、两个词偏好相反的交互排序（0.75）、固定动作未来近距预测（0.4）及包含前进动作的前缀可通行比例预测（0.25）。所有平局和零收益起点保留在分类及总体评价中。
- 固定种子 83。先以 AdamW（学习率 0.002）训练当前视觉定位 12 轮，再以 AdamW（0.001）训练四个路线头 12 轮。两阶段权重衰减 0.015，梯度裁剪为 3。路线训练使两类候选具有相等采样权重。12、1、2、3 个历史视角由固定规则生成。每个物理起点先汇总预算与视角，最后按房屋等权。
- `results/selection.json` 给出校准选模。`results/independent.json` 给出九种动作的预设准入条件及全部对照。`results/family_and_mirror.json` 给出原前沿、固定动作和左右镜像候选结果。镜像表中计数含同一起点的不同目标和视角，独立样本量看 `*_starts` 和 `*_houses`。`results/parity.json` 记录正式权重与本包的数值核验。

### HSSD 的主要读数

下表是各方案相对均匀轮流充当原候选的新增可报告实例数，保留所有零机会状态。它衡量每次局部选路的平均收益。官方层采用 HSSD ObjectNav 任务发布的六类物品合法视点，扩展层采用本项目对十类物品渲染的视点。两层均为本项目的派生测试。

| 候选与物品 | 仅几何 | 仅观测辅助 | 仅 JEPA | 联合 | 同起点错词 |
|---|---:|---:|---:|---:|---:|
| 九种动作，官方六类 | +0.0107 | +0.0174 | +0.0187 | +0.0058 | +0.0031 |
| 九种动作，扩展十类 | −0.0352 | +0.0141 | +0.0071 | +0.0094 | −0.0083 |
| 原生前沿，官方六类 | +0.0359 | +0.0305 | +0.0303 | −0.0070 | +0.0126 |
| 原生前沿，扩展十类 | +0.0099 | +0.0298 | +0.0287 | +0.0338 | +0.0281 |

联合头未通过预设独立门槛。官方层可见性 F1 偏低，独立留出面板上的当前视觉定位 F1 为 0.171（可见）、0.091（近距），此 F1 合并面板内有可靠标签的全部目标类。新增固定动作上，等预算左右镜像且两个目标偏好相反的 8 个有效起点覆盖 4 栋房屋，交互排序得分为观测辅助 0.652、联合 0.621、JEPA 单支 0.614、纯位移 0.500；打平给半分。原生前沿没有符合该严格条件的起点。

### Blender 位置互换

四栋训练房中，杯子与沙发交换左右位置，入口布置咖啡台与灯作为提示。只以提示正确的 8 个布局微调，固定 10 轮、种子 101，与原 HSSD 动作等比例回放。两栋留出房、12 个布局测试正确提示、隐藏和反向提示。隐藏组的两种摆放在实际观测 RGB 上逐像素相同。

| 联合头，24 步方向准确率 | 提示一致 | 完全隐藏 | 提示相反 |
|---|---:|---:|---:|
| HSSD 训练 | 53.1% | 50.0% | 46.9% |
| HSSD + 受控微调 | 68.8% | 50.0% | 31.3% |

微调能学习摆放线索，也会放大错误提示。将微调后的未来特征换回观察特征，在提示一致条件下同样得到 68.8%。自然环境复测复用了原四栋留出房，官方层增益从 +0.00584 变为 +0.00563、扩展层从 +0.00944 变为 +0.00195。线上实验使用原冻结 V8。详细结果见 `results/controlled.json`。

## 使用自有合法缓存

依赖 Python、PyTorch、NumPy。仅直接提取 RGB 特征时需要 Pillow 和训练时相同的 OpenCLIP RN50 与预处理。原数值核验使用 PyTorch 2.8.0。准备自己的冻结 V5/V6 和三份按房屋互斥的 CPU Tensor 缓存后执行：

```sh
python train_v8.py fit --train train.pt --calibration calibration.pt --full full.pt --sparse sparse.pt --output experiment
python train_v8.py check --holdout holdout_primitives.pt --full full.pt --sparse sparse.pt --output experiment
python evaluate_families.py --states holdout_both.pt --checkpoint experiment/v8.pt --full full.pt --sparse sparse.pt --output families.json
```

使用门控时，另存仅含 `anchors,queries,states` 的无真值缓存，每个 state 只含 `sid,house,code,anchor_sim,ctx,actions`（`ctx` 沿用原始裁剪缓存，入口统一归一化）；运行 `python predict_switch.py --cache observed_only.pt --checkpoint experiment/v8.pt --full full.pt --sparse sparse.pt --predictions blind_predictions`，可直接将输出交给 `data_tools/learn_switch.py` 的 `fit/evaluate`。每个起点写入完整词表，按 4/12/24 步及 12/1/2/3 视角依次记录每个原候选的两专家选择和六个分歧特征。

`torch.save({"anchors": anchors, "queries": names, "states": states}, path)`。先固定 16 个单位化 RN50 文本向量 [16,1024]，顺序与名字匹配。每个 state 表示一个物理起点。训练分区保留原生跟随器路线和固定动作，校准与预设独立检验使用固定动作。特征和教师字段如下，其中 B 是候选数，Q 是该屋可独立核查视点的查询数。

| 字段 | 内容 |
|---|---|
| `sid, house, family, query, domain` | 起点、房屋标识，`frontiers` 或 `primitives`，Q 个名称及对应 `official/derived`。 |
| `ctx, code, anchor_sim` | 12 个真实方向的三个单位化 RN50 裁剪向量 [12,3,1024]、每格 64 维投影 [12,49,64]、与 16 个训练词的相似度 [12,49,16]。后两项按 FP16 存储后还原 FP32。 |
| `ids, text, actions` | 各词在词表中的索引 [Q]、词向量 [Q,1024] 及可执行计划 [B,24]。动作 0/1/2 分别为前进 0.25 米、左转 30°、右转 30°。 |
| `v, n, teacher_near, samples` | 原始像素数 [12,49,Q] 的可见与近距两份，未来整帧近距像素数 [B,5,Q]，时间点 [2,4,6,12,24]。原生前沿的视觉教师留零，仅固定动作参加视觉与未来近距监督。 |
| `gains, teacher_actions, collision` | 4/12/24 步的新增可报告实例数 [B,3,Q]、实际执行的动作与接触布尔值 [B,24]。教师字段仅用于训练或离线统计。 |

受控可选入口为 `controlled.py`。训练和验证的 `.pt` 均为布局列表，每项含 `sid,house,mode,swap,queries,text,ctx,local,action,collision,gain_by_query_by_horizon`；额外的 `local` 为实际看见的 12 张图的单位化区域特征 [12,49,1024]。`mode` 是 `congruent/hidden/conflicting`，只用于划分实验并描述结果。`replay` 是只含训练房原语的自然缓存。

```sh
python controlled.py --train blender_train.pt --held blender_test.pt --replay train_primitives.pt --checkpoint experiment/v8.pt --full full.pt --sparse sparse.pt --output intervention
```

## 当前是否值得请原 VLM 复核

`review_cue.py` 用当前 RGB 的局部目标响应估计当前位置是否已经进入目标的合法报告视点（导航网格测地距离不超过 0.25 米）。它训练两个独立的逻辑回归头，一个看当前画面，一个汇总在同一位置实际看过的十二个朝向。训练使用 12 栋 HSSD 房屋、144 个物理起点、1,884 个可核查的起点与类别组合，其中 307 个为正。校准使用另 4 栋、48 个起点，按精确率至少 65% 选择召回最高的阈值。后续三栋房屋曾用于另一项选路门控评测，其当前状态标签在本次模型、阈值与全部盲预测冻结后才打开。

| 观测方式 | 校准结果 | 三栋留出房的 TP / FP / FN / TN | 精确率 | 召回率 | 提示覆盖 |
|---|---|---|---:|---:|---:|
| 当前画面 | 未达到 65%，始终弃权 | 0 / 0 / 18 / 130 | 无提示 | 0% | 0% |
| 十二个已观察朝向 | 阈值 0.3461，19 真、9 误 | 6 / 5 / 12 / 125 | 54.5% | 33.3% | 7.4% |

留出集仅有 12 个物理起点。十二朝向模式命中的 6 个正例全部来自官方六类，扩展十类的 11 个正例全被漏掉。两种模式均未达到上线所需的精确率。这项诊断没有触发付费调用或改变两臂成绩。`results/review_cue.json` 保存分屋、分类与阈值无关的平均精度等统计。

对五个联合臂回合做了盲回放。在 1,137 步中，有 29 个时刻原地累计看过十二个朝向，其中 8 个时刻的目标与训练词表精确相符，另 21 个时刻要求判断门的颜色。8 个可比较时刻仅代表 3 个实际位置，提示器均未触发。原仿真独立重放证实，这些位置均无当时可正式上报的未报实例。41 张用到的历史图像与重放画面对齐，位置最大误差为 0 米。这次盲回放没有覆盖已到位但漏报的正例，无法据此估计能补回几次报告。

复用时，训练和校准缓存保留 `anchors,queries,states`；每个 state 含 `sid,house,code,anchor_sim,eligible`，标签按完整词表编号为 −1（无可核查视点）、0 或 1。预测时删除 `eligible`，保持完整词表。运行 `python review_cue.py --help` 查看 `fit/predict/evaluate`。预测输入通过字段白名单校验。独立评估的标签 JSON 含 `words,domains,rows`，每条 row 只需 `sid,house,eligible`。
