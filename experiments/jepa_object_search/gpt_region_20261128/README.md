# GPT-4o 选择区域和细查时机

在同一批 8 栋 HSSD 房屋、每屋 300 步的测试中，GPT-4o 上层与 JEPA 观察位组合在 2 栋靠近了至少两个实例，合计靠近 8 个实例。上一版的结果为 1 栋和 6 个，更早的区域探索版为 3 栋和 10 个。[逐屋结果和验收](accepted.json)

## 模块分工

GPT-4o 读取目标文字、当前右中左三张 RGB 图、可达区域的距离与方位、原策略的摆放先验提示和在线探索记忆。它从区域编号中选一个，并决定继续探索或细查中心图的某一块。地图生成和检查可达观察位，冻结的 JEPA 在细查时给候选路线排序，原有跟随器执行实际动作。生成不了合法观察位时继续按区域行动。原生 MOST-Nav 宿主保留了目标靠近、调整、上报和结束的优先级。[上层输入和提示](gpt_gate.py) · [探索与细查](arm_policy.py) · [原生接入](gpt_agent.py)

使用 APIYI 返回的固定模型标识 `gpt-4o-2024-11-20`。两份历史对照使用同一份冻结清单、同一模拟器、相同起点和朝向、RGB-D、位姿、动作预算及评分函数。主要指标为真实轨迹到不同目标实例合法观察机位的可导航距离小于 0.25 米，同一实例每屋只计一次。八个起点均未命中实例。每屋对应一个类别；类别和建筑的影响无法由这八个回合分别估计。[房屋与评分协议](../local_target_20261128/eval_family/README.md) · [版本指纹](gate_lock.json)

## 决策日志

- **探索预算重新分配。** 在总计 2,400 步中，区域移动从 977 步增加到 1,548 步，局部移动从 534 步降至 8 步，扫描从 880 步降至 824 步。GPT 在 191 次上层决策中选了 188 次探索和 3 次细查。它在 151 次决策中选择了与同一输入下旧排序首选不同的区域，余下 40 次相同。这一组对照同时改变了选区和细查触发，只能衡量两者的合并效果。
- **细查集中在柜子回合。** 三次细查中，一次缺少可达观察位，两次建立了局部观察位并各执行四步，随后被上层切回探索，均未取得观察位抵达回执。第二次局部移动在第 163 步首次进入第三个柜子的计分范围。八个实例的首次靠近中，七个发生在区域移动，一例发生在局部移动。
- **几何靠近与视觉确认。** 画作回合贡献了四次靠近。该回合 21 次上层判断均未给出疑似或明确的目标线索。几何成绩说明路径经过了四个实例的合法观察位置；识别、登记和主动上报仍需完整任务评测。

## 接口与复核

191 次正式模型请求全部收到固定版本的有效决策，服务报告共 319,883 个 token，未返回实际计费金额。训练屋的真实请求和缓存检查、HM3D 原生宿主的真实图像调用分别独立执行。宿主检查使用受控地图和位姿，验证了高层选择能派发为导航动作。[训练屋预检](preflight_gate_receipt.json) · [宿主检查](host_receipt.json)

服务器项目目录中，加载已配置的私有 GPT-4o 服务后，可使用 Habitat 环境核验冻结文件、运行和审计。正式运行支持按回合编号拆分，已完成的回合按源码指纹复用。

```sh
source ops/profiles/apiyi_gpt4o/activate.sh
PY=simulation/habitat-env/bin/python
$PY gpt_region_20261128/run_gate.py --seal-only
$PY gpt_region_20261128/run_gate.py --indices 0 1 2 3 4 5 6 7
$PY gpt_region_20261128/audit.py
```

在仅有公开汇总的环境中，执行 `python audit.py --public-only` 可复核配对汇总。受限数据环境中的完整审计额外逐条核对模型返回、实际决策、动作预算与首次命中步号。[独立验收程序](audit.py)
