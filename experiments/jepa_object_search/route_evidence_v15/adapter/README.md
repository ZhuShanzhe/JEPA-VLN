# 缺少目标线索时的选路

MOST-Nav 负责生成候选、接近物体、报告与结束。探索分支提供三条不同且可行的 24 步路线时，机器人用四次原地转头获取三个当前视野，按原动作预算计费。V15 用 [V14 的执行适配器](https://github.com/ZhuShanzhe/JEPA-VLN/blob/937c24d6e2804e5e72dd239c5e5ad2bf5e107366/experiments/jepa_object_search/most_execution_v14/README.md) 将选中的路线交给跟随器。开场探索从首次满足候选和预算条件的分岔生效。

| 输入 | 作用 |
|---|---|
| 当前三个视野、目标词和候选动作 | 新训练的 JEPA 头估计未来四个观测点中至少出现一次新目标证据的概率。真实运行时可能已经看过某些实例，这个概率仍是对潜在线索的估计。 |
| 近期实际观测与报告动作 | 按本回合局部格子和朝向保存证据。用 HSSD 训练房屋的校准表将视觉线索映射到证据强度，扣除背景频率并按 24 个动作的时间尺度衰减。已报告过的视向从未处理线索中移出，重复报告不等同于找到了新物体。 |
| 走过的格子、候选路线和剩余动作 | 估计每条候选前进步将进入未访格子的比例。在没有新线索、仍有步数探索时，更偏向能揭示目标证据的未访空间。 |

缺线索程度 (d) 为 1 减去近期最强有效观测的相对强度，范围 0 至 1。令 (B) 表示 V13 连续评分，(p) 为新证据概率，(u) 为候选中前进步的未访比例，(T) 为剩余步数。选取下面分数最高的候选。

```text
w = 0.5 × d × min(1, T / 48)
score = B + (0.25 + 0.75 × d) × p + w × u × (0.35 + 0.65 × p)
```

V15 移除了 V13 固定在第二个路口触发的查新规则。每次实际评分记录完整 V13 在相同输入上的选择，以及分别去掉额外探索项、去掉新证据预测时会选择的路线。这些同状态重评分可以帮助解释分支变化。整条轨迹变化后的搜索效果需要闭环任务测量。
