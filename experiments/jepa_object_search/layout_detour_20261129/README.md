# 弯道候选与 JEPA 观察位预测

在 HSSD 训练房屋用两段平移加转向生成路线，实际执行以取得通行标签和终点 RGB。预测头读取起始图像特征、目标框、候选动作和从可见深度估计的布局，学习未来画面特征的变化，并预测路线可达性及终点目标的可见性。沿用原通行检查器。[训练统计](training.json) · [模型](layout_model.py)

在旧 94 个困难起点，59 组选过弯路，32 组实际沿不同方向前进。与前一版相比，达到可见标准的组数均为 58，新得 2 组、丢失 2 组。[路线诊断](route_geometry.json) · [布局栅格选路](../layout_detour_v2_20261129/README.md)
