# 从发现实例到靠近、复看与上报

任务是让 MOST-Nav 在 HM3D 中找到并上报两个不同的钟。在这个开发回合，官方评分器只在执行 `TARGET_FOUND` 时计分。有标注观察点时，要求机器人到其中一个有效观察点的可通行距离不超过 0.25 米。策略运行时只能估计合适的观察位置。

## 行为

1. 上层确认过的线索有清晰登记图后，机器人可以优先处理该实例。近处保留已有 JEPA 选出的复看路线，每执行一步便从新机位重新检查。若已有可信拍摄机位适合返回，也可以直接规划回到该机位并对准原方向。
2. 每次准备移动前先检查能否上报。遇阻时避开刚失败的移动方向，转到另一个可通行位置；取得一帧可信外观后，暂存当时机位和目标方位，优先复看。单次接近最多 32 个动作，使用回合原有预算。身份冲突、持续无路或预算耗尽时让出控制，保留线索。
3. 原跨视角身份模型优先工作。仅当几何输入缺失时，使用可信历史照片与当前检测框内的纹理和周围地标进行比对，需要连续两个不同观测支持且没有竞争实例。明确的身份否决仍有效。上报动作实际执行后才登记为已报。动作回执只证明动作已执行，正确与否由独立评分器判定。

## 受控仿真与回放

| 测试 | 对照条件 | 官方计分或模块结果 |
|---|---|---|
| 从评分范围外返回已见过的时钟，直达起点 | 在同一起点立即上报，得 0 个正确实例、1 次误报 | 靠近和复看使用 12 个动作（含 8 次前进），随后上报正确 1 个，误报 0 |
| 从评分范围外返回同一只钟，需绕障的起点 | 在同一起点立即上报，得 0 个正确实例、1 次误报 | 靠近和复看使用 22 个动作（含 16 次前进），随后上报正确 1 个，误报 0 |
| 旧版已看到钟但暂缓上报的第 137–140 步 | 旧版沿原轨迹未发出上报，最终 0/2 | 固定前缀下，新版在第 139 步主动上报，评分 1/2，误报 0；下一步记录执行回执 |
| 从两个已经能得分的位置继续贴近物体中心 | 两处立即上报各得 1 个 | 强制继续靠近多走 11 和 18 个动作，两处仍各得 1 个 |
| 独立 HSSD 房屋的局部视觉复核 | 12 栋房屋，覆盖时钟和画作，每组为一张登记图和两张不同查询视角 | 同类不同实例 42 组，错误接受 0；同一实例 42 组，正确接受 2、暂缓 40 |

圈外两处是在同一只钟上的独立重启，预先提供了另一次采集的清晰观测。为单独检验靠近行为，测试提供已知通行地图、精确里程计和根据检测框与对齐深度估出的目标位置，使用实际 Habitat 动作、重新渲染的画面与官方评分。起点分层和事后验收可以读取标注；行为控制器无法读取官方有效观察点或得分。固定轨迹回放使用真实 RGB、检测器、实例竞争和回执，并提供旧建图模块当时记录的弃判结果。HSSD 统计衡量局部视觉复核，其阈值在运行这组验证前固定。[圈外靠近对照](physical_return_active.json) · [圈内贴近物体对照](object_standoff_verified.json) · [第 139 步回放](clock_report_replay.json) · [独立房屋视觉核验](hssd_witness_results.json)

## 从第 132 步接管同一次寻钟任务

使用相同的登记和起点，让新控制器在 Habitat 中发出每个动作。三支都可使用真实 RGB 和检测结果。旧几何分支设置为不可用，以便单独考察局部视觉确认。

| 可用的地图和路线 | 控制与计分 |
|---|---|
| 使用第 132 步行动前已经生成的 JEPA 复看路线、当时认可的通行格；实际动作仍与旧路径相同时提供当时的 SLAM 位姿 | 控制器执行 3 次前进、4 次转向。地图估距从 1.15 米降至 0.60 米，第 139 步根据两帧自行上报正确 1 个实例，误报、重复均为 0 |
| 使用同一份首段计划，改由仿真的通行网格重新检查每一步 | 运动中重新规划，未上报，0/2 |
| 使用仿真通行网格和里程计，自行重算 JEPA 首段路线 | 近场候选从原来的 7 条变为 1 条；共执行 26 个动作，最近估距 0.38 米，未获得足以确认身份的图像，0/2 |

三支都只考察这次接近机会。保住能看清实例的路线时，新模块能把已有发现转成官方计分；更换通行图后，走到离估计物体中心更近的位置仍可能看不清它。从零探索、找到第二只钟及整回合成功率还没有新版成绩。[使用原路线和通行记录](clock_approach_recorded_inputs.json) · [重新检查原路线](clock_approach_recorded_first.json) · [重新规划首段路线](clock_approach_online.json) · [闭环重放程序](replay_clock_approach.py)

## 运行入口

服务器项目模块为 `identity_stage6_approach`。正式评测类为 `approach_agent:ApproachAgent`，继承已有导航、建图、检测和身份模型。原版与早期冻结回合独立保留。离线检查及完整自主评测的独立配置可通过下列入口准备。

```bash
bash run_environment.sh -m unittest test_approach_agent.ApproachTests test_visual_witness
bash run_environment.sh prepare_evaluation.py
```
