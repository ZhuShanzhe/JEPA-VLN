# 目标为什么看不清

这项诊断复用 HSSD 三栋留出房屋中的 94 组局部观察任务。当前协议用实例在 192×192 画面中实际可见的面积判断是否看清，门槛为 369 像素，约占整幅图的 1%。框里的背景不计入。这个指标衡量目标露出了多少，对焦、纹理锐度和人眼能否辨认属于不同问题。

## 真实可见面积不足

上一版有 33 组在原路线全程没有一帧达到门槛。每组取最好的一帧，可见面积中位数为 163 像素。以下对照只改变指定条件，部分组可同时受多个因素影响。

| 只改变的条件 | 实测结果 | 对选观察位的含义 |
| --- | --- | --- |
| 保持原有机位，移走目标以外的场景物体和表面 | 10/33 组在至少一个已经走过的机位达到门槛。一幅画被落地灯遮住时有 306 个可见像素，移开遮挡后有 406 个。一张桌子被沙发遮住时有 145 个，移开后有 574 个 | 同样距离下，侧移绕开前景可能比继续向前更有效。[遮挡测量](occlusion_attribution.json) · [遮挡物类别](occlusion_blockers.json) |
| 取每组最佳原帧，在无遮挡空间把相机与目标间距缩短 35%，保持相对视线方向 | 原机位去掉遮挡仍未达标的 26 组中，14 组达标 | 距离能解释部分小目标。这个对照没有要求近处机位在房间里实际可达。[距离对照](occlusion_attribution.json) |
| 恢复完整房间，从最佳原帧朝目标尝试前进 | 25/33 组连第一步 0.25 米也走不通。走近的 8 组中，5 组目标反而变小，其中 4 组原本可见的表面有过半越出画面上下边缘 | 靠近过程中要同时考虑障碍、机位与画面的上下边界。[移动对照](approach_probe.json) |
| 保持各组最佳原帧的机位，试五个俯仰角 | 2/33 组达标。前述 4 组在前进后的新机位调俯仰，目标均变大，但都未过门槛 | 改变俯仰能纠正部分出框，能够绕开遮挡且看得见目标的实际位置仍很重要。俯仰测试仅用于诊断。[俯仰对照](approach_pitch.json) |

## 相机分辨率与采样

实际检查到的相机为针孔模型，平视，高 1.31 米，水平视场 90°，未开启传感器噪声。在相同机位和视场将长宽各翻倍到 384×384，目标像素中位数约增至四倍。在上述 33 组的完整原路线上，沿用相同画面占比（1,476 像素），达标组仍为 0。若错误地沿用 369 个像素的绝对门槛，会得到 27 组达标。另在原模型输入尺寸下，只提高当前 RGB 的采样质量再缩回 192×192，下面 14 组的代表帧仍有 0 组被接受。采用原生高分辨率输入重新训练识别器的效果尚未检验。[分辨率对照](camera_resolution.json) · [采样对照](camera_sampling.json) · [Habitat 相机参数](https://aihabitat.org/docs/habitat-sim/habitat_sim.sensor.CameraSensorSpec.html)

## 已拍够但拒绝上报

上一版有 29 组见过达标画面却未上报。在新旧版本均未上报的组中，找到 14 组具有位置吻合的候选框，同一实例评分已过线，清晰度评分未过线。每组在这些合格画面中取联合得分最高的一帧。以下均为每组一帧的中位数。

| 观测量 | 14 组的代表帧 |
| --- | ---: |
| 目标真实可见面积 | 456 像素 |
| 由初始记忆表面投影到当前帧估出的面积 | 327 像素 |
| 候选框覆盖真实可见目标像素的比例 | 89.4% |
| 同一实例评分 / 清晰度评分 | 0.971 / 0.603 |
| 可见表面沿相机光轴的深度 | 1.64 米 |

30 组正确首次上报的表面深度中位数为 1.97 米。两组目标构成不同，这一比较只能说明漏报也发生在较近的画面。旧记忆的投影面积在 11/14 组偏低，其中 9 组被估到 369 像素以下。固定其余输入和权重，仅以真实面积替换该项估计及其派生比值，4/14 个代表帧转为接受。仅用真实外接矩形替换候选框，0/14 个转为接受。另有 5 组过早上报，当前候选框内估计的目标面积在这 5 组均偏高。训练上应分别处理漏估和高估，让模型能区分框内目标与背景。[评分与面积对照](observed_clarity.json)

94 组经过困难条件筛选，数字仅适用于这一批任务。移除物体、使用真值、改变俯仰和提高分辨率均用于离线诊断。模型任务成绩沿用原评测。
