# 隐藏目标选路的比较约定

主问题是，起点看不到目标时，在同样的可执行路线中选择，预测未来视觉表征是否带来超出直接监督的收益。本轮不重做 GPT 的目标报告评测。比较对象是输入、动作和预算一致的选路模块，MOST 整机的历史结果单独保留。

## 主比较

- 自然房屋作为主检验。在 HSSD 起始提供给策略的所有 RGB 方向里，目标类别应为零实例像素。合格分岔至少有一条路线能见到并接近目标，也至少有一条做不到。按独立新房屋配对比较两种策略，记录候选总数、有效起点数、有效房屋数及筛选率。
- 用 11、29、47 三个配对种子。每个种子内两种模型共享输入、候选、目标词、路线成功监督、环境和可用的在线记忆。JEPA 训练时额外预测真实执行后获得的视觉表征。未来图像和实例标签都不进入推理输入。禁止从终评选种子、挑房屋或倒推超参数。
- 把纯 HSSD 训练与 HSSD 加 Blender 训练分别比较。主要性能量为首次选择在给定动作预算内是否发现符合判定的目标。对可执行后续检查的任务，再报告有限探查预算内的累计发现。重复查看同一物体只算一次；同类多个目标须同时报告“找到任意一个”与“找全”的分母。
- Blender 辅助检验预先关心符合摆放规律、与规律相反、无入口提示和同类多实例。多实例同时具有摆放属性时按实际设计分组，分别标出样本数。物体缺席单独统计，不把用光预算推断成物体缺席。

## 如何解释优势

先逐起点、逐种子配对，再按房屋等权汇总。统计单位为房屋，不把同一房屋里的相邻视点、同一初始画面的反事实摆放或多个训练种子当作独立房屋。对主要 HSSD 比较给出按房屋重采样的区间、种子方向，以及逐屋删除后的变化。候选成果不同的样本是有意富集的挑战集，不能由该成绩推断所有自然出发点上的成功率。

若一个分组只有少数房屋、置信区间跨零或种子之间方向不一致，保留实测差值并作为线索。只有受控合成场景有收益时，结论限于该场景。三种子与不同训练条件重复使用同一留出集，分别报告，不挑出其中最好者代替主结果。

另核查同一自然分岔中“找甲必须走的方向与找乙完全不重合”的条件。交换顺序固定的两个目标各自选出的路线，检查是否比正确目标得分更低。此项诊断辨别模型依赖目标语义的程度，样本不足时只描述，单独列出它的起点数与房屋数。
