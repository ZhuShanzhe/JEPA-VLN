# 隐藏目标选路头

分岔口有三条固定步数的路线。选路头读取起点左、前、右三张 RGB、目标类别文本和每条计划的前进与转弯动作，给三条路线打分。首选命中表示在选中的路线出现了可见的目标实例。此指标衡量搜索机会。完整导航系统还需要识别、去重和报告目标。

## 训练与在线记忆

| 方法 | 共同的训练目标 | 额外训练信息 |
|---|---|---|
| 直接监督 | 判断每条路线能否看到目标，按新见实例数量学习路线排序 | 无辅助损失 |
| JEPA | 同上 | 预测走这条路线后，在 1/4、1/2、3/4 和终点的视觉特征，包含整幅图及左右两个局部。另对齐同一起点不同路线的特征差异 |
| 错配未来 | 同上 | 使用相同的特征预测损失，在同一起点把三条路线的未来特征循环互换，检验匹配正确路线是否有额外作用 |

三个方法共用冻结的 RN50 视觉和文本编码器、126,561 个可训练参数、初始化及批次顺序。各做三个随机种子，每次训练 480 步，批次 48。联合训练先等概率抽 HSSD 或 Blender，再等概率抽训练房屋。JEPA 的特征损失系数为 0.65，其中同一起点的路线差异项系数为 0.5。模型按固定步数冻结。训练房、权重摘要和设置在 [训练记录](fit_receipt.json) 与 [训练配置](protocol.json)。

三个方法都沿用 V10 的在线记忆。机器人在一轮搜索内记录访问位置、碰撞和从已走路线 RGB 提取的目标线索，回到分岔后重新给剩余路线打分。新起点清空记忆。目标实例 ID 只用于计分，训练权重在探查期间固定。

## 未见房屋测试

HSSD 提供 28 栋训练房、6 栋校准房和 16 栋测试房。测试共 275 个起点、424 个目标查询，起点全景无目标像素，实际走不同路线可见的目标实例数有差异。Blender 有 8 栋训练房、2 栋校准房和 6 栋测试房。测试有 432 个起点配置、864 个查询，其中 792 个有目标。重复可见布局配合不同隐藏摆放，用于检验目标线索能否区分路线。

下表先在每栋房内平均查询和种子，再平均各栋房。首选看第一条路线能否看到目标；两次探查看任一条探索路线能否看到目标。

| 测试与训练来源 | 直接监督 | JEPA | 错配未来 | JEPA 相对直接 |
|---|---:|---:|---:|---:|
| HSSD 首选，仅 HSSD 训练 | 43.33% | 49.42% | 50.61% | +6.08 个百分点 |
| HSSD 首选，联合训练 | 48.32% | 49.14% | 49.46% | +0.82 个百分点 |
| HSSD 两次探查，仅 HSSD 训练 | 72.04% | 79.95% | 77.56% | +7.91 个百分点 |
| HSSD 两次探查，联合训练 | 76.00% | 79.63% | 78.67% | +3.63 个百分点 |
| Blender 有目标查询的首选，仅 HSSD 训练 | 42.30% | 43.18% | 42.17% | +0.88 个百分点 |
| Blender 有目标查询的首选，联合训练 | 45.33% | 45.03% | 44.99% | −0.29 个百分点 |

仅用 HSSD 训练时，两次探查中 JEPA 相对直接监督提升 7.91 个百分点，按房屋配对重采样的 95% 区间为 [1.05, 17.71]。JEPA 相对错配未来提升 2.38 个百分点，区间为 [−0.91, 7.23]。首选相对直接监督提升的区间为 [−0.66, 16.00]。现有结果支持继续检验探索两条路线时的收益，尚难将收益归因于预测了正确路线的未来视觉内容。

HSSD 的序列包含首段 24 步、返回 36 步和第二段 24 步。在线记忆先读取首段 4 帧，再读取返回段 6 帧，第二段从实际返回后的位姿重放。返回未通过时仅保留首段已有发现。在每个方法的 1,272 条种子与查询组合中，仅 HSSD 训练的直接监督、JEPA、错配未来分别有 21、20、25 次返回未通过，联合训练分别有 29、36、26 次。

Blender 每条首段实走 28 步、返回实走 40 步，归位误差验收阈值为 3.5 厘米。记忆读取首段 4 帧及碰撞，回程按实际耗时推进。第二段计分使用原分岔位置实走过的候选路线记录。联合训练时，216 个含两个同类实例的查询中，两次探查找全两个实例的比例依次为直接监督 23.46%、JEPA 25.00%、错配未来 25.93%，按独立实例 ID 去重。
