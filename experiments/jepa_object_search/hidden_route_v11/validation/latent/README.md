# 冻结模型能预报哪条路线会看到什么吗

HSSD 的 16 栋留出房屋提供 275 个起点。每个起点有 3 条等步数路线，同时有至少一个目标会因选路不同而改变发现机会。共 424 个这样的「起点 × 目标」。先核验 18 个模型的冻结权重哈希，再读取测试集。权重来自两种训练数据、三种训练目标和三个随机种子（11、29、47）。

比较同一起点的三条路线。机器人先根据三张已观察的起点图像和候选动作预报未来。实际走过路线后，用同一个冻结视觉编码器提取第 7、14、21、28 步图像的全图、左部和右部特征，评价当前预报是否准确。复制视角对照仅按计划朝向，重复使用三张起点图中朝向最接近的一张。

| 训练数据 | 方法 | 余弦误差 ↓ | 三选一配对 ↑ | 两路线配对 ↑ | 首选路线有目标发现机会 ↑ |
|---|---|---:|---:|---:|---:|
| HSSD | 直接监督 | 0.8871 | 36.74% | 53.04% | 43.59% |
| HSSD | JEPA | 0.1228 | 37.87% | 62.99% | 50.60% |
| HSSD | 错配未来监督 | 0.1195 | 32.29% | 47.81% | 51.15% |
| HSSD + Blender | 直接监督 | 0.8676 | 34.95% | 53.92% | 48.14% |
| HSSD + Blender | JEPA | 0.0932 | 37.17% | 63.85% | 49.00% |
| HSSD + Blender | 错配未来监督 | 0.0985 | 32.30% | 50.91% | 49.42% |
| 无训练 | 复制起点最近视角 | 0.1504 | 40.41% | 64.52% | 无选路输出 |

三选一配对根据每条预报与哪条实际路线最相似给分，随机水平为 33.33%。两路线配对从同一起点取两条路线，比较正确分配与交换分配的总相似度，随机水平为 50%。两者都在相同时间、相同图像区域比较。首选命中衡量沿首选路线能否观察到目标，沿用冻结时保存的每个模型的选择。表格先平均种子、同起点的目标及同一房屋的起点，再对各房屋等权平均。因各起点包含的目标数不同，该列权重与按查询聚合的主评测可有差异。

**JEPA 学到了与路线有关的视觉差异。** 与错配未来监督相比，两路线配对率提高 15.18 个百分点（仅 HSSD，按房屋配对重采样的 95% 区间为 9.27 至 20.85），加入 Blender 后提高 12.94 个百分点（4.13 至 21.13）。但复制起点视角也达到 64.52%，提示起点已经可见的背景和方向提供了相当多的路线判别信息。这组指标无法单独说明模型预测出了遮挡后的目标。

**表征更接近实际画面时，机器人首选路线并不总是更好。** 混合训练的 JEPA 在全部 275 个起点的余弦误差均低于直接监督，但选择目标的结果只有 73 个起点提升，127 个持平，75 个下降。两路线配对改善量与首选命中改善量在起点上的描述性 Pearson 相关系数为 −0.031，单用 HSSD 为 +0.036。这里的首选命中是路线可见性与距离判据给出的发现机会，完整系统的探索、识别及报告还需分别验证。

在首选路线上，把正确未来监督和错配未来监督直接配对，单用 HSSD 的差为 −0.55 个百分点（95% 区间 −4.55 至 +2.45），加入 Blender 后为 −0.42 个百分点（−3.58 至 +2.68）。两个区间均包含零。

`diagnose.py` 读取冻结权重、缓存的特征和既有首选记录。`results.json` 保存按房屋汇总的表征指标、配对 95% 区间和起点级相关性统计。表征指标区间使用 10,000 次房屋重采样。`future_choice.py` 与首选命中主分析共用统计函数，用 20,000 次房屋重采样计算正确与错配未来监督的首选差异，输出为 `future_choice.json`。
