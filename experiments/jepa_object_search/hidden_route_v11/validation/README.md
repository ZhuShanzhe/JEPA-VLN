# 选路验收与统计口径

| 问题 | 验收结果 | 记录 |
|---|---|---|
| 新测试房屋会不会是旧房的同编号变体？ | 16 栋新测试屋与训练、校准及历史建模房屋共享的编号前缀均为零。168 套 HSSD 场景的建筑网格按厘米量化、统一平移和四种水平朝向后有 168 种签名。签名检查能识别相同网格，不能排除不同网格之间设计相似。 | [建筑几何核查](layout_audit.json) · [几何签名程序](layout_signatures.py) |
| 走哪条路真的会改变结果吗？ | 16 栋房屋 275 个起点的 825 条去程，独立重放的起始和四个时刻 RGB 与存档逐像素一致，实例发现标签全部复现。真实执行 825 次返程，811 次通过闭合检查。从返回后的位置实际走了 1,622 条第二段路线。 | [去程与返程统计](return_analysis.json) · [仿真程序](physical_return.py) |
| 首选差值是否由同一个房间或少数种子造成？ | 固定 3 种子，先在每个起点平均目标，再在每屋平均起点。以房屋配对重采样 20,000 次，同时做房屋差值符号置换。纯 HSSD 训练逐一删去任一房屋，差值介于 +3.04 和 +8.36 个百分点。混合训练为 −1.31 至 +1.73。数据量小的单屋容易影响区间宽度。 | [首选配对统计](paired_results.json) · [计算程序](paired_analysis.py) |
| 返程失败如何处理？ | 去程已经看见的目标始终保留。已确认累计发现、双方均实际返回的配对，以及将未完成第二段所有未知结果作最有利和最不利填充得到的差值边界分别公开。边界与房屋抽样的不确定性是两种不同的量。HSSD 训练组 1,272 个种子与查询配对中，JEPA 20 次、直接监督 21 次返程无效；混合组分别为 36、29 次。 | [返程配对统计](return_analysis.json) · [计算程序](return_analysis.py) |
| 是否随目标改变方向？ | 仅比较同一位置上成功路线集合完全不重叠的目标对，分别用正确目标的决策和交换后的决策评分。换目标时视觉匹配线索也随之变化。 | [换目标统计](goal_contrast.json) · [计算程序](goal_contrast.py) |
| 保持第一条路线相同，走后的记忆更新是否有帮助？ | 固定同一模型的首选，在同一真实返回位姿比较它更新后的第二选择与从起始排名中选取剩余最高分路线。分别统计了改选比例、累计发现和额外见到不同实例的机会，以及返程无效时的已知结果。 | [记忆消融](memory_effect.json) · [计算程序](memory_effect.py) |
| 预测的到底是路线外观还是目标？ | 将同一路口两条路线的未来特征与真实画面配对，同时与错配未来、直接监督及复制起点视角对照，并检查预测误差变化与找目标得分变化的关系。 | [未来视觉表征诊断](latent/README.md) |

HSSD 校验使用真实搜索、返程和返回后第二段。Blender 每条路线的 28 步搜索及 40 步返程经过物理执行，第二次选择使用已验收同一分岔的分支记录。Blender 在线记忆读取已选去程四个时刻的画面与沿途碰壁，返程只推进时钟。HSSD 的记忆同时读取已选去程与真实返程的视觉线索和碰壁。两种环境分别计分。
