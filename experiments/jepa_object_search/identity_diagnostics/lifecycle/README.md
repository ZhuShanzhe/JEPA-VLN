# 实例登记、复看与上报

## 两个 HM3D 完整回合

| 原有开发回合 | 候选 → 登记 | 实际复看 | 物理上报 / 新实例得分 |
|---|---|---|---|
| 时钟 | 6 → 1 | 4 次启动，3 次抵达后身份确认未通过，1 次因位姿或目标估计变化结束。17 个复看动作都有一致的执行回执 | 0 / 0 |
| 指定画作 | 5 → 0 | 5 个候选均来自两张没有指定画作的源图，其中 2 个被拒绝、3 个缺有效审阅，没有触发已登记实例的复看 | 0 / 0 |

时钟首次抵达的复看已核对源图、终点和仿真实例编号。源图点击命中正确实例，新视角中的同一实例在可报告距离内，现场匹配返回 `no_current_instance_match`。另外两次失败仅由程序原因码统计。这两个完整回合的位姿 JEPA 身份评分调用均为零。

## 报告回执与实例记忆

采用当前实验适配器、合成 RGB、预输入候选框和受控位姿进行检查。发出报告动作时实例保持待报；动作被替换时允许重新报告；收到正确动作回执后登记一次，重复回执仍只有一条记录。旧实例的重复请求被拦截，单独登记的相邻同类实例仍可报告。另有 11 项隔离检查通过，包含同帧分离、旧实例别名及重复、错误和过期的动作回执。

两例闭环都没有走到真实报告动作。回执证明执行过上报，独立的仿真计分还检查报告地点。以历史物理对照看，错误登记的源图碰巧在另一真实目标附近报告也得了 1 分。评估须同时保留源图与终点是否对应同一实例、是否实际发出报告、评测器是否给分。
