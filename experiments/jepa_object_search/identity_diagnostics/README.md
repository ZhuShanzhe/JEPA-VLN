# 跨视角实例记忆与身份确认

机器人第一次记住一只钟，再从门侧看到一只外形相似的钟。这一环节要判断两个问题：能否认回原来那一只，以及能否把墙上另一只同款钟留作独立实例。当前失误主要发生在**登记之后、上报之前的现场身份确认**。靠近和增加参考图可帮助部分样例，误认邻居仍会污染记忆。

## 数据与证据

| 对照 | 样本 | 可回答的问题 |
|---|---|---|
| [同物换视角](positive/README.md) | 既有 HSSD 16 栋留出房屋，192 对、124 个实例 | 两端框住正确物体时，现用的模板和局部特征在哪道检查失去对应 |
| [近邻同类与同款物体](negative/README.md) | 既有自然房屋构建 365 个竞争样例；8 栋留出房屋、10 个受控布局构建同款干扰及移除干扰物对照 | 拒绝匹配、认回旧实例和误认邻居能否区分 |
| [定向复看与记忆更新](revisit/README.md) | 重新渲染 13 栋留出房屋中的 10 只时钟和 26 件墙面艺术品，共 168 套 RGB、深度与像素身份图 | 走近、侧移或补存过渡视角，是否让同一实例更容易认回 |
| [登记、复看与上报](lifecycle/README.md) | 2 个既有 300 步 HM3D 回合；另以受控输入检查记忆状态 | 真实回合走到了哪一步，报告回执能否正确写回 |

各面板有房屋和实例重叠，单个物体可产生多个对照。数据用于开发诊断，不相加为独立导航回合。冻结上层模型、检测器和当前身份匹配器，沿用既有限值。确认为同一实例、暂缓和误认分别统计。

## 主要发现

1. **跨视角对应容易断。** 在 192 个同物对上，使用可见标注框，同一个确认器在原图回输时认对 156 次，换视角后认对 49 次。132 次返回没有当前匹配，其中 83 次在正确裁块间找不到足够的双向特征对应，30 次已有对应但无法支持一致的几何变换。这两项是局部特征分支里最常见的拒绝原因。历史时钟回合首次复看已经进入可报告距离，独立真值也确认同一只钟在画面里，匹配环节仍拒绝。画作回合在实例登记前中断，两例都没有触发位姿 JEPA 身份评分。
2. **记住类别外观不足以区分同款实例。** 在登记图中同时放 A 和同款邻居 B，复看时保留 A、移除 B。对同一复看图分别询问 A 和 B。在 82 组可核对的组合上，使用真实检测框，仅 21 组既认回 A 又拒绝把 A 当成 B，19 组用 B 的参考也接受了 A，42 组对两种参考均暂缓。两端使用标注框后仍有 21 组用 B 的参考接受 A。它们是身份确认器的错误接受；最终记忆是否误并还取决于后续几何检查与写回。
3. **多存一张图有收益也有代价。** 在新采的 89 次目标可见复看中，真实检测框配合单张参考认对 27 次，允许吸收一张已被当前确认器接受的过渡图后认对 29 次，同时出现 1 次错认。同一物体同时在靠近与同侧横移机位可见的 27 组中，有 11 组只在靠近后认回，12 组两个位置都没有认出。过渡图要保留身份来源及冲突信息。
4. **报告写回可单独验收。** 在可控输入下，正确回执只写入一次，错误回执后可重试，相邻且独立登记的实例仍可上报。两个真实回合均无上报动作，其日志不能估计真实运行中的重复上报率或误合并率。

## 身份模块的训练重点

给定登记时的目标局部特征、当前候选的 RGB 裁块及可用的相对位姿、深度，学习跨视角身份验证；若两者是同一物体，动作或视角条件下预测的局部特征应与实际复看的特征相符。训练房屋采集换角度的同物正例，并将同帧同款邻居、原物离开画面而同款邻居仍在场的组合配成困难负例。推理输出“原实例”“不同实例”“证据不足”，只在身份得到支持时更新已有记忆。与使用相同输入和同等监督数据的直接身份分类器比较。开发面板已用于定位问题，后续最终评估应另留未参与训练及方法选择的场景。
