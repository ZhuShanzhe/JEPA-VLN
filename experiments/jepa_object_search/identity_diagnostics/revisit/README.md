# 时钟与画作的连续复看

在 Habitat 中，从项目 HSSD 留出划分选择有合格登记机位的房屋。每屋每类最多选两个不同的物理实例，按稳定哈希选实例与起始机位。选取过程只依赖场景记录。保留原登记视角，另从该位置在导航网格上尝试同侧横移、向另一侧横移和向物体靠近。每个新机位朝向目标真实中心，这给出了适合诊断的拍摄方向。导航策略实际选路和走完整条路径的能力需在闭环另测。

| 数据 | 数量 |
|---|---:|
| 项目留出房屋 | 13 |
| 不同物理实例 | 36（10 只时钟、26 件墙面艺术品） |
| 预定视角 | 180 |
| 实际保存 | 168（36 个登记视角、35 个过渡视角、97 个复看视角） |
| 缺少不同可用机位 | 12 |
| 复看图中原实例达到可见标注要求 | 89/97 |

每个机位保留 384 × 384 RGB、深度、像素级物理实例编号、相机参数和同类可见框。全量读回后逐框对照像素掩膜，260 个标注框及 168 套观测通过验收。同一实例各机位间距至少约 10 厘米。原始观测、标签、冻结选样清单和逐次判定留在科研数据盘。该组与先前多类别面板使用同一留出划分，不能再用于无偏评估基于它选出的模型或阈值。各个视角可来自同一个物体。

## 单视图与双视图记忆

所有方案使用同一冻结的局部外观确认器、同一批复看画面与同样的现场候选。真实检测条件用 Grounding DINO 的原配置供框；登记时离线选择可唯一对应指定物体的首个真实检测框，现场确认器无法查看身份编号。36 个实例中有 5 个缺少可用的起始检测参考。标注框条件只作为离线输入干预。两种输入条件都按全部 89 次可见复看来评分。

| 参考图进入记忆的条件 | DINO 正确 / 错认 / 暂缓 | 标注框正确 / 错认 / 暂缓 |
|---|---:|---:|
| 仅保存登记图 | 27 / 0 / 62 | 31 / 2 / 56 |
| 允许补存一张被当前确认器接受的过渡图 | 29 / 1 / 59 | 35 / 2 / 52 |
| 过渡图所选框由标注指认，仅供诊断 | 32 / 0 / 57 | 38 / 2 / 49 |

补存方案按时间顺序处理过渡图，遇到错误接受也照常写入；若两张参考认出的候选有冲突，输出暂缓。它是独立的记忆更新对照，没有接入正式导航模型。在真实检测条件下，新增参考使 3 次暂缓变正确、1 次正确变暂缓、1 次暂缓变错认。以房屋为单位等权计算，正确率差为 +3.1 个百分点，成对重采样 95% 区间约为 −1.5 至 +9.0 个百分点。对于未达到可见要求的 8 个复看机位，各组均暂缓。

## 靠近与横移

只用首次真实检测参考，向物体靠近时正确确认 17/33，同侧横移后 4/27，另一侧横移后 6/29。进一步限定为同一物体在两种位置均达到可见标准：

| 成对比较 | 实例数 | 两个机位均正确 | 仅靠近正确 | 仅横移正确 | 两个均未认出 |
|---|---:|---:|---:|---:|---:|
| 靠近与同侧横移 | 27 | 4 | 11 | 0 | 12 |
| 靠近与另一侧横移 | 26 | 5 | 9 | 0 | 12 |

在这些定向机位，仅保留第一张参考时，靠近能帮助部分实例；仍有许多实例两个机位都未能认回。该比较同时改变距离、可见细节及投影，不单独识别任何一个因素的因果效应。

## 重跑

依次执行以下步骤，输入路径指向科研数据盘上的既有项目及兼容的 HSSD 资产。

1. 在 Habitat 环境运行 `python collect.py PROJECT HSSD_ASSETS PRIVATE_DIR`，建立带像素真值的复看序列。
2. 在项目评测环境运行 `python score.py PROJECT PRIVATE_DIR results.json`。本地检测模型与数据均已在项目中提供。
3. 在 Habitat 环境运行 `python verify.py PRIVATE_DIR PROJECT verification.json`，核对图像、实例标签、分房划分和成对对照。
