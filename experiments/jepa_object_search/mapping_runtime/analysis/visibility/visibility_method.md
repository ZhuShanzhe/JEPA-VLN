# 基线轨迹的离线可见性回放

回放仅消费原评测器已接纳的 MOST-Nav 回合。工作进程校验冻结清单、回合身份及结果 SHA-256，随后用同一 Habitat 配置、房屋、初态和动作重放。导航动作调用原版环境，报告和结束沿用原评测语义。语义图和标注参考位姿始终与策略进程隔离。

相机宽高从 1280×1280 等比降至 320×320 读取语义标签，安装位置、朝向和 120° 水平视场与策略的 RGB 相机一致。逐步核对动作前相机载体的位置，容差为 2 毫米。每回合最多抽取 12 帧 RGB 与原服务保存的实际输入比对，缩放到 64×64 后平均绝对差需低于 3/255。末端位置也与原轨迹核对。

| 字段 | 含义 |
|---|---|
| `count_exposed.any` | 路径上至少一次出现一个标签像素的不同合格实例数。极小掩膜仅能支持曾进入视野。 |
| `count_exposed.moderate` | 同一实例连续可见于至少两个不同相机位姿，每个位姿均占至少 103 像素，约 0.10% 画面。 |
| `count_exposed.large` | 同一实例连续可见于至少三个不同相机位姿，每个位姿均占至少 512 像素，即 0.50% 画面。 |
| `annotation_control_instances_with_10px` | 回放结束后，对每个合格实例均匀抽查最多 12 个标注目标视点。至少一帧包含 10 个该实例像素的实例数。 |
| `incomplete_with_moderate_exposure_meeting_k` | 未报够配额的回合中，路径上至少有 K 个真实实例达到持续曝光标准的回合数。还需结合到达报告半径、候选池、报告动作核对。 |
| `incomplete_below_k_even_allowing_unconfirmed_references` | 未报够配额且持续曝光不足 K，即使把全部参考核验不足且未达到持续曝光的实例计为曝光，仍达不到 K 的回合数。 |
| `incomplete_below_k_unresolved_reference_coverage` | 未报够且持续曝光不足 K，参考核验不足可能影响这项划分。 |
| `windows_first_moderate_exposure` | 真实 VLM 成功应用前沿选择、当时至少有 2 个合法候选；在选择后的下一帧至后续决策帧之间，至少一个有效实例首次达到持续曝光。 |
| `windows_first_any_without_first_moderate` | 同样的决策区间内，出现了此前从未露面的实例，但没有实例首次跨过持续曝光线。 |

上面三个对失败回合的划分互斥，并与配额计分共用原任务的合格实例集。多线路决策区间的区间数与回合数分别统计。一个实例的首次露面、首次持续曝光与首次大面积曝光可以发生在不同区间。朝向相同、位置相同的重复帧不会增加持续曝光所需的不同位姿数。

语义像素只能证明相机接收了与目标相对应的区域。可辨识的细节、物体类别及属性是否被模型识别，以及另一个方向是否更好，均需要独立证据。官方达标距离以目标标注的导航观察点为准，靠近这些观察点与当前视野中出现标签可以有差异。

逐例私有证据在 `native_20261115/verified/`，无轨迹或实例标识的汇总在 `native_20261115/aggregate.json`，按类别与属性任务分别计算。核验出错的回合进入 `native_20261115/issues/` 并保留原日志，只对核验完成的回合计算曝光统计。
