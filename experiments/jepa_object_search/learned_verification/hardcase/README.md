# 小登记框的 HM3D 物理分支

在上一版时钟闭环第一次到达复看机位、但当前实例匹配失败的案例中，从同一历史起点分别执行几何、直接监督、JEPA 选择的路线。该实例的登记框仅占整幅图的 0.317%。三个分支共用 12 步上限、可选路线、冻结检测器和原有局部外观门控。接触障碍时仍可能沿墙移动，前进的实际位移低于 0.005 米时结束该分支。

当时的完整在线占用图未持久化。回放使用起点之前的已走通道、理想前缀里程计及当时已规划的原路径作为保守可达地图；目标方向和登记机位使用当时系统的在线估计。选择时没有使用目的机位的真实图像、目标语义位置或裁判视点。两个候选都包含前进动作。只比较一次选路后的实际运动和识别，不进行第二次重规划。

| 策略 | 执行动作 | 实际平移 | 终点同一语义标签像素（含木台面） | 最佳检测框覆盖的同标签像素比例 | 外观通过 |
|---|---:|---:|---:|---:|---|
| 原几何路线 | 3 | 0.069 m | 17,968 | 5.01% | 否 |
| 直接监督选路 | 3 | 0.069 m | 17,968 | 5.01% | 否 |
| JEPA 选路 | 1 | 0.000 m | 11,693 | 8.15% | 否 |

几何与直接监督选择相同路线，两次前进发生接触但有小幅平移，重现原运行真实终点。JEPA 选择另一条地图上可行的方向，首次前进没有位移。该分支没有抵达拟议机位，无法据此评价那个机位本身的视觉质量。所有分支的最终位置满足裁判距离，均未获得足以通过外观门控的新证据。该观察只覆盖一个已经固定的失败案例。

**撞停后的单次改选。** 在单独回放中，把首次无位移的前进边暂时标记为阻断，从同一候选集选择另一条路线。剩余 11 步内有 1 条可选，实际再走 3 步，整个分支使用 4/12 步、平移 0.069 米。终点能看见原几何路线的同一只钟。5.01% 的分母包括与钟面分离的木台面标签像素。复核发现钟面所在的两个分量共 905 像素，检测框覆盖 901 个。现场外观门控仍暂缓报告。[RGB 与语义标签复核](../../region_proposals/README.md) 该分支检验了卡住以后恢复移动的能力。
