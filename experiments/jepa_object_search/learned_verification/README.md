# 多实例寻物中的主动验证

机器人发现疑似目标后，先判断已有证据是否足以确认实例。证据不足且存在可定位的线索时，从记忆地图生成几条可达短路线，比较走到各终点可能获得的局部视觉证据，执行其中一条，再用真实新图复核。探索选路、验证选位和实例上报使用独立接口，共用回合的动作预算。

| 环节 | 输入 | 实际输出 |
|---|---|---|
| 发现候选 | 历史关键帧、目标类别、完整文字描述 | 冻结 Grounding DINO 产生物体框，训练的排序器挑选送审框，可选用 CLIP 检查描述属性。上层同时看到编号、原图和框。[候选模块](candidates/README.md) |
| 决定去哪里验证 | 记忆中的参考框、在线估计的目标位置、已探索地图、候选动作 | 地图生成返回旧机位、靠近或换角度的可达方案。JEPA 依据参考图和相对运动预测未来局部表征，并给机位排序。另训练了利用框外上下文的弱线索头。[局部头](active/README.md) · [弱线索头](active_weak/README.md) |
| 执行并审核 | 实际运动回执、新 RGB 图、原候选身份 | 遇阻可在剩余步数内换路。已登记实例通过新图复核后才发起报告；上层曾标记为存疑的实例，将新图及其帧号交回审核。一次复看最多 12 个真实动作。[导航接入](integration/README.md) |

## 验证结果

| 检验 | 结果 | 反映的问题 |
|---|---|---|
| Habitat，疑似时钟的主动复看 | 同一正确源框，当前画面看不到该钟；局部头走 11 步后新图出现 3,710 个该实例像素，上下文头走 6 步后出现 3,218 个。 | 四组正误源框都把实际到达帧交回审核。获得新证据与确认实例是两个独立结果。[实际动作与交接](integration/uncertain_physical_results.json) |
| HSSD，16 栋留出房屋 | 338 组正确起始框中，局部 JEPA 再检出率 84.32%，同输入直接监督 83.73%，最大前向位移 84.91%。 | 机位有价值，但尚无可靠证据表明预测未来特征比直接学习机位得分更好。[同预算结果](active/detector_transfer.json) |
| HSSD，同一检测器给出的 41 组真实碎框 | 局部 JEPA 找回 26 组，弱线索 JEPA 30 组，同配方直接监督 29 组。每组都从同样两个终点选一个。 | 专门针对错框和碎框训练有帮助。与直接监督相比，房屋间差异较大。[弱框结果](active_weak/README.md) |
| PInVerify 跨环境单次选位 | 18 组起始框准确时，局部 JEPA 及直接监督均为 17/18；弱线索 JEPA 为 10/18。6 组起始框不准时，弱线索 JEPA 与同配方直接监督均为 1/6，原局部 JEPA 为 0/6。 | 清晰线索通常已经够用，错误线索仍很难找回。弱线索头保留为单独实验配置。[外部检验](external/README.md) |
| HM3D 时钟物理回放 | 地图预测可走的一条边实际受阻；改选后共走 4 步，可见目标像素达 17,968，检测框仅覆盖约 5.01% 目标，实例审核未通过。 | 机器人能恢复运动，但碎框仍不足以匹配记忆中的同一只钟。[时钟回放](hardcase/README.md) |
| HM3D 画作观察覆盖 | 旧轨迹的 274 张关键帧均无指定画作像素。在旧轨迹首次进入合法距离的位置，原地转向及俯仰所得 13 幅图同样没有拍到它。 | 这个位置缺少可见证据，需要移动到其他观察位置；更换审核模型无法从这些帧选出指定画作。[观察覆盖](external/README.md) |

## 当前适用范围

训练数据使用 HSSD 官方训练场景，按房屋划分训练、校准和留出测试。PInVerify 检查一次选位后的重定位，Habitat 检查短程实际移动和复核。报告采用相同候选、相同动作预算的模块比较。当前尚无本组合策略的完整 300 步任务成功率。

优先改进两个环节。一是收集时钟等小目标在**当前错框、换角度后出现完整轮廓**的真实样本，并保留旁边相似物体作为负例。二是当目标从未入镜时，让探索器选择可平移到的互补视点。候选辅助负责多提供一次看清和送审的机会；指定属性和同一实例的最终判断继续使用完整任务描述、原证据和新图。[研究依据](literature.md)
