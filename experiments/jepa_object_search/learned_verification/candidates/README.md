# 供上层审核的历史图像与区域

每次上层作决策时，从本回合已经拍摄、已入图且可查看的帧中，检查最多四张新图。机器人拍摄时缓存微缩 RGB，与建图服务返回的同号源图比较后才进行推理。Grounding DINO 产生类别框，线性排序头估计局部框覆盖目标的可信度。可选的冻结 CLIP ViT-L/14 对最优框及其邻近上下文检查完整目标，与清晰可混淆的描述比较。上层可同时收到最多两个已有帧号、一张区域预览，用原生工具复核目标属性、选择分割区域及决定是否登记。

组合入口使用 `candidate_scout:CandidateScoutMixin`，位于 `ActiveFrontier` 之前。原运行环境须启用 `NAV_LOCAL_BOXES=1`。默认沿用原有决策。设置 `NAV_SOURCE_SCOUT=1` 启用完整目标筛选，`category_only` 仅用于类别消融。没有可靠框或视觉模型不可用时，保留原有决策流程。该模块无需付费服务，仍需上层负责复杂描述、不同实例和最终语义审核。

## 训练与 HSSD 留出房屋

沿用已验证的缓存 Grounding DINO 检测，使用 HSSD 训练集 10 栋房屋、180 帧上的 381 个预测框训练带 L2 正则的逻辑回归。输入为原检测分、相对面积、宽高比、边缘距离、全图或切片来源、框中心水平与垂直偏移。监督为该框能否以 IoU 至少 0.5 覆盖一个当前类别的标注实例。6 栋验证房屋确定排序器和送审阈值，16 栋测试房屋单独评估。这一监督学习的是类别定位质量，细粒度属性由第二级处理。

| HSSD 测试指标 | 原检测分 | 训练排序 |
|---|---:|---:|
| 244 张正例图中成功定位 | 163 | 180 |
| 提供候选的帧数 | 203 | 235 |
| 推荐精确率 | 80.3% | 76.6% |
| 44 张空帧中的误推 | 13 | 16 |
| 每 4 帧仅审 1 个框，31 个窗口中的定位命中 | 27 | 30 |

最后一行是按房屋和类别构成的离线固定名额窗口，31 个窗口都含正例。不能用该行估计连续导航或房间中无目标时的表现。[分割与完整计数](hssd_quality.json)

## 重建排序参数

在服务器的候选模块目录运行以下命令。`NAV_ROOT` 指向研究项目根目录，`jepa_reid_v21/data/frames.jsonl` 提供带房屋划分的标注，`jepa_reid_v21/detector/predictions.jsonl` 提供冻结检测框。使用安装 NumPy 的 Python。训练脚本按验证集表现选择排序器及阈值，并将参数和统计分别写入输出目录。

```bash
python fit_quality.py "$NAV_ROOT/jepa_reid_v21" --output-dir "$NAV_ROOT/jepa_reid_v25/candidates"
export NAV_SCOUT_SELECTOR="$NAV_ROOT/jepa_reid_v25/candidates/selector.json"
export NAV_SOURCE_SCOUT=1
export NAV_LOCAL_BOXES=1
```

只有启用助手且进入正式决策时才读取参数。文件位置可由 `NAV_SCOUT_SELECTOR` 指定，默认查找模块旁的 `selector.json`。缺少参数时直接沿用上层原有决策。[接口测试](test_scout.py)
