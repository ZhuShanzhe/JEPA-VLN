# 首见记忆与跨视角复核

在每栋房屋内按目标类别建一个空记忆库。输入是已经定位的候选物体框与上下文。按冻结的散列顺序交错呈现不同物体的多个视角。当前画面与库中得分最高的记录达到阈值时关联，否则登记为新线索。每条记录只保留创建时的视角。一旦错误合并或漏认，后续观测会继承这次决定。真实实例编号仅用于构造观测流与事后评分。

| 指标 | 含义 |
|---|---|
| 正确认出重见 | 当前物体此前已出现，且成功关联到同一物理实例的记录。分母是所有重见观测。 |
| 首见误合并 | 某件物体第一次出现即被归入另一件物体。分母是全部不同物体。 |
| 错误合并总数 | 所有关联到错误物理实例的次数，包含首次出现和后续重见。 |
| 额外记录 | 当前物体在库中已有记录，却被再次登记。 |

阈值分别用 6 栋校准房屋选择。每种方法先满足首次出现的物体被误并的比例不超过 2%，再选择正确认出最多重见的阈值。报告 16 栋测试房屋上的实际比例。跨视角方法与直接监督使用同一编码器、输入和观测顺序。按房屋配对重抽样 5,000 次计算差值区间。

| 程序 | 验证内容 |
|---|---|
| [first_memory.py](first_memory.py) | 首次登记、后续匹配、错误累积及多实例级阈值。 |
| [identity_audit.py](identity_audit.py) | 同款异物、不常见资产、墙面艺术品等子组。替换背景实验固定物体特征，在同物正例上换入其他实例的背景，在异物负例上换入首次观察的背景。 |
| [context_refiner.py](context_refiner.py) | 冻结跨视角预测器，分开比较物体与遮罩后的背景，再训练一个复核器。训练时将负例权重的一半分给同一资产的不同物理实例。 |
| [geometry_memory.py](geometry_memory.py) | 相同深度和相机位姿条件下，比较仅位置、位置与冻结特征、位置与直接监督、位置与 JEPA。使用 0.60 米位置门限。额外的水平位置噪声实验是人为扰动。 |

主实验依据 Habitat 真实渲染图像构造观测序列；出现顺序不对应机器人实际经过的轨迹。这里的重见识别数、重复登记数与机器人行动步数分别计量。
