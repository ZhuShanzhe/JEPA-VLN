# MOST-Nav 跨视角实例复核

入口为 `reid_agent:ReIDFrontier`，继承 `report_agent:ReportFrontier`。当原始映射器取得新目标框并提出重复复核时，模块将它与唯一邻近实例的首次登记图像比较。目标框每侧扩张 15%，周边框每侧扩张 80%，周边图遮去目标。原生框和关键帧均来自地图客户端，视角差取当前对齐坐标系下两次相机光轴的水平转角。

评分只在两份独立图像证据齐全、位姿与尺度有效、三维估计相距不超过 0.60 米且邻近只有一个实例时提交原决策器。不同目标绑定、同帧互斥框、多个附近实例及低置信分数均交原流程处理。原决策器仍可选择建立新实例。独立确认重复后，系统将新观测附到原实例；原实例已经执行过报告时，回访请求转入探索；尚未报告时继续保留该实例。此适配器不执行目标检测。

在原 V19 环境变量和 `PYTHONPATH` 的基础上加入当前目录。显式设置 `NAV_REID_WEIGHTS=$NAV_ROOT/jepa_reid_v20/model/jepa.pt` 可启用。图像编码子进程使用已有策略环境，通过本地管道传输对象与周边图。可用 `NAV_REID_PYTHON` 指定策略解释器，默认 CPU，可选 `NAV_REID_DEVICE`。未启用时沿用原流程。

- `check.sh` 检查已有报告的再次访问、首次记忆、新实例保护、歧义、去重裁决和姿态接口。
- `check_worker.py` 在原评测解释器中载入策略解释器及实际权重，以一个预先按清单顺序选定的留出图像对检查接口。
- `audit_archived.py` 核对原时钟和画作回合在报告当时已经具备的独立候选框。
- `detector_audit.py` 使用固定 GroundingDINO 在保存的 RGB 画面上补提候选，按已执行动作估计相对转角，输出所有候选分数。该诊断没有独立实例标签，也未改变历史行动。
