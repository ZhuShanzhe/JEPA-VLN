# 跨视角实例匹配

首次看到物体时保留目标裁图、周围环境裁图与相机朝向。后续检测到同类物体时，根据两次朝向之差预测另一视角的视觉特征，并将预测与观测到的特征比较。

| 环节 | 实现 |
| --- | --- |
| 视觉编码 | 冻结 DINOv2 ViT-B/14。目标框四边各扩原框宽或高的 15%，提取分类标记与平均图块特征。环境框各扩 80%，遮住其中的目标框后提取分类标记。三部分分别归一化，余弦权重为 0.425、0.425、0.15。 |
| 跨视角预测 | 输入一个视角的特征和两次观测的水平朝向之差，对目标和周围环境的联合特征做残差预测。双向预测各自只读取起始观测和朝向变化，最后对两次预测与对应真实观测的余弦取平均。 |
| 训练 | 所有样本用二分类损失监督同一实例或不同实例。正样本另用余弦距离监督预测的另一视角特征，损失权重 3。特征提取器完全冻结。 |
| 对照 | 直接比较冻结特征，或用同一架构与相同正负对只做二分类训练。仅目标的 JEPA 使用相同优化设置，置零周围环境特征并重新归一化。 |
| 配对 | 正例为同一实例且两次相机朝向至少相差 15°。负例为同一房屋、同一类别中的其他物理实例，优先匹配正例的查询方向。每个起始视角最多取五个正例和相同数量负例。 |
| 标定 | 房屋级隔离训练、验证及测试。使用验证集 5% 误合并率以内的标准化部分 ROC 曲线下面积选择轮次，使用该验证集使召回最高且误合并率不超过 5% 的阈值。 |

`train.py` 接收项目根目录、采集清单及输出目录。视觉权重来自项目已有的 DINOv2 本地缓存。预训练权重和推理环境只需加载一次。输出包括验证与测试得分、特征缓存、三种学习方法的模型权重及指标。每个切分按冻结清单顺序索引图像。运行时需要上游检测框和两次相机朝向；仿真真值标识只用于构造训练样本和评估正确性。所有阈值适用于候选匹配对，记忆库有多个可能实例时应另外检查整库误合并率。

`reid_model.py` 提供推理接口，`mask_context` 接收 RGB 环境裁图及原始目标框在裁图中的像素坐标。`load_matcher(project, weights, device)` 加载编码器和 JEPA 预测头。`compare` 接收两个目标 RGB 裁图、带符号的相对朝向（度）和两个遮罩后的环境 RGB 裁图，返回分数、验证阈值与匹配判定。

## 首轮结果

训练、标定和测试分别涉及 28、6、16 栋互不重合的房屋。测试含 15,121 对同一物体与 15,121 对同屋同类的不同物体。表中识别率是同一物体被正确认作已见的比例，误合并率是不同物体被误认成同一个的比例。各模型分别使用自己在标定房屋冻结的阈值。

| 方法 | 同一物体识别率 | 不同物体误合并率 | AUROC |
| --- | ---: | ---: | ---: |
| 冻结 DINOv2，物体与环境联合余弦 | 19.22% | 4.56% | 0.765 |
| 同架构直接监督 | 42.33% | 7.59% | 0.846 |
| 加跨视角 JEPA 训练目标 | 37.45% | 7.59% | 0.802 |
| 只保留物体输入的 JEPA | 34.46% | 7.02% | 0.795 |

跨视角 JEPA 的预测与另一视角真实特征的平均余弦为 0.731，直接沿用当前特征为 0.688。直接监督在识别身份时召回更高。按房屋成对重抽样 5,000 次，JEPA 相对直接监督的识别率差为 −4.88 个百分点，95% 区间为 −8.23 至 −0.99 个百分点。

同一物体在背景变化较大的观测中识别率为 18.61%，背景变化较小时为 53.86%。两组按标定集中同一物体正例的背景余弦中位数划分。朝向相差 15° 至 30° 时识别率为 52.97%，相差 100° 至 180° 时降至 29.91%。不同物体若使用同一套三维模型，误合并达到 20.66%（882/4,270）；使用不同模型时为 2.44%（265/10,851）。壁画识别率为 40.38%（508/1,258），画框为 2.56%（4/156），两类应分别报告。

`heldout_summary.py` 按场景重抽样，并统计相同资产、训练未见资产及类别的表现。`score_extra.py` 使用已有权重及阈值评测补充观测。`replay_depth.py` 在标定和测试场景中回放 RGB 与深度，先与原始 JPEG 逐像素比对，再用框内中位深度附近的真实像素回投三维坐标。4,974 份观测全部通过逐像素校验并取得深度。三维结果代表可见表面，采用仿真精确相机姿态。
