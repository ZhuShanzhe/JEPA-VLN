# HSSD 跨视角实例观测

`build_dataset.py` 读取项目已固定的 HSSD 房屋划分。三个子集均来自 HSSD 官方训练房屋，复用 28 栋训练、6 栋校准、16 栋测试的项目内部划分。脚本检查三组房屋编号及其前缀互不重叠。相同家具资产可能用于不同房屋，`audit_views.py` 统计这种重合。

`collect_views.py` 在 Habitat-Sim 内给场景中的每个刚体赋予独立语义编号。在可导航表面从不同方位看向同一物体，按可见实例像素生成目标框，画面为 384 × 384、75° 水平视场、相机高度 1.25 m。每个实例保留 2 至 6 个视点，每对相机位置至少间隔 0.35 m，从物体中心观察两相机的水平夹角至少为 15°。每个入选的房屋与类别组合至少包含两个不同实例。

视觉输入包括向四边各扩展 15% 的目标框裁剪以及各扩展 80% 的局部场景裁剪，越过画面边缘处截断。两种裁剪均保存为 RGB JPEG。上下文图内的原始紧框以左闭右开的像素坐标保存。相机间差角可通过 `camera_heading_deg`（世界前向量的 `atan2(z,x)`）计算。`yaw_deg` 是参考物体中心计算的视点方位，仅用于核查视角跨度。房屋、实例、资产、世界真值位置和语义编号仅用于数据构建和评价。

`manifest.jsonl` 记录每个有效观测的两种图像相对路径、房屋、类别、实例、资产及相机信息。`sampling_protocol.json` 固定房屋和采集器校验值。`audit.json` 记录逐划分数量、图像完整性核查后的清单校验值。`geometry_audit.json` 记录有效不同视角数量、资产重用及相同模板负样本规模。

该任务测量已定位目标的跨视角关联。针对物体定向采样及仿真紧框使其适合测试身份匹配，真实导航中的检测框偏差、实例漏检、长程遮挡和完整导航效果需要分别测量。

## 时钟迁移

HSSD 按壁钟、台钟、闹钟等子类标注时钟。`clock_inventory.py` 检查原生资产和房屋实例。`collect_clock_family.py` 在相同的 16 栋测试房屋合并这些子类，保留同时具有两个可观测时钟实例的 5 栋，共 13 只钟和 53 个视角。主训练、校准和阈值均未使用这些时钟观测。

`clock_pair_audit.py` 读取冻结模型的配对分数和主验证阈值，按照钟表是否同款、是否同子类统计误合并。23 个同款负图对实际来自 2 对独立实物，67 个同子类不同款负图对来自 3 对独立实物，78 个不同子类负图对来自 5 对独立实物。聚合结果见 `clock_pair_audit.json`。
