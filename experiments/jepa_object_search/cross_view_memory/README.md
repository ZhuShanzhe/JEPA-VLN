# MOST-Nav 的跨视角实例记忆

寻找多个同类物体时，将首次可靠观测的物体框、周围背景、拍摄方向和地图位置存为线索。之后发现一个同类候选，先检查空间上能否对应，再预测从新方向观察时应出现的视觉特征，与实际画面比较。上层确认是同一实例且已有报告回执时，复用原记录，避免为它再次发起回访。未报告的旧线索仍可接近和报告，附近的新实例仍可独立登记。

预测器借鉴了 JEPA 在特征空间预测目标的思路。它在向前和反向预测时各自只读取起始视角与相机朝向变化。冻结的 DINOv2 分别编码物体和遮掉物体框后的周围环境。训练时既预测另一视角的表示，也学习区分同一房屋中的同类实例。[I-JEPA](https://arxiv.org/abs/2301.08243) · [DINOv2](https://github.com/facebookresearch/dinov2) · [模型与训练](model/README.md)

## 样本和对照

50 栋 HSSD 官方训练房屋按项目冻结划分分成 28 栋训练、6 栋校准和 16 栋测试。共 2,259 个物理实例、11,482 次视角观测，每次各有一张物体裁剪和一张背景裁剪。测试包含 734 个实例、3,647 次观测。测试中 503 个资产模板有 414 个未在训练房屋中出现。同一房屋可有多件完全相同款式的家具。物理实例编号用于生成训练标签与计分。[采集与验收](collect/README.md)

### 给定两次观测，是否为同一物体

测试包含 15,121 对同物跨视角观测和 15,121 对同房同类异物观测。每个方法在校准房屋选择误合并率不超过 5% 时召回最高的阈值。表中是测试房屋的实际结果。

| 匹配方法 | 正确认出同物 ↑ | 把异物认作同物 ↓ |
|---|---:|---:|
| 冻结视觉特征，物体与背景 | 19.22% | 4.56% |
| 直接监督，同架构、同输入 | 42.33% | 7.59% |
| JEPA，仅物体 | 34.46% | 7.02% |
| JEPA，物体与背景 | 37.45% | 7.59% |
| JEPA 加分开比较物体与背景的复核器 | 38.71% | 7.44% |

加入背景提高了同物召回，同时带来更多误合并。对物体与背景联合 JEPA，不同款式的异物误合并 265/10,851（2.44%），同款但不同物理实例误合并 882/4,270（20.66%）。固定物体特征、把异物的背景人为替换为首见背景，错误合并从 1,147 对增加到 2,347 对。预测特征与真实换视角特征的平均余弦从直接复制首见特征的 0.688 提高到 0.731，但直接监督的身份识别召回仍高出 4.88 个百分点。[按房屋与类别的结果](model/heldout_summary.json) · [背景替换检验](evaluation/identity_results.json)

### 连续遇到多个同类实例，只保留首次登记视角

190 组房屋与目标类别依次输入共 3,647 次观测。每种方法用同一套首次登记和后续匹配规则，在校准房屋将首次误合并率控制在 2% 以内，再固定阈值。每一次错记都会影响以后的匹配。此处统计的是记忆登记和检索，连续观测顺序由固定规则构造。

| 方法 | 2,913 次重见中正确关联 ↑ | 734 件物体中首次出现被误并 ↓ | 观测序列中额外创建的重复记录 ↓ |
|---|---:|---:|---:|
| 冻结视觉特征 | 127（4.36%） | 9（1.23%） | 2,698 |
| 直接监督 | 514（17.65%） | 22（3.00%） | 2,264 |
| JEPA，物体与背景 | 667（22.90%） | 28（3.81%） | 2,059 |
| JEPA 加背景复核器 | 509（17.47%） | 19（2.59%） | 2,302 |

JEPA 比直接监督多认出 153 次重见，同时首次误并多 6 件。按房屋配对重抽样，重见正确率差为 +5.25 个百分点，95% 区间为 +3.15 至 +7.30。首次误并率差为 +0.82 个百分点，区间为 −1.14 至 +3.41。背景复核器把首次误并从 28 件降至 19 件，也把正确关联从 667 次降至 509 次。按事先设定的校准集选择规则，保留基础 JEPA 作为实验性复核信号。[记忆测试协议](evaluation/README.md) · [记忆结果](evaluation/memory_results.json)

### 时钟与墙面画作

时钟在 HSSD 中有挂钟、座钟、闹钟等细类。单独在原测试划分的 5 栋房屋汇集 13 只钟、53 次观测。沿用主模型权重和主校准阈值，168 对同钟观测中 JEPA 认出 58 对，直接监督认出 116 对。168 对异钟观测中两者分别误并 0 对和 1 对。同款异钟负对仅 23 对。墙面艺术品的主测试中，1,258 对同物观测两者分别认出 508 对和 682 对。时钟和画作上的结果支持继续保留直接监督对照。[时钟子集](collect/clock_pair_audit.json) · [墙面艺术品子组](evaluation/identity_results.json)

### 加上首次观察的位置记忆

重放校准与测试的 4,974 个视角，RGB 裁剪与原记录逐像素一致。用检测区域内的中位深度附近像素和仿真相机位姿回投一个可见表面点。同一物体不同面的表面点可以相距较远。各方法共享位置输入及 0.60 米候选范围，均在校准房屋选阈值。位置基线在此范围内按距离选择；其他三组在范围内分别根据各自视觉分数选择。[深度重放核验](model/geometry_audit.json)

| 记忆匹配方法 | 准确仿真位姿，认对重见 / 首见误并 | 水平位置加入 0.25 米标准差的噪声，认对重见 / 首见误并 |
|---|---:|---:|
| 只按可见表面点的位置 | 1,808 / 14 | 1,109 / 14 |
| 位置筛选 + 冻结视觉特征 | 1,496 / 11 | 1,136 / 10 |
| 位置筛选 + 直接监督 | 1,539 / 11 | 1,442 / 14 |
| 位置筛选 + JEPA | 1,637 / 13 | 1,377 / 14 |

两列分母相同，分别为 2,913 次重见和 734 个首次出现的实例。位置信息干净时，仅用位置认出最多重见。对每个观测独立加入人为水平位置误差后，两个训练过的视觉头都比只用位置多认出重见，此条件下直接监督表现最好。实际 MOST-Nav 使用 SLAM 估计及原生实例位置，其误差来自建图、检测和尺度对齐。人工噪声仅用于测量敏感性。这组几何诊断沿用前述留出房屋，后续架构比较需要另一组独立房屋。[完整结果与区间](evaluation/geometry_memory_results.json)

## 导航接入

适配器接在原生实例重复审核处。当场景里有独立定位的当前候选、仅有一个空间上足够接近的登记实例、且历史与当前关键帧均有观察证据时，才提交跨视角分数给原生裁决器。两个独立登记框或多个邻近同类会保留歧义。确认归入已有实例后，已收到报告回执的实例不再触发专程回访；其余实例仍可发现、接近和报告。[适配器与离线验证](adapter/README.md)

历史时钟和画作回合的三个报告时刻均缺少当帧独立登记框。用冻结 GroundingDINO 离线提取候选，三帧分别得到 1、2、3 个框，训练好的 JEPA 对六对候选均未达到原校准阈值。候选与首见画面之间缺少独立物理身份标签，无法用这些分数给历史回合重新计分。10 项接口检查和使用实际权重的跨环境调用均已通过。完整导航的重复报告率、正确报告的不同实例数与实际消耗步数还需闭环对照。[适配与旧回合核验](adapter/adapter_summary.json)
