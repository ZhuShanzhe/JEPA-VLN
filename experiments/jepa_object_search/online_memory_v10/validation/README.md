# 在线证据与评测覆盖

## HSSD 中有没有“没见过目标也能选对”的题

逐动作重放 4 栋留出房屋的 16 个起点，170 张历史关键帧与原始 RGB 逐像素一致。分别统计类别曾清楚出现、只在小区域出现以及未出现的情况。一格中至少 20 个同类像素归为清楚出现。该标签只在跑完后用于分组。

| 已有关键帧中的目标类别 | 起点、目标与预算组合 | 所有候选收益均为零 | 候选收益相同且为正 | 选对候选能改变收益 |
|---|---:|---:|---:|---:|
| 完全没有像素 | 240 | 240 | 0 | 0 |
| 出现过，任一格均少于 20 像素 | 18 | 18 | 0 | 0 |
| 至少一格有 20 个像素 | 330 | 229 | 3 | 98 |

收益按路线能新到达几个合格实例视点计算。初始画面见过这类物体，可以是见过同类的另一个实例。更贴近“找从未出现的具体实例”的自然房屋结果见[独立探索边界实验](../hidden_hssd/README.md)。[关键帧重放统计](slices.json)

## 写进记忆的视觉线索有多可靠

在同一批 4 栋房屋的 16 个独立全景起点，检验 2,352 个“当前朝向 × 该房屋可核查类别”组合。其中 632 个有可见标注。用当前 RGB 的 49 个局部得分最大值作线索，平均精确率（AP）为 0.515，阳性率为 0.269，AUROC 为 0.721。灯的 AP 为 0.79，镜子为 0.23，时钟为 0.04。时钟只有 3 个阳性视角，误差尤其大。这里的标签为类别可见性；具体实例、颜色或画作内容还需进一步识别。[逐类统计](visual.json)

## 记忆能否被纠正和保存

同一步的重复写入、保存后恢复、跨回合清空及阻塞后实际走通的检测均通过。两个候选先验相同时，交换真实传入的左右证据，左侧相对于右侧的优势从 +0.108 变为 −0.109。两个分支在输入相同的时段产生相同预测。240 步后未刷新的语义线索幅值从 0.384 降到 0.000375。此检查直接提供左右证据，用来隔离记忆更新逻辑。实际图像输入的表现另在 Blender 和整机条件下检验。[接口实测](memory_contract.json)
