# 路线内获得新实例视点的概率

输入当前及历史 RGB 的视觉证据、目标词和一段候选动作。输出该动作序列在指定步数内能否进入至少一个新增的、符合实例目录要求的视点的概率。标签来自实际执行路线，计入阳性和阴性。前方物体实际存在、成功报告物体以及探索新区域的奖励分别是不同事件。

12 个 HSSD 房屋用于拟合逻辑回归，4 个独立房屋用于拟合随步数变化的 Platt 概率校准，另 4 个房屋用于评估。每个起点、目标与预算下只保留一条完全相同的名义动作前缀，所有重复前缀物理标签一致。在测试的 5,888 条记录中有 374 条阳性，仅 16 个独立起点。场景中缺少目标类别的合法阴性也计入。校准集有一个房屋的一个类别目录无法核实，该类别对应的 92 行已排除。

两个视觉模型使用相同的房屋划分、打分头结构、动作几何和目标视觉记忆。一个读取原 V8 的观测加 JEPA 预测分数，另一个读取仅基于观测的 V8 分数。两者均不加入探索奖励、房屋中的目标存在标记或未来观测。

| 预算 | 阳性/总数 | 实际阳性率 | Brier（频率 / JEPA / 仅观察） | AP（频率 / JEPA / 仅观察） |
| --- | ---: | ---: | ---: | ---: |
| 4 步 | 50/1,280 | 3.91% | 0.0382 / 0.0349 / 0.0347 | 0.039 / 0.208 / 0.239 |
| 12 步 | 158/2,304 | 6.86% | 0.0651 / 0.0563 / 0.0547 | 0.069 / 0.321 / 0.338 |
| 24 步 | 166/2,304 | 7.20% | 0.0680 / 0.0596 / 0.0581 | 0.072 / 0.315 / 0.332 |
| 全部 | 374/5,888 | 6.35% | 0.0604 / 0.0529 / 0.0517 | 0.070 / 0.302 / 0.320 |

Brier 越低，概率对真实结果的平均平方误差越小。AP 越高，正例在排序中越靠前。两个视觉模型均优于只按步数给固定概率的对照；三个预算下，仅观察的对照均略好。JEPA 模型平均预测 4.14%，低于实际的 6.35%。这些记录来自同一批分叉上的多个候选动作，不能按 5,888 个独立场景解释。
