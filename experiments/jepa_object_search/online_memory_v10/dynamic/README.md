# 目标换位与现场记忆

Habitat 在同一场景中交换杯子和沙发的位置，目标实例身份随物体移动。机器人和相机保持连续，前往岔路与返回都使用动作。配对的另一组保持物体原位。给模型的输入只有 RGB、动作、里程计、当前目标和碰撞记录。每次需要判分时，仿真器从相同状态独立执行两条候选路线，用真实可达轨迹、实例是否有至少 64 个可见像素以及水平距离是否在 2 米内确定结果。

| 数据 | 房屋与序列 | 评价内容 |
|---|---:|---|
| V10 冻结模型压力测试 | 4 套训练房 48 条供后续使用，另 2 套测试房 24 条 | 杯子与沙发交换后能否更新选路 |
| 完全遮挡目标的先验训练 | 8 套全新训练房 144 处起点，6 套全新测试房 108 处起点 | 只看入口线索能否选中有目标的分支 |
| 现场证据更新器 | 另 6 套全新测试房，72 条搬动与原位序列，左右两种首探顺序各重放一次 | 先验能否经真实视觉反馈修正，再选路时多走多少步 |

在第一组测试中，两组观察照片在第 183 至 184 步才首次出现差异。在此之前七项对照的预测完全一致。调换后重新看完两个区域，V10 正确 12/24，静态先验和纯探索也各为 12/24。独立可见性诊断使用 238 张去重 RGB。原视觉头对杯子是否可见的 AUC 为 0.964，对沙发为 0.775。对应的选路表现见 [动态测试](dynamic_summary.json) 与 [识别诊断](perception_diagnostic.json)。

程序按 `collect_streams.py`、`score_streams.py`、`evaluate.py` 顺序执行。`diagnose.py` 读取额外渲染的实例图统计和已冻结的相机打分。48 条备用训练序列中，12 条在换位当帧有可观察差异。上述两套动态测试房的所有换位在该帧均不可见。

先验训练和另六套房的现场更新详见[隐藏目标选路与动作成本](hidden_goal/README.md)。

在真实三岔路房屋中最多选两条分支的测试见[三分支限预算寻物](multi_branch/README.md)，其中包括目标缺席和多实例查询。
