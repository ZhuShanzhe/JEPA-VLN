# 三个候选区域的限预算寻物

Blender 生成一个有三处岔口入口的整体房间，Habitat 中的三条候选路线均从同一位置出发，各前进 5 米。开局真实转动相机扫描 12 个方向，目标和干扰物的可见像素均为零。智能体可以从房间布置推断目标位置，再前往一个分支检查终点。它依据新拍摄的 RGB 决定是否报告；仍要搜索时，实际退回岔口、选择未走过的另一侧。每个查询最多检查两条分支。

训练用 6 套房、252 个摆放，测试用另外 4 套房、168 个摆放。每个摆放分别寻找杯子和沙发。336 个查询由 240 个单实例、48 个多实例和 48 个目标缺席组成。多实例查询找到任意一件即可。红椅作为干扰物。五种策略各运行 336 次。一次前往花 28 步，两次前往之间返回花 40 步，算上起始扫描最多 108 步。

| 同一任务集上的策略 | 首次命中，有目标 288 次 | 两次内找到并正确报告 | 目标缺席时误报，48 次 | 每条查询平均动作数，含开局扫描 |
|---|---:|---:|---:|---:|
| 未来视觉特征预测先验 + 近期证据更新 | 208 | 248 | 0 | 65.90 |
| 直接监督先验 + 同样更新 | 208 | 248 | 0 | 65.90 |
| 未来视觉特征预测先验 + 排除已访区域 | 208 | 248 | 0 | 65.90 |
| 直接监督先验 + 排除已访区域 | 208 | 248 | 0 | 65.90 |
| 均匀先验 + 排除已访区域 | 112 | 208 | 0 | 85.33 |

先验把两次内的有目标命中率从 72.2% 提高至 86.1%，各分支视觉提示与目标具有人为设定的相关性。直接监督使用相同的局部入口图像、目标类型和物理路线。它与特征预测在 48 个查询的第一分支选择不同，各自多解决 12 个查询，最终总数相同。给特征预测先验加入依据近期观察的跨分支反馈后，有 4 次改变探查路径，2 次转为成功，2 次转为失败。

有目标时，预测先验在 200/240 个单实例查询中成功，在 48/48 个多实例查询中找到至少一个目标。剩余 40 个查询用尽两次机会。其正确表述是“检查预算内未找到”。若据此断言整个房间没有目标，将产生 40 次错误缺席判断；均匀先验会产生 80 次。

这些房屋是静态、人工布置的三分支场景。现场访问和报告使用当前相机输入。通用视觉编码器冻结，类别和摆放有限。该结果检验了三分支探查效率，动态换位结果见[六套新布局的独立实验](../hidden_goal/README.md)。
