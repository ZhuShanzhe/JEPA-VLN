# 多实例寻物闭环评测

沿用五个有完整原版记录的开发回合。回合编号依次为 1、14、21、32、39，目标实例配额分别为 2、3、3、3、5。原版 MOST-Nav 的高层决策、报告与终止处理、建图、动作集合、300 步预算和 0.25 米官方报告判定均沿用原配置。图像和决策调用使用 APIyi 的 `gpt-4o-2024-11-20`。

| 版本 | 在相同候选路线上的决策 |
| --- | --- |
| 在线记忆 | 对每条候选路线结合 V8 行动条件预测、几何得分、近期覆盖、前进受阻证据和真实看到的目标线索进行排序 |
| 静态对照 | 采用相同训练权重中的 V8 先验系数、固定几何系数、候选集合和改道门槛，排序仅依赖静态项 |

两个版本都记录当前观测。每步根据已发出的动作和原算法基于 RGB 变化判断的运动受阻信号更新局部位置。每三步遇到可校正的水平图像时，取冻结视觉模型在当前真实画面中 49 个网格的目标可见性最大值，写入该位置和朝向。记忆保存在单个回合的私有目录，跨回合清空。目标线索只识别类别，区分已报告实例由原版 MOST-Nav 处理。

| --- | ---: | ---: |
| 逐回合原始去重实例数 | 1，0，2，5，3 | 1，1，0，2，0 |
| 按每例任务配额封顶后的实例合计 | 9/16 | 4/16 |

五个原版回合的命中数依次为 1、0、2、2、0，V8 为 1、1、0、2、2。在线版本与静态对照相比有三例更多、一例持平、一例更少。在线版本共做了 57 次有效路线评分，其中 24 次同帧首选与静态对照不同，22 次实际执行到第一个不同的动作。静态对照第 39 例的一次上游请求超过 475 秒，已保留隔离记录和未知计费状态，该次尝试从评测分母剔除，以完整重跑结果计分。

每个决策处额外记录同帧下的静态版本、原 V8 和移除 JEPA 预测的选择。实际执行以动作进入仿真器并到达与对照分歧的第一个动作为准。全回合结束后独立重放动作并核验图像、位姿、可报告实例和正式报告。开发回合重复使用，研究结论限于这五例。两次独立调用托管 VLM 的输出可能不同。
