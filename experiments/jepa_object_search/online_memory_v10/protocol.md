# 研究问题与对照

任务是在给定动作预算内，找到并报告足够多的不同目标实例。检验的假设是，导航器用当前房屋的实际观测修正跨房屋学到的弱先验，可以把有限的步数分给更有价值的方向。

## 训练和推理

1. 预训练时，同一起点分叉执行不同短路线。实际走完路线后的视觉特征可以作为 JEPA 的预测目标。训练房屋与检验房屋分开，仿真真值只用于生成监督和事后评分。
2. 运行时，预测一条路线可能带来的视觉证据，同时查询当前房屋这片区域的观察记录。对少看过的地方保留探索空间。已经认真查看过的位置、实际碰壁的方向与同时代的正线索应区别处理。
3. 一帧没看到目标，可能是视角或遮挡所致。旧线索过期后可以回访。空间形状和陈设只参与排序，单出口的房间仍可能有目标。
4. 正式回合开始时清空其他回合的房屋记忆。同回合保存与恢复需要保留观测时间、证据和坐标约定。在线学习指运行过程中写入和修正场景记忆，模型参数更新另行区分。

## 预先确定的比较

| 比较 | 保持一致的条件 | 主要读数 |
|---|---|---|
| HSSD 留出房屋上的候选选路 | 同起点、同一组可执行候选、同一观测历史、同一预算 | 加入预测与在线记忆后，选中路线实际获得的目标证据；与固定先验、仅当前视觉、几何规则比较 |
| 人为改变物体摆放的受控场景 | 改变前两组共享相同观测。分别检查获得新证据前后，并保留位置不变的对照 | 旧位置是否被错误地持续优先，新位置能否升序；无变化时是否无端改道 |
| MOST-Bench 五个配对开发回合 | 历史冻结的时钟、彩色风景画、镜子、白门、灯五例。两组使用同一组路线候选、门控、VLM 快照、300 步预算和官方裁判 | 各组达到配额的回合数、裁判认可的不同实例数、动作预算与真实改道次数 |

MOST 闭环比较完整在线版与同版本关闭记忆评分的控制组。托管 VLM 会引入运行间波动，因此同时记录同一帧在不同策略下的候选首选。看到物体、选路变化、实际走近和正式报告分别核对。五例是反复用于开发的困难样本，整机结果只代表这组回合。

## 方法来源

动作条件潜变量预测借鉴 V-JEPA 2-AC。预测器可针对不同候选动作生成不同的未来表征，导航实验还须检验这些差异能否改变路线并提高寻物成绩。[V-JEPA 2](https://arxiv.org/abs/2506.09985)

动态环境里的物体搜索已有直接参考。Scene Graph Memory 根据历史观察和当前局部信息预测物体位置，提供了比较一般位置先验和当前场景记忆的思路。[Modeling Dynamic Environments with Scene Graph Memory，ICML 2023](https://proceedings.mlr.press/v202/kurenkov23a.html)

GOAT-Bench 研究了同一房屋中连续寻找多个目标时记忆的作用。其跨目标记忆评测与本项目回合内对旧线索的修正可以分别检验。[GOAT-Bench，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Khanna_GOAT-Bench_A_Benchmark_for_Multi-Modal_Lifelong_Navigation_CVPR_2024_paper.html)
