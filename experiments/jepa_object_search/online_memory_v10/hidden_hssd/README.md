# HSSD 自然房屋中的隐藏实例

从智能体实际生成的探索边界取候选路线，先记录起点已有的 12 个方向视图，再比较沿不同路线执行 4、12 或 24 步能走近哪些新实例。一个实例在已有视野中贡献过任何像素，就不算隐藏实例。同一栋房屋里可能摆着多个同类目标，看到某一把椅子仍可能需要寻找此前从未看到的另一把。

冻结视觉编码器和动作条件 JEPA 预测器，让小型选路头从候选未来表征读取目标本身以及其他类别的环境线索。目标词决定环境线索的权重。使用 12 栋训练房的 144 个起点。在 5,652 项“起点 × 目标 × 预算”中，181 项存在优劣路线，生成 970 对有顺序的路线监督。分离 4 栋校准房和另 4 栋检验房。真值只参与监督和评价。该附加头离线检验，MOST 正式闭环使用另外冻结的 V10。

| 使用的信息 | 校准房屋 | 留出房屋 |
|---|---:|---:|
| 路线几何 | 0.582 | 0.333 |
| 实际观察到的方向表征，同容量训练头 | 0.479 | 0.444 |
| JEPA 预测方向的表征，同容量训练头 | 0.539 | 0.333 |
| JEPA，更换为错误目标词 | 0.399 | 0.333 |
| 从候选中均匀抽取的期望值 | 0.287 | 0.493 |
| 可以预知所有路线结果时的上界 | 1.168 | 1.111 |

数值是在候选收益有差别的条件上，所选路线新达到合格视点的隐藏实例数，按房屋等权。留出集 588 个条件里仅 12 个提供辨别机会，来自 3 栋房屋的 4 个起点。8 个条件需要检验 24 步路线。当前自然数据未验证 JEPA 相对于实际观测或几何的增益。[训练与评测统计](natural_hidden.json)
