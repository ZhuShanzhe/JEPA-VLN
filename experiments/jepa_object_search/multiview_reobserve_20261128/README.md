# 没有最终观察位时的短程复看

从三视图导航中出现的全部 8 个“已接受框、已有深度锚点、无最终观察位”的时刻恢复仿真。每次复现机器人位姿、历史观测地图和相机画面，从该状态分出一条短路线。与原路线继续相同动作数时的画面比较。另单独重放前一版 4 个历史触发用于复核。台灯有一个触发在两组中重复，统计仅使用本轮 8 个时刻。[正式整屋评测](../multiview_nav_20261128/README.md)

机器人先朝向原线索，只在当前地图确认可行走且能拉近距离时前进。每一步都重新检测当前图像，核对原锚点投影位置及深度，存在多个匹配或发生碰撞时立即停下。每个时刻最多 4 个动作，最多前进两次，共 0.5 米。这条测试路线使用冻结的检测器和真实仿真动作。实例标注只用于运行后的独立核对。[控制器](reobserve.py) · [物理重放与评分](physical_review.py)

| 正确侧视候选 | 触发时源图中该实例的像素 | 短程复看结束时 | 原路线走同样动作数后 |
|---|---:|---:|---:|
| 台灯 | 232 | 264 | 0 |
| 植物 | 482 | 226 | 0 |
| 柜子第一例 | 2,301 | 2,127 | 2,105 |
| 柜子第二例 | 1,678 | 1,643 | 1,626 |

4 个正确候选都在随后真实取得的新画面中重新匹配到了同一实例，共 9 次正确关联。台灯和植物在同时刻的原路线画面中消失，两次柜子复看的可见面积与原路线接近。相对最初源图，只有台灯最终占据了更大面积。8 个时刻共执行 17 个动作，发生两次碰撞并终止。4 个正确候选均没有转成满足原约束的最终观察位；一个错误候选反而生成了最终观察位。[实例核对及每例结果](physical_review.json)

这项能力可以暂时保住线索。跨帧重新看到一个物体仍需和“它属于任务要求的类别、身份已经确认、位置满足上报规则”分别计量。该控制器作为可选短程实验保留。上表为固定起点分支的效果，8 屋主评测统计使用原三视图接口，未启用这个附加分支。短程物理试验没有新增付费调用。

在多次决策的宿主中，可用同一回合的持久轨迹编号限制重复启动。固定起点分支逐例恢复，没有测量回合级去重的效果。[交接记录](dispatch_guard.py)

PY=simulation/habitat-env/bin/python
$PY multiview_reobserve_20261128/physical_review.py run
$PY multiview_reobserve_20261128/physical_review.py score
