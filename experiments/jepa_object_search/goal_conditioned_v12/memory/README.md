# 探查后的在线改选

第一次探索留下的真实画面、位移和碰壁反馈，用来重排剩下的两条路线。V10 的回合内记忆保留访问过的位置和朝向、新颖性与目标线索。新训练的更新头额外估计沿剩余路线能否看到一个**不同的实例**，更偏向可能有新收获的方向。同一实例在两段路线里反复出现只计算一次。

训练使用 28 栋 HSSD 训练房屋的实际往返。从每个起点分别走第一条路线 24 步、返回 36 步，成功归位后实际执行剩余候选各 24 步。用不同实例 ID 的并集取得监督，在两种后续选择对新实例有不同收益时训练，共 1,729 个有效排序对。输入只来自起点、已经走过的路线、返回沿途和两个未走方向的名义动作。23 个特征表达它们的方向、重叠程度、起点视觉匹配、第一段新线索及已有记忆。每回合更新证据，训练参数冻结。6 栋校准房屋将额外修正强度选为 0.5。[冻结记录](memory_fit.json)

| 独立评测面板 | 同一首选头 | 既有在线记忆，两探至少发现一个目标 | 加训练更新头 | 第二段找到新实例的比例（旧→新） |
|---|---|---:|---:|---:|
| A，16 栋，525 查询 | 第一轮局部裁剪 JEPA | 76.42% | 75.85% | 31.17% → 30.64% |
| B，12 栋，430 查询 | 第二轮有界 JEPA 修正 | 76.09% | 77.83% | 31.62% → 33.74% |
| B，同一批查询 | V11 原首选头 | 75.34% | 78.26% | 30.45% → 33.74% |

在第二组房屋固定有界修正头的首选，学习后的改选把第二段新增实例的概率提高 2.12 个百分点，按房屋配对重采样的 95% 区间为 +0.09 至 +3.91。每个查询的已确认不同实例数从 1.012 升至 1.049。第一组房屋累积发现略有下降，显示收益会随环境和第一条路线变化。面板 A、B 的全部返回分别为 927/951 和 792/807；未成功归位时保留实际首段收获，并单列中断数。累计发现指标是已确认的物理观察机会。[两组完整结果](memory_results.json)

训练、校准和评测可依次调用 [观察编码](encode_observations.py)、[物理往返样本整理](memory_panel.py)、[训练与计分](train_replan.py)。[replan.py](replan.py) 提供证据特征和二次排序接口。[summary.py](summary.py) 以起点及房屋等权汇总实走结果。新模型与原记忆都只能读取被选择路线的观察，不遍历其它候选的未来画面。

[ObservedRouteUpdate](live_update.py) 是仿真运行时入口。传入当前回合持有的记忆、目标词、出发时的排序、实走去程与返程的 RGB 及碰壁记录，就能更新记忆并给出第二选择。返程未闭合时保留已有观察，返回空选择。6 栋校准房按固定顺序各取一个查询，实时 RGB 的二选与冻结缓存全部一致。[接口验收](live_update_check.json)
