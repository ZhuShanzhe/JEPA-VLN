# 多物体自主搜索实验准备

## 探索选路

输入是已观测的 RGB-D 片段、当前可达前沿与每个候选的动作序列。各分支从相同位姿出发，使用同一控制器与动作预算。策略只读取历史观测；未来观测、实例可见性和“是否为新匹配实例”保存在训练监督与离线评测端。

| 数据或接口 | 已验证的内容 |
|---|---|
| HSSD ObjectNav v0.2.5 | 作者发布的训练包为 122 个场景、120,552 回合，验证包为 42 个场景、1,248 回合。原始训练回合从原始位姿渲染出 RGB-D，并通过物理转向提取候选前沿。 |
| HSSD 分支试验集 v2 | 从独立于终评的 12 个训练房屋与 4 个开发房屋获得 144 个训练状态和 48 个开发状态。共 765 条候选分支和 18,360 帧未来 RGB-D。 |
| 分支区分度 | 固定 24 步内，不同前沿改变新目标可见结果的状态为训练 31/144、开发 2/48。此开发集适合接口和初步对照，细小改进须在更多独立场景复核。 |
| 预测输入 | V-JEPA 2.1 ViT-B/16 384 在 RTX 5090 上加载官方参数；已读取候选动作与未来特征。VLFM 的视觉语义排序已在实际 HSSD 图像上前向验证。 |
| HSSD-OV 补充基准 | StopWatch 独立发布的 1,751 回合、43 场景、93 个目标类别均能关联官方合法视点。单回合起点最短距离与发布记录一致。 |

## 主动选角与语言关系

PInVerify 正式评测按作者索引使用 3,000 个任务对，来自 1,000 次多视角采集。正例、同类负例和异类负例各 1,000 对。有 420 次采集同时含可见与低可见的可达扇区。该分组仅供离线分析。固定验证器、候选动作和预算，分别观察真目标接受率、相似物体误接受率及用步。

官方 Qwen3-VL-4B-Instruct、Grounding DINO 与离线仿真器已在同一回合联通。预检采用作者的多视角属性验证及随机选角配置。模型兼容适配包括 SDPA 和 Grounding DINO 的 PyTorch 采样路径。

已核对正式评测的 15,435 个文件和 SFT 训练侧的 9,492 个文件；145 个训练场景包通过校验并解包。训练索引含 15,225 对。以房屋为单位从作者训练数据划出 125 个训练房、20 个开发房，分别有 4,375 和 700 次采集。数据加载入口保存可达视角的相机位姿与图像路径；训练时可用真实目标视角作监督，评测时只允许策略看到已经访问的图像。

LangNav 作为语言关系补测。发布包的验证集有 832 个回合、20 个场景，测试集有 875 个回合、15 个场景。35 个场景均验证了 RGB-D 渲染、转向、位移及至少一个目标的可见性。原始起点在当前导航网格上的可用数量分别为 806/832 与 847/875；运行与官方评分前需逐条处理几何差异。

## 整机仿真准备

HSSD 开发房屋分为 100 个训练房和 25 个开发房，另隔离 43 个公开验证房屋。双实例教师预检覆盖实际移动、两次不同实例报告和主动结束。教师读取几何信息，成绩不参与学习策略的性能对照。整机规划与报告接口可参考 OneMap、3D-Mem 以及 MOST-Bench 作者发布的多目标适配器。原始 HM3D 场景需另行取得访问许可。
