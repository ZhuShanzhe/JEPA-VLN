# 按房间布局规划可达观察位

使用探索记忆生成已观察空地的局部栅格，按位置与机身方向搜索候选路线。JEPA 比较可达性与终点可见性，保留目标和余程，每前进至多两次便用新观察检查后续路段。未知或被标为障碍的位置限制后续前进。[决策入口](grid_policy.py) · [选择参数](calibration.json)

[实际路线几何对照](route_geometry.json) 记录绕行次数、看清机会和卡住次数。[低处空间覆盖诊断](low_body_support.json) 比较卡住和正常前进时机器人前方低位区域的可见情况。[首次上报与误报对照](../layout_audit_20261129/README.md) 汇总完整结果。
