# 完整回合的计分与诊断

[两例试验设计](design.json)固定任务、上限与主指标。[配对验收](audit.py)检查原版和改进版的目标集合、初始位姿、相机和有效报告判据，并验证每份结果对应独立 Habitat 重放。每次报告仅增加官方裁判新确认的实例，任务要求的不同实例全部记分才算完成。[正式结果](results.json)

[观察机会诊断](opportunities.py)在模型停止运行后重放实际动作。逐步核对真实实例是否同时清晰可见且位于有效报告距离内，检查过去保存的相机帧与原始标注点是否对应任务目标，再核对发出报告时最近的有效视点距离。语义标签和裁判距离只在事后使用。视角执行凭证核对预测动作末端与实际位姿，允许 0.125 米位置误差和 15 度朝向误差。[诊断结果](opportunities.json)

正式可见性回放使用至少两个不同观察位姿的连续画面，每张在 320×320 语义图中有至少 103 个目标像素。本目录的同帧诊断以一张达到 103 像素为准，用于定位可以确认目标的位置。专属决策调用的账本独立于共享图像描述服务。若服务商未回传金额，则只报告可核实的请求量。

[视角选择与执行](view_funnel.json)记录候选筛选、排序、动作改变和按选定动作到达视角的次数。[线索登记与报告](confirm_funnel.json)逐项对齐实例登记、回访、当前画面匹配、正式报告和裁判得分。两份统计可分别通过[视角统计程序](view_funnel.py)和[报告统计程序](confirm_funnel.py)从验收记录重新生成。
