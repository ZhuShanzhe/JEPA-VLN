# 时钟与画作的 MOST-Nav 配对评测

时钟任务要求报告两个不同实例，画作任务要求三个。每个回合的动作上限为 300，转向、扫描和报告使用同一官方动作预算。两个任务复用冻结原版 MOST-Nav 的验收记录，改进组使用同一 APIyi 决策模型 `gpt-4o-2024-11-20`、图像描述服务、建图设置、相机、初始位姿和实例裁判。正确报告的不同实例数和找齐配额的任务数为主要结果。

[准备和冻结](prepare.py)建立独立清单、比较相机与模型锁、核对离线功能回执和源代码指纹。正式入口为数据盘 `mapping_runtime/pilots/jepa_confirm_v18_first2/campaign.py run`。每项正式结果均通过独立 Habitat 动作重放和 RGB 帧核对。[进度检查](progress.py)输出结束状态、动作数和正式计分。
