# 实例候选框供应

将完整 RGB 画面和当前目标的类别名称交给本地 GroundingDINO Swin-T OGC。输出二维框、置信分数和来源，供地图与跨视角记忆核对；实例登记、重复裁决和已报告状态分别由上层维护。

| 部分 | 内容 |
|---|---|
| 输入 | 原始 RGB、目标类别。只有事后评分使用 HSSD 物理实例、语义掩膜与真值框。 |
| 候选产生 | 主视图沿用 0.35 目标门限和 0.25 文本门限。补充两个覆盖原画面宽高各 80% 的放大视图，分别对齐左侧和右侧，垂直居中。在人工裁切边界 3 像素内截断的框舍去。 |
| 重叠消除 | 映射回原画面，将候选按检测得分排列，移除与已保留框 IoU 达到 0.85 的候选。 |
| 模式确定 | 108 张校准图上比较全图、全图无结果才补框、全图与两个补充视图联合。在每帧新增未匹配框不超过 0.15 个、新增重复框不超过 0.04 个的条件下，优先选正确匹配数最多的模式。冻结结果为三视图联合。 |
| 接入 | `proposal_worker.ProposalWorker` 通过本地管道在专用环境里持久加载预训练检测器。输入每个相机原始帧；输出的 `xyxy` 与 `bbox` 均为原图像素的同一个框。 |

## 留出房屋结果

框与真值按 IoU ≥ 0.5 一对一匹配。真实目标按可见面积、最短边和填充比例筛选；未匹配预测包括细粒度语义差异、过小或遮挡严重的物体以及错误检测。

| 同一测试集，288 张全图 | 正确匹配 / 661 次物体出现 | 双物以上画面至少找到两个 / 145 | 未匹配预测 | 其中重复命中已有真值 |
|---|---:|---:|---:|---:|
| 单全图及重叠消除 | 314 | 79 | 196 | 6 |
| 三视图联合及重叠消除 | 338 | 86 | 219 | 11 |

三视图在重叠消除前给出 1,067 个候选，去重后保留 557 个。对应真值的重复框由 394 个降至 11 个，正确匹配从 343 次降至 338 次。两个近邻机位都能看到同一物体的 576 个成对机会中，两端均有正确框的有 273 次，至少一端有正确框的有 348 次。缺一端框时应保留待查状态。壁挂艺术品在 136 次出现中检出 102 次，时钟在 15 次出现中检出 12 次。

[冻结配置](protocol.json) · [逐类别统计](detector_summary.json) · [重叠与跨机位覆盖](coverage_summary.json)

按 16 栋房屋配对重抽样 5,000 次，三视图相对单全图的召回率增加 3.63 个百分点（95% 区间 1.67 至 6.16），双框覆盖率增加 4.83 个百分点（0.69 至 10.46）。每帧未匹配框增加 0.080（0.045 至 0.122）。单独在 60 帧同款钟表与画作控制场景使用冻结配置，30 张多个目标同时可见的图像中，19 张能匹配至少两个不同物体。[房屋配对区间](house_summary.json) · [补充控制组](control_detector_summary.json)

## 历史 RGB 与接口验收

三个历史报告帧的原生当帧登记框均为零，使用三视图检测分别得到 1 个时钟候选、2 个和 4 个画作候选。旧画面没有可独立核实的实例标识。用导航原生评测解释器调用真实 GPU 检测进程，按清单选取的零框、一框、两框校准帧均与离线输出吻合。[历史帧复核](archive_summary.json) · [接口验收](worker_summary.json)

`evaluate.py` 运行主校准与测试，`coverage.py` 复算相邻机位和近距实例的候选覆盖，`extra_panel.py` 使用同一冻结配置处理补充控制集。逐帧候选和图像位于项目数据盘。
