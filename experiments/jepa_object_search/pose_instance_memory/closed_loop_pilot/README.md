# 跨视角实例记忆在 MOST-Nav 中的闭环测试

## 实例复核与报告

系统把本地检测框交给上层模型审核。在同类实例身份仍有歧义时，位姿 JEPA 结合物体裁剪、背景、相机相对位姿和可见表面的位置差给出相同实例的提示。上层继续审核身份，底层负责到达可报告位置并执行动作。

画作第 78 步的正式报告来自新增检测框，该框已通过审核并进入实例记忆。裁判记录到最近合法视点还有 0.641 米。第 211 步的报告来自原生候选，距离为 1.029 米。重放这两个报告时刻，320×320 语义图中三个任务目标的像素数均为零。第 78 步的 RGB 与送给上层模型的图像逐字节一致；第 211 步为自动报告，按实际动作重放并以裁判距离核对。两次报告都没有得分。

单独检查时钟的首次尝试。决策服务在第 117 步超时并触发兜底动作，此次尝试单列为工程中断。在超时前的第 80 至 116 步，上层模型连续 37 次要求报告，底层均执行左转。28 次因外观匹配未通过，9 次因缺少合格的近距视角。只抽查首尾两步，重放的 RGB 均与上层输入逐字节一致，且距离有效视点都是 0.223 米。在其中任一处执行报告都能获得同一个尚未上报的时钟。此前第 37 步有两条待判重观测，当时地图还未完成米制标定，第 38 步才获得尺度。

画作回合中，43 次有有效回复的上层决策请求均收到实时检测框，涉及 15 个不同动作步。一个新增候选通过了原生登记，全程未出现需要提交给位姿头评分的候选对。时钟从相同起点补跑一次，第 130 步再次出现决策超时。此前有 51 次有效报告请求被转换为左转，分布在第 75 至 90 步和第 95 至 129 步。两次中断均保留在工程日志。三次尝试中，线上位姿头实际评分均为零。

## 位姿头的独立功能检查

在 HSSD 留出房屋中按房屋、序列、机位和预测框的固定顺序，分别取第一对满足复核条件的同物观测和同类异物观测。使用真实 RGB 检测框、RGB-D 和已知相机位姿，通过与闭环相同的待复核入口和冻结权重。两对均使用 0.941285 的阈值。

| 输入原生待复核入口的观测对 | 机位间距 | 光轴夹角 | 分数 | 返回给上层的结果 |
|---|---:|---:|---:|---|
| 换机位观察同一把椅子 | 0.24 米 | 10.07° | 0.994 | 给出同一实例提示 |
| 两件靠近的同类沙发 | 0.24 米 | 10.55° | 0.750 | 保留独立复核，未给出合并提示 |

两对观测均保留了原生审核权。这里检验的是位姿和观测齐备时的接口行为。HM3D 运行时需要从建图结果恢复米制尺度，线上增益以表中的正式回合为准。

## 改进重点

报告被拒时，把原因和上一次有效视点反馈给上层，同一实例、同一证据再次被拒后，转为前往新视点取证。执行报告前，用当前图像核对是否确实看到了登记的实例，并复核当前位置。米制尺度稍晚才就绪的观测可保留为待复核项，在有新几何证据时再次提交位姿头。两项闭环诊断分别覆盖了可得分时误拦报告和不可得分时放行报告。

三次尝试共记录 194 个去重后的专属决策网关请求，192 个成功，2 个在发送后超时，最终计费未知。这一计数含健康检查等网关流量；共享图像描述服务另计，日志未给出实际货币金额。
