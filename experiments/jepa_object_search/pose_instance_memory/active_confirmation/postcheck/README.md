# 审核编号反馈

画作回合中，模型先用两个正确的候选编号拒绝相应画面，随后在同一步提交了数字 1 和 2。数字并非该次登记表内的候选编号。原工具返回操作成功，实际处理数为零。同一步尚未产生后来一直没有审核的另外三个候选。

编号反馈模块对未知引用返回明确错误，并列出调用当时实际可审核的候选。混合提交时，只有有效项进入原有语义和几何审核。该模块在付费测试结束后用已存的真实请求和原图验证；两例正式分数对应原先冻结的入口。

后续运行可选择单独的 `review_feedback_agent:ReviewFeedbackFrontier` 代理入口。回放核验了两次真实提交与五张原始候选图。已审过的真实编号仍交由原生工具处理。[代理入口](review_feedback_agent.py) · [编号校验](review_ids.py) · [原请求回放](replay_review_ids.py) · [回放结果](replay_summary.json)
