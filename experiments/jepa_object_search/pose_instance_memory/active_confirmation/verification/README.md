# 仿真与计分核对

在原时钟场景重放已保存的相机帧，分别将该帧的两个区域作为近距登记线索。两例使用相同的 0.60 米距离输入、理想局部里程计和只覆盖已走短通道的地图。转身离开后，让策略发出真实的 Habitat 前进和转向动作。在到达机位后，使用当前 RGB、冻结检测器和原有外观门控再次识别。离线核查使用实例语义像素和原生裁判。原始图像、实例标注和已执行轨迹保存在受限实验环境。

| 预输入 | 真实结果 | 裁判新增正确实例 |
|---|---|---:|
| 登记框含真时钟，实时检测可用 | 11 个动作后同一只时钟再次可见，可见像素从 0 恢复到 3,710，系统发出报告 | 1 |
| 同一登记框、同一路线，屏蔽新检测 | 系统回到同一机位，缺少新检测框时暂缓报告 | 0 |
| 预先登记一个误检框 | 背景再次匹配，系统误认该区域；原框内任务目标像素为 0 | 1，附近恰有真时钟 |

裁判依据可报告视点的距离给分。在同一位置，视觉上认错区域也可能得分。受控回放同时保留了这两种判定。[免费核查汇总](free_checks.json) · [场景回放](verify_views.py)
