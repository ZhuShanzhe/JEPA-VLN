# 近距离重新观察

输入是已登记实例的局部外观、登记相机的估计位姿、当前位姿和在线占据地图。策略先寻找可行走且朝向实例的机位，逐步执行前进或转向，再用抵达后的 RGB 观测调用同一套近距、外观和实例冲突检查。登记的相机位姿和物体中心承担不同作用，前者描述“从哪里看清过”，后者用于估计物体所在方向。

每个动作都与下一次观测携带的实际动作和估计位姿对齐。位姿偏差、前进受阻、路线新出现障碍或实例消失时，会结束本次尝试并把控制权交还给探索。每个实例的尝试次数有限。报告动作有单独的执行回执。
