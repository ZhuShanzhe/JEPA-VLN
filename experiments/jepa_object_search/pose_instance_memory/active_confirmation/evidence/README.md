# 区域到实例的证据

区域选择按原始相机帧和掩码关联。异步建图返回后，记录生成的候选、随候选保存的局部图，以及原生实例审核的回执。遇到暂时未就绪的帧，短暂等待后，用同一帧和选区继续处理。尚待审核的候选可再次提供给上层决策。

统计时分别核对决策状态、实际成功请求携带的候选图、模型提交的审核结果和原生实例登记。每次请求可携带的图片数有限，状态里出现候选编号时，候选图可能仍在等待送达。每一阶段按不同候选分别计数，多次出示同一候选只占一个。
