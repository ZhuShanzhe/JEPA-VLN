## 时钟在什么地方卡住

收到近距线索后，机器人优先返回曾看清实例的相机位置和朝向；若原机位无法使用，则在当前地图上搜索另一处可达视角。抵达后用当前图像和登记外观重新核验。当前方被堵、估计位姿偏离或目标位置估计移动时，结束这次尝试并保留线索。[视点控制与测试](view/README.md)

付费回合启动了 4 次复看。17 个复看动作与实际动作及下一次观测的动作回执完全一致，其中 10 次前进均产生了位移。3 次到达后未通过当前实例外观匹配，另 1 次因位姿或目标估计变化结束。时钟场景共有 3 个任务实例，至少需要报告 2 个；本次只进入过 1 个实例的合法报告范围。改进复看与发现第二个实例属于两个不同环节。[物理动作核对](verification/report_and_motion_audit.py)

对首次抵达后匹配失败的复看单独做了物理回放。134 步前的登记点确实属于所找的时钟，但登记框中只有 76/315 像素是该实例。复看前后，同一只钟的可见像素从 11,693 增到 17,968，两个位置都满足官方距离。终点唯一可用的检测框只覆盖真钟可见像素的 5.01%，与真值框的交并比为 0.0555。冻结检测器和外观匹配重现了拒绝。此例的物体已经可见，直接问题在于近景定位和用早期小图确认同一实例；其余复看需要分别归因。[时钟抽查记录](verification/closed_clock_confirm_audit.json)

## 画作候选到了哪一步

上轮 7 次区域选择中，6 次完成异步映射，产生 16 个候选。13 个进入后续决策状态，9 个候选的图片确实随成功请求送达，最终收到审核的候选数为 0。有 3 个候选在最后一次决策之后才生成。

本版对异步返回的候选保留原始帧、掩码和图片。同一选择可在地图就绪后继续，重复选择可取回原候选。用上层成功请求的实际附件核对送达情况，尚待审核的候选可有限次再次送交。两次决策对同一候选的出示计为一个候选。[候选交接与测试](evidence/README.md)
