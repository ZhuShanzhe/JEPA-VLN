# 用位置和机位区分同类物体

首次找到目标时，保存物体外观、周围背景、观察机位和可见表面的位置。以后再看到类似物体，先在原图及局部放大图寻找独立候选，把每个框投回地图。用 JEPA 从首见机位预测换到新机位后的视觉特征，再检查候选的实际位置和外观是否吻合。两个机位都能分别跟踪到两个分开的物体时，登记为互斥线索，避免后续把它们合并。只有原系统确认身份且该实例已报告，才取消对它的重复回访。

## 真实候选框

从 HSSD 的 10 栋训练、6 栋校准、16 栋测试房屋生成 576 帧，覆盖多个同类同时可见、单实例和转向观察。测试有 96 个三机位片段，共 288 帧。冻结 GroundingDINO 的多尺度补框方案在校准集选定。在 661 次合格实例出现中，全图检测框对 314 次，加入局部放大后框对 338 次。145 张多实例图中，至少正确检出两件从 79 张增至 86 张。未匹配合格标注的框也从 196 增至 219 个。新增框先作为待核验线索。[数据](data/README.md) · [检测器和补框对照](detector/README.md)

## 位置和机位信息分别在哪里起作用

从首见相机坐标系预测另一视角，使用相对平移、相对旋转和源物体观测深度。把预测与新图比对时，再加入两次观测位置的偏移和射线方向差。只把机位变化给视觉预测器，在自然测试的相邻视角中识别出 87/181 个同物对，仅用朝向为 92/181。把实际候选的空间位置也送入核验端后，识别出 159/181 个，但把 227 对异物中的 26 对也认成同物。同输入直接监督分别为 150/181 和 15/227。[模型、训练和消融](model/README.md)

固定 RGB 和相机位姿，把查询物体的观测位置人为向右移一米，181 个真实同物对中有 178 个的同一实例分数下降，中位下降为 0.400。把整个场景的坐标原点和朝向统一改变，分数最大变化小于 0.00001。模型会利用物体相对机位的位置。[输入核验](model/pose_input_checks.json)

## 同框和相邻机位能否保护两个不同实例

在同一画面中两个分开的框可以提示存在两件物体。跨机位时，用独立深度与双向投影分别跟踪每个框，只有两个物体的一对一对应均明确、且两幅画面中的框各自分离时，才禁止交叉合并。把同款壁钟或同款墙画复制到原件相邻位置，间距为 0.43 至 1.14 米。10 套布局使用相同机位分别渲染单物和双物，共 60 帧。两件均可见时，同时取得两个正确框的双钟画面为 7/15，双画为 11/14。在 56 个同款近邻的跨机位异物组合中，真实检测框能为 22 个提供互斥证据；使用真值框时为 46 个。单画布局也出现 12 个未经标注支持的互斥提示，直接根据候选数量新建实例有误拆风险。[同款控制](data/controls_detector_audit.json) · [跨机位核验](association/README.md)

对于从未同时出现在这三个视角的两个实例，还试验了双向重投影。给观察框和深度范围留出余量后，两次投影仍分别落在对方框外，才标记为可能不同。自然测试有 8 对可核实的此类异物，其中 2 对被标出；273 对同物中没有被误标。这个子集太小，暂时只保留为复核提示。[分离诊断](model/panel_results.json)

### 近邻困难样本

仅按整体误合并率选择阈值时，基础位姿 JEPA 把 37 对估计距离不超过 0.60 米的异物错并了 23 对。单独增加训练房屋中的近邻、同款异物采样，按相同规则校准后仍为 23/37。改为在校准房屋同时限制整体和近邻误合并率，再在自然测试中比较：基础 JEPA 错并近邻 5/37，整体认出 127/181 个同物对；同预算难例 JEPA 分别为 6/37、135/181。高风险场景采用保守阈值的效果比单独增加难例更明确，需要以漏认一部分重见为代价。难例头保留为实验选项。[近邻训练和校准方法](hard_cases/README.md)

## 全片段关联

同一物体在测试房屋的两个视角里都可见，共有 576 次关联机会。受检测覆盖限制，两端都有正确候选框的只有 273 次。下表对每个三机位片段的三种机位配对进行一对一关联，所有方法共享同一套检测结果。每一条输出都归入正确、错误或无法按现有标注核实三类。

| 关联方法 | 正确认出同一件 ↑ | 确认错并不同物体 ↓ | 无法核实 |
|---|---:|---:|---:|
| 仅朝向条件的 JEPA | 150 | 4 | 35 |
| 仅用双向投影和一对一几何规则 | 237 | 0 | 89 |
| 位姿 JEPA | 240 | 5 | 94 |
| 几何规则＋同输入直接监督 | 248 | 5 | 110 |
| 几何规则＋位姿 JEPA | 253 | 3 | 109 |
| 几何规则＋位姿 JEPA，近邻使用保守阈值 | 246 | 2 | 99 |
| 几何规则＋直接监督，近邻使用保守阈值 | 245 | 4 | 105 |

规则＋位姿 JEPA 正确认出 253/273 个两端可检测的重见，按全部可见机会计为 253/576。与同输入直接监督相比多 5 次、确认的错并少 2 次。按 16 栋房屋配对重抽样，全可见机会上的召回差为 +0.87 个百分点，95% 区间为 0.00 至 +2.25。剔除框密集的书柜类别，两者分别正确关联 246 和 241 次。独立同款控制组中，两种联合方法均认对 52/88 次可见重见，23 条关联缺乏可核实标注。现有证据更明确地支持加入空间一致性与可靠共现保护；JEPA 损失相较直接监督的额外收益仍需更多不同房屋和随机种子。[自然场景](model/panel_results.json) · [独立同款测试](model/control_panel_results.json)

## MOST-Nav 接入

实验入口为 `multiview_agent:MultiviewFrontier`。原生解释器已能向本地检测器请求候选框，并用训练后的位姿头评分。当前实时画面可取得辅助框；有图像和地图对齐证据的关键帧再走原生分割、候选审核和登记，沿用原报告回执。19 项接口测试及实际权重跨进程调用通过。完整导航中的回访次数、行动数及正确报告的实例数应在固定预算的闭环回合中另行测量。[运行开关与接口](association/README.md)

针对近距离去重，可指定 `hard_cases/pose_jepa_near_review.pt` 作为可选复核权重。它沿用基础位姿头的参数，采用专门在近邻数据上校准过的高阈值。全片段对照对 0.60 米以内的学习提示使用该阈值，优先保留双视角独立核验的几何对应。[近邻档与常规档对照](model/near_panel_summary.json)
