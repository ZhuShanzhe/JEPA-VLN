# 位姿条件的跨视角实例预测

用首次观察的目标框、遮去目标的周围环境和相机位姿预测另一个机位的视觉表示。检测器先独立找出新画面的候选框，实例核验头再将每个候选的实际表示、可见表面点与预测进行比较。

| 输入 | 预测与核验 |
|---|---|
| 物体与背景 | 沿用冻结的 DINOv2 表征，共 2,304 维。物体框四边各扩 15%；环境框各扩 80%，遮掉中间目标。 |
| 两次机位 | 在首见相机坐标系表示平移和相对三维旋转。预测器读取起始特征、相对机位以及源框内可见表面点相对源相机的坐标与单位方向。单向预测时没有目标视角的 RGB 或检测结果。 |
| 位置一致性 | 用框内可观测深度估计一个表面支撑点。核验时计算两点的空间距离、沿光轴的偏移、两端观测射线的方向差以及机位位移。两个方向分别预测后，取对称分数。绝对房间编号、物体真值中心与资产编号均排除在模型输入外。 |
| 损失与训练 | 物理实例同一性二分类，加权重 3 的正例跨视角余弦预测损失。直接监督使用相同架构、输入、采样、随机种子和更新次数，仅训练身份分类。 |

## 数据与比较

原来的 11,482 个视角提供大角度同物与同屋同类异物对。在原 28 栋训练房屋重放深度，与原 6 栋校准、16 栋测试房屋的深度合并，按裁剪 RGB 逐像素核对。新增 576 帧近机位数据使用训练集中的 10 栋房屋及原校准、测试房屋。三个子集不跨房屋。冻结检测器的框与标签做一次独立的一对一匹配（IoU ≥ 0.50）。对应标签用于监督和评分；框内深度用于模型输入。

旧训练视角产生 55,208 对样本，新检测帧产生 1,112 对。训练批次各取一半。新增部分在相邻视角同物、相邻视角异物、同帧异物、同一检测框的小幅扰动四组中均衡采样，并均衡类别。同时扰动机位与观测位置，以减少依赖理想深度的倾向。每个模型训练 14 轮，每轮 80 次更新，随机种子 12511。在校准房屋按两种数据部分 ROC 面积均值选择轮次，分别标定旧裁图与真实检测框的阈值。本轮是探索性比较，旧测试房屋在前次研究中也有使用。

| 真实候选框的相邻视角测试 | 181 对同物中正确识别 ↑ | 227 对异物中错误合并 ↓ |
|---|---:|---:|
| 仅位置距离 | 147 | 13 |
| 仅朝向条件 JEPA | 92 | 20 |
| 机位和位置进入预测器，核验端只比视觉特征 | 87 | 16 |
| 机位与观测位置核验，直接监督 | 150 | 15 |
| 机位与观测位置核验，JEPA | 159 | 26 |

该表使用每段序号相邻的两组视角。阈值在真实检测框的校准候选上以不超过 5% 的误合并率选取；列出测试房屋的实际计数。JEPA 与同输入直接监督的召回差为 +4.97 个百分点，按房屋配对重抽样的 95% 区间为 −1.20 至 +12.32 个百分点。只把坐标送入预测器，没有呈现上述联合方案的增益。两候选的估计支撑点相距不超过 0.60 米时，基础位姿 JEPA 在 37 对异物中错并了 23 对，直接监督错并 13 对。近邻证据冲突时需要保留两个候选。[训练、消融与分组结果](pose_results.json)

## 重算

服务器实验目录使用 `jepa_reid_v21`，上轮冻结视觉编码、权重和采集清单位于同项目的 `jepa_reid_v20`。先用 Habitat 环境运行 [training_depth.py](training_depth.py) 重放原训练房屋，再用策略环境运行 [encode_proposals.py](encode_proposals.py)、[train_pose.py](train_pose.py)、[panel.py](panel.py)。后面三个程序均以服务器项目根目录作首个参数。控制组使用 `--frames`、`--predictions`、`--cache` 指定独立的清单、检测和缓存，评分时添加 `--out` 保存独立结果。

[pose_inference.py](pose_inference.py) 接收每个机位的相机到世界变换、独立候选的表面点和视觉特征，只在有效输入上计算分数。已有可信一对一几何对应优先，可观测的互斥关系优先于外观相似度。近机位间从未同框的分离判断另以扩张的双向投影区域做诊断。[自然场景联合评分](panel_results.json) · [克隆同款控制组](control_panel_results.json)
