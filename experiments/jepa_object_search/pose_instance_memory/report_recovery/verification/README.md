# 当前画面与实例身份验证

[关键步回放](old_views.py)在原 Habitat 环境重放两例已知的旧动作序列，只抽查时钟第 80、116 步和画作第 78、211 步。时钟中断轨迹保留了当前图像和检测框，缺少终局分割登记表，因此四帧表中时钟的身份支持标作未知。画作保留了登记框与关键帧，两次上报都能检验新门槛。第 211 步由系统自动报告，重放时用每一步的原始位置核对仿真，并用冻结检测器重新生成当步框。[四个视点的结果](old_views_final.json)

[留出房屋对照](view_controls.py)在 16 栋 HSSD 房屋内按房屋、序列、视角及检测框次序选取两类各一对观测。两幅图属于同一个房屋、同一目标类别。第一类在后一图仍有原目标标注，第二类在后一图只标注了其他同类实例。固定样本后，两个视觉方法均用同一张实际检测框内的物体建立参照，并在完整当前画面定位。真值框用于选择样例和判分，匹配器接收 RGB、保存的参照和实际检测框。输出框与唯一标注实例的 IoU 至少为 0.50 时判定身份；无法唯一对应的框单列。[32 对观测结果](view_controls.json)

这两项测试核对报告前的局部视觉证据。导航动作、几何距离约束、位姿 JEPA 的延迟审核以及任务成功数在各自的独立结果中统计。
